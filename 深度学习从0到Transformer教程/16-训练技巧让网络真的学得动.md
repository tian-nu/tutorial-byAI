# Ch16 · 训练技巧 — 让网络真的学得动

> 所属篇：第二篇 · 预计耗时：25 分钟

你建了个网络，跑了一下——loss 不动。或者 loss 下降了但抖得像心电图。别急，这不是网络的问题，是你还没掌握"训练技巧"。学习率、批大小、优化器、初始化……这些"调料"决定了网络能不能学得动。就像做菜——食材（数据和模型）一样，但火候和调料（训练技巧）不同，结果天差地别。

---

## 为了什么（Why）

**核心痛点**：裸跑的 SGD 经常不收敛或收敛太慢；需要一系列技巧让训练稳定高效。

举个反例：
- 学习率设成 0.001 太小？跑了一晚上 loss 才降了 0.01。
- 学习率设成 1.0 太大？直接发散到 NaN。
- 权重全部初始化为 0？所有神经元学到一模一样的东西，网络退化为一个神经元。

**这一章的目标**：掌握 Momentum、Adam、权重初始化、BatchNorm、Dropout 等核心训练技巧，知道什么时候用哪个、怎么用。

## 要做到（Goal）

- **输入**：一个能前向 + 反向传播的网络（Ch14-15 的产物）。
- **输出**：训练稳定、收敛快的配置方案。
- **成功标准**：loss 平滑下降，测试集表现达标。

### 逐组件拆解

**学习率调度**：训练初期用较大学习率快速下降，后期用较小学习率精细调参。常见策略：固定值、指数衰减、余弦退火（Cosine Annealing）。

**批大小（Batch Size）**：
- **BGD（批量梯度下降）**：每次用全部数据。稳定但慢，内存装不下。
- **SGD（随机梯度下降）**：每次用 1 个样本。快但抖动大。
- **MBGD（小批量梯度下降）**：折中方案，通常用 32~256。工业界默认选择。

**优化器**：
- **SGD**：最基础，`w = w - lr × grad`
- **Momentum**：给 SGD 加"惯性"，累积历史梯度方向
- **Adam**：自适应学习率 + 动量，目前最常用

**权重初始化**：
- **Xavier/Glot 初始化**：适合 sigmoid/tanh 激活
- **He/Kaiming 初始化**：适合 ReLU 激活

**BatchNorm（批归一化）**：对每一层的输入做归一化（均值 0、方差 1），让训练更稳定。

**Dropout**：训练时随机把一部分神经元"关掉"（输出置 0），防止过拟合。

## 怎么算（How）

### 核心公式

#### Momentum（带动量的 SGD）

```
v = β·v + (1-β)·grad      ← 累积速度（惯性）
w = w - lr·v               ← 沿速度方向更新
```

其中 β（通常 0.9）控制"惯性强度"。β 越大，越依赖历史梯度方向。

直觉类比：推一辆车下山。纯 SGD 是每步重新判断方向再走；Momentum 是车子有惯性——即使当前坡度变了，车子还会沿之前的方向继续滑一段。这让它在"平坦的谷底"不会来回震荡，而是平滑地滑向最低点。

#### Adam（自适应矩估计）

```
m = β₁·m + (1-β₁)·grad           ← 一阶矩估计（类似均值）
v = β₂·v + (1-β₂)·grad²          ← 二阶矩估计（类似方差）
m̂ = m / (1-β₁ᵗ)                  ← 偏差修正的一阶矩
v̂ = v / (1-β₂ᵗ)                  ← 偏差修正的二阶矩
w = w - lr · m̂ / (√v̂ + ε)       ← 自适应更新
```

### 数值小例子：Momentum 的 3 步累积

初始状态：v = 0, w = 0, β = 0.9, lr = 0.01
假设每步梯度都是 g = 1.0（模拟持续下坡的场景）

**第 1 步**：
```
v₁ = 0.9×0 + (1-0.9)×1.0 = 0 + 0.1×1.0 = 0.10
w₁ = 0 - 0.01×0.10 = -0.001
```

**第 2 步**：
```
v₂ = 0.9×0.10 + 0.1×1.0 = 0.09 + 0.10 = 0.19
w₂ = -0.001 - 0.01×0.19 = -0.0029
```

**第 3 步**：
```
v₃ = 0.9×0.19 + 0.1×1.0 = 0.171 + 0.10 = 0.271
w₃ = -0.0029 - 0.01×0.271 = -0.00561
```

对比纯 SGD（每步 `w -= 0.01×1.0 = -0.01`）：

| 步数 | 纯 SGD: w | Momentum: w | v 值 |
|------|-----------|-------------|------|
| 1 | -0.010 | -0.001 | 0.100 |
| 2 | -0.020 | -0.003 | 0.190 |
| 3 | -0.030 | -0.006 | 0.271 |

可以看到：**Momentum 前期比 SGD 慢**（因为速度还在积累中），但随着 v 越来越大，后续会加速超过 SGD。这就是"惯性"的效果——起步慢但后劲足，且不会像 SGD 那样在谷底来回震荡。

### 数值小例子：Adam 第 1 步完整计算

初始状态：m = 0, v = 0, β₁ = 0.9, β₂ = 0.999, lr = 0.001, ε = 1e-8
假设第 1 步梯度 g = 1.0

**计算一阶矩 m 和二阶矩 v**：
```
m₁ = 0.9×0 + 0.1×1.0 = 0.10
v₁ = 0.999×0 + 0.001×1.0² = 0.001
```

**偏差修正（Bias Correction）——为什么需要？**

这是初学者最容易困惑的地方。m 和 v 初始化为 0，所以刚开始几步它们的值会被"拉向 0"（偏小）。比如第 1 步 m = 0.1，但真实的梯度均值应该接近 1.0（因为我们只有 1 个样本 g=1.0）。偏差修正就是除以 `(1-βᵗ)` 来补偿这个初始化偏差：

```
m̂₁ = m₁ / (1-β₁¹) = 0.1 / (1-0.9) = 0.1 / 0.1 = 1.0
v̂₁ = v₁ / (1-β₂¹) = 0.001 / (1-0.999) = 0.001 / 0.001 = 1.0
```

注意看！修正后的 m̂ 和 v̂ 都变成了 1.0——这才是对第一步梯度的合理估计。

**参数更新**：
```
w₁ = 0 - 0.001 × 1.0 / (√1.0 + 1e-8) ≈ -0.001
```

Adam 第 1 步就走了完整的 `-lr` 大小的步长！而 Momentum 第 1 步只走了 `-lr×0.1`。这是因为 Adam 的偏差修正机制让它在早期就"自信地"迈出大步子。

### Xavier / He 初始化公式简要

**Xavier 初始化**（Glorot, 2010）：适用于 sigmoid/tanh
```
W ~ U(-√(6/(n_in+n_out)), √(6/(n_in+n_out)))
或 W ~ N(0, √(2/(n_in+n_out)))
```

**He 初始化**（Kaiming, 2015）：适用于 ReLU
```
W ~ N(0, √(2/n_in))
```

直觉：Xavier 让每层输出的方差保持不变（不爆炸也不消失）；He 在此基础上考虑了 ReLU 会把一半的神经元归零，所以用更大的方差来补偿。

## 怎么用（Use）

代码文件：`深度学习从0到Transformer教程/code/ch16_training_tricks.py`

关键片段：

```python
import torch
import torch.nn as nn

# 定义带 BatchNorm 和 Dropout 的模型
model = nn.Sequential(
    nn.Linear(10, 64),     # 全连接层: 10维 → 64维
    nn.ReLU(),             # ReLU 激活
    nn.Dropout(0.5),       # Dropout: 训练时随机丢弃50%的神经元
    nn.Linear(64, 32),     # 全连接层: 64维 → 32维
    nn.ReLU(),
    nn.BatchNorm1d(32),    # BatchNorm: 对32维特征做批归一化
    nn.Linear(32, 2),      # 输出层: 32维 → 2类
)

# Adam 优化器 + 余弦退火学习率调度
opt = torch.optim.Adam(model.parameters(), lr=0.001)
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(opt, T_max=100)

# 训练循环
for epoch in range(100):
    for X_batch, y_batch in dataloader:  # dataloader 见下方说明
        pred = model(X_batch)
        loss = nn.CrossEntropyLoss()(pred, y_batch)
        opt.zero_grad()    # 清空梯度
        loss.backward()    # 反向传播
        opt.step()         # 更新参数
    scheduler.step()       # 更新学习率

# 推理时必须切换模式！
model.eval()
with torch.no_grad():
    test_pred = model(test_X)
model.train()  # 切回训练模式（如果还要继续训练）
```

**关于 dataloader**：上面的代码假设你已经有一个 `dataloader`（通常是 `torch.utils.data.DataLoader` 的实例），它负责每个 iteration 返回一批数据 `(X_batch, y_batch)`。如果你还没有，可以用以下方式简单创建：

```python
from torch.utils.data import TensorDataset, DataLoader

# 假设 X_tensor 和 y_tensor 已经准备好
dataset = TensorDataset(X_tensor, y_tensor)
dataloader = DataLoader(dataset, batch_size=32, shuffle=True)
```

## 想多一点

> 为什么 Adam 最常用？
>
> 三个原因让它成为"开箱即用"的首选：
>
> 1. **自适应学习率**：Adam 为每个参数维护独立的学习率。稀疏特征（出现频率低的词）自动获得更大的更新步长，频繁出现的特征则被抑制。不用手动调不同参数的学习率。
> 2. **动量效果**：内置 Momentum 机制，不需要单独配置 β 参数就能享受惯性的好处。
> 3. **鲁棒性强**：默认参数（lr=0.001, β₁=0.9, β₂=0.999）在绝大多数场景下都工作良好。不像 SGD/Momentum 那样需要精心调学习率。
>
> 当然 Adam 不是万能的——在某些需要精确控制的场景（如 GAN 训练、强化学习），研究者还是会回到 SGD+Momentum。但对 90% 的日常任务来说，Adam 是最好的起点。

## 易错点预警

- ❌ 权重全部初始化为 0，导致所有神经元对称、学到完全相同的权重（对称性破缺失败）→ ✅ 正确：使用 **Xavier** 或 **He** 随机初始化（PyTorch 的 `nn.Linear` 默认就是 He 初始化，所以大部分情况你不需要手动设置）。
- ❌ 推理时忘记调用 `model.eval()`，导致 Dropout 仍然随机丢弃神经元、BatchNorm 用当前 batch 的统计量而非全局统计量→ ✅ 正确：推理前务必调 `model.eval()`，训练前调回 `model.train()`。
- ❌ 学习率太大导致损失发散（变成 NaN）→ ✅ 正确：从较小的学习率开始（如 1e-3），观察 loss 曲线。如果 loss 不降就适当增大，如果震荡就减小。

## 章末小结

| 技巧 | 作用 | 易错点 |
|------|------|--------|
| 学习率衰减 | 后期精细调参，避免在最优解附近震荡 | 衰减太快会导致提前卡住不动 |
| Momentum | 累积历史梯度方向，加速收敛并减少震荡 | β 太大（如 >0.99）会导致震荡加剧 |
| Adam | 自适应学习率 + 动量，开箱即用 | 默认参数就够了，不要过度调参 |
| 权重初始化 | 打破对称性，让不同神经元学到不同特征 | 全 0 初始化是新手最常见的错误之一 |
| BatchNorm | 归一化每层输入，稳定加速训练 | **推理时必须切 eval 模式** |
| Dropout | 训练时随机丢弃神经元，防止过拟合 | 同上，推理时必须关闭（eval 模式自动处理） |
| 批大小 | BGD 稳定但慢，SGD 快但抖，MBGD 折中 | 默认选 32~128，根据 GPU 显存调整 |
