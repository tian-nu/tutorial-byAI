# Ch12 · 激活函数家族

> 所属篇：第二篇 · 预计耗时：20 分钟

如果网络全是线性变换，100 层等于 1 层——因为线性组合的线性组合还是线性。激活函数就是给网络注入"非线性"，让它能拟合任意曲线。没有激活函数，深度学习就是个笑话。

---

## 为了什么（Why）

**核心痛点**：纯线性网络无论多少层都等价于单层，无法拟合非线性关系。

举个反例：假设你有一个 100 层的全连接网络，每层都是 `y = Wx + b`（没有激活函数）。那么第 1 层输出 `W₁x + b₁`，第 2 层输出 `W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)`……一直推到第 100 层，最终结果还是 **某个矩阵乘以 x 加上某个向量**——等价于只有 1 层！你白算了 99 层。

用纯线性网络去拟合 XOR？100 层也拟合不了，因为它本质上还是一条直线。

**这一章的目标**：掌握 5 种主流激活函数的公式、图像、导数和适用场景，知道什么时候该用哪个。

## 要做到（Goal）

- **输入**：任意实数 z（通常是上一层神经元的加权求和结果）。
- **输出**：变换后的值，且函数必须**非线性**、**（几乎处处）可导**。
- **成功标准**：能画出 5 种激活函数的大致形状，说出各自在什么场景下使用。

## 做了什么（What）

激活函数是神经网络中的"非线性开关"。如果把网络比作水管系统，那激活函数就是阀门——它决定信号能不能通过、通过后变成什么样。

5 种主流激活函数的"名片"：

| 函数 | 形状 | 输出范围 | 一句话定位 |
|------|------|---------|-----------|
| sigmoid | S 形曲线 | (0, 1) | 老牌选手，概率输出专用 |
| tanh | 更陡的 S 形 | (-1, 1) | 零中心版 sigmoid |
| ReLU | 折线（L 形） | [0, ∞) | 现代默认选择 |
| LeakyReLU | 斜折线 | (-∞, ∞) | ReLU 的改进版 |
| GELU | 平滑折线 | (~-0.17, ∞) | Transformer 的最爱 |

### 逐组件拆解

**sigmoid**：把任意数压缩到 (0, 1)。适合做二分类的概率输出。但两端容易"饱和"（梯度趋近于 0），深层网络中会导致梯度消失。

**tanh**：sigmoid 的零中心版本。输出范围 (-1, 1)，均值为 0，训练时收敛更快。但同样有饱和问题。

**ReLU**：最简单的非线性——正数原样放行，负数砍成 0。计算极快（就是一个 max 操作），不会饱和（正区梯度恒为 1）。但负区梯度恒为 0，可能导致"死亡神经元"。

**LeakyReLU**：ReLU 的修补版——负区给一个很小的斜率（通常 0.01），让负区也有微小梯度流动，避免神经元彻底死亡。

**GELU**：ReLU 的平滑版。在 0 附近不是硬拐角而是平滑过渡，梯度更稳定。BERT、GPT 等 Transformer 模型都在用它。

## 怎么算（How）

### 核心公式

**sigmoid**：
```
σ(z) = 1 / (1 + e^(-z))
σ'(z) = σ(z) · (1 - σ(z))     ← 这个性质超好用！
```

**tanh**：
```
tanh(z) = (e^z - e^(-z)) / (e^z + e^(-z))
tanh'(z) = 1 - tanh²(z)
```

**ReLU**：
```
ReLU(z) = max(0, z)
ReLU'(z) = 1    if z > 0
ReLU'(z) = 0    if z ≤ 0
```

**LeakyReLU**：
```
LeakyReLU(z) = max(α·z, z)    （通常 α = 0.01）
```

**GELU**（近似形式）：
```
GELU(z) ≈ 0.5 · z · (1 + tanh(√(2/π) · (z + 0.044715 · z³)))
```

### 数值小例子

#### 当 z = 2.0 时：

**sigmoid(2.0)**：
- e^(-2) ≈ 0.1353
- σ(2) = 1 / (1 + 0.1353) = 1 / 1.1353 = **0.8808**

**tanh(2.0)**：
- e^2 ≈ 7.389，e^(-2) ≈ 0.1353
- tanh(2) = (7.389 - 0.1353) / (7.389 + 0.1353) = 7.2537 / 7.5243 = **0.9640**

**ReLU(2.0)** = max(0, 2.0) = **2.0**

**LeakyReLU(2.0)** = max(0.01 × 2.0, 2.0) = max(0.02, 2.0) = **2.0**

#### 当 z = -1.0 时：

**sigmoid(-1.0)**：
- e^1 ≈ 2.7183
- σ(-1) = 1 / (1 + 2.7183) = 1 / 3.7183 = **0.2689**

**tanh(-1.0)** = **-0.7616**（奇函数，tanh(-z) = -tanh(z)）

**ReLU(-1.0)** = max(0, -1.0) = **0** ← 负区直接砍掉！

**LeakyReLU(-1.0)** = max(0.01 × (-1.0), -1.0) = max(-0.01, -1.0) = **-0.01** ← 负区保留了一点点

汇总表：

| z | sigmoid | tanh | ReLU | LeakyReLU |
|---|---------|------|------|-----------|
| 2.0 | 0.881 | 0.964 | 2.0 | 2.0 |
| -1.0 | 0.269 | -0.762 | 0 | -0.01 |

### sigmoid 导数的数值验证

这是反向传播中最重要的性质之一：**sigmoid 的导数可以用自身的值算出来，不需要再求一次指数**。

当 z = 2.0 时：
- σ(2) = 0.8808
- σ'(2) = σ(2) × (1 - σ(2)) = 0.8808 × (1 - 0.8808) = 0.8808 × 0.1192 = **0.1050**

用定义验证：`(σ(2.001) - σ(1.999)) / 0.002` ≈ 0.1050 ✅ 吻合！

这个性质让 sigmoid 的反向传播计算非常高效——前向传播时已经算出了 σ(z)，反向传播直接复用即可。

### "零中心"是什么意思？

你可能注意到上面表格里 tanh 的输出是 (-1, 1)，而 sigmoid 是 (0, 1)。这有什么区别？

**sigmoid 不是零中心的**：输出总是正数。这意味着所有传到下一层的梯度都是同号的（要么全正，要么全负），参数更新时会出现"之字形"路径——像醉汉走路一样左右摇摆，而不是直奔目标。

**tanh 是零中心的**：输出有正有负，均值接近 0。梯度也是正负交替的，参数更新方向更稳定，收敛更快。

类比：想象你在推一辆车。如果每次只能往前推（sigmoid），遇到需要往后调的方向时你得绕一大圈；如果能前后自由推（tanh），调整起来就快多了。

这就是为什么 tanh 在 RNN 等序列模型中更受欢迎，而 sigmoid 主要用于二分类的**输出层**（因为概率天然在 (0,1) 范围内）。

### GELU：Transformer 的选择

GELU（Gaussian Error Linear Unit）是 ReLU 的平滑版本。它在 z = 0 处不是尖锐的拐角，而是平滑过渡。这对 Transformer 很重要——因为 Transformer 很深，0 附近的梯度不稳定性会被逐层放大。

公式（精确形式）：
```
GELU(z) = z · Φ(z)
```
其中 Φ(z) 是标准正态分布的累积分布函数（CDF）。

实际实现常用上面的近似公式（误差 < 0.0001），计算效率更高。

```python
import numpy as np

def relu(z):      return np.maximum(0, z)
def sigmoid(z):   return 1 / (1 + np.exp(-np.clip(z, -500, 500)))
def leaky_relu(z): return np.where(z > 0, z, 0.01 * z)
def gelu(z):
    return 0.5 * z * (1 + np.tanh(np.sqrt(2/np.pi) * (z + 0.044715 * z**3)))

z = np.array([-2.0, -1.0, 0.0, 1.0, 2.0])
print(f"z       = {z}")
print(f"sigmoid = {sigmoid(z)}")
print(f"tanh    = {np.tanh(z)}")
print(f"ReLU    = {relu(z)}")
print(f"L-ReLU  = {leaky_relu(z)}")
print(f"GELU    = {gelu(z)}")
```

## 想多一点

> 为什么 Transformer 用 GELU 而不用 ReLU？
>
> 主要原因有三个：
> 1. **平滑性**：GELU 在 z = 0 处是平滑过渡的（二阶导连续），而 ReLU 在 0 处有一个不可导的尖角。对于很深的网络（Transformer 通常有几十层），这种不平滑性会在反向传播中被放大。
> 2. **非零负区**：GELU 对负输入不是简单归零，而是给出一个小的负值（比如 GELU(-1) ≈ -0.16）。这意味着即使某个神经元被"抑制"，信息也不会完全丢失。
> 3. **经验结果**：在 BERT、GPT 等大模型的实验中，GELU 比 ReLU 的最终效果略好。
>
> 当然，如果你在做 CNN 或简单的 MLP，ReLU 依然是性价比最高的选择——简单、快速、够用。

## 易错点预警

- ❌ 隐藏层全部使用 sigmoid，导致深层网络梯度消失（sigmoid 两端饱和，梯度趋近于 0，多层连乘后趋近于 0）→ ✅ 正确：隐藏层优先使用 ReLU 或 GELU，sigmoid 只用于二分类输出层。
- ❌ ReLU 学习率设置太大，导致大量神经元进入负区后永远无法恢复（"死亡 ReLU"问题）→ ✅ 正确：适当降低学习率，或改用 LeakyReLU/GELU 给负区保留梯度通路。
- ❌ 忘记 softmax 前面的 logits 不需要过激活函数（softmax 本身就包含类似 sigmoid 的压缩操作）→ ✅ 正确：分类任务的最后一层直接输出 logits，然后接 softmax（或交给 CrossEntropyLoss 内部处理）。

## 章末小结

| 函数 | 值域 | 导数特点 | 适用场景 |
|------|------|---------|---------|
| sigmoid | (0, 1) | σ' = σ(1-σ)，易饱和，梯度消失 | 二分类**输出层** |
| tanh | (-1, 1) | 零中心，仍易饱和 | RNN/LSTM 隐藏层 |
| ReLU | [0, ∞) | 正区恒为 1，负区为 0，极简 | CNN/MLP 隐藏层（首选） |
| LeakyReLU | (-∞, ∞) | 负区有小斜率 α | 解决死亡 ReLU 问题 |
| GELU | (~-0.17, ∞) | 平滑可导，非零负区 | Transformer（BERT/GPT） |
