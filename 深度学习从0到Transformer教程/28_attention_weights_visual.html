Attention 权重热力图 — 模型学会看哪里

Encoder 编码源序列「我 / 爱 / 自然语言」得到 3 个隐藏状态 h₁,h₂,h₃；Decoder 在每个时间步生成目标词时， 用当前状态 sₜ 与所有 hᵢ 计算分数 eₜᵢ = score(sₜ, hᵢ)，softmax 后得到 attention 权重 αₜᵢ。 点击下方不同 Decoder 步骤，观察权重分布如何随生成内容变化。

选择 Decoder 步骤：
权重低权重高 |　αₜᵢ 数值标注在每条连线上
eₜᵢ = score(sₜ, hᵢ)　→　αₜᵢ = softmax(eₜᵢ) = exp(eₜᵢ) / Σⱼ exp(eₜⱼ)　→　cₜ = Σᵢ αₜᵢ · hᵢ
点击上方按钮选择 Decoder 步骤
每个 Decoder 时间步对应不同的 attention 权重分布。本示例使用预设分数，模拟翻译「我爱自然语言 → I love NLP」时模型的对齐行为。
