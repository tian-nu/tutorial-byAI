# Ch03 · 概率论最小必要知识

> 所属篇：第零篇 · 预计耗时：20 分钟

天气预报说"明天降水概率 70%"，这个 70% 怎么来的？气象模型输出的是一堆分数，softmax 把它们变成"加起来等于 1"的概率。分类问题的最后一层永远有 softmax 的影子，而衡量"预测概率"和"真实标签"的差距用交叉熵。这两个概念是 Ch08 逻辑回归、Ch15 神经网络训练的核心，搞不懂它们，损失函数对你就是天书。

---

## 为了什么（Why）

**核心痛点**：分类问题要输出概率；衡量"预测概率"和"真实标签"的差距用交叉熵；不懂概率论看不懂 Ch08 逻辑回归的损失函数。

举个反例：Ch08 逻辑回归的损失函数是 `-Σ y·log(p)`。如果你不懂：
- `p` 是 softmax 把分数压成的概率
- `y` 是 one-hot 编码的真实标签
- `log` 是用来"惩罚自信的错误"

那这个公式对你就是一堆符号。你会问：为什么不用平方误差？为什么要 log？为什么前面有负号？这一章把这些问题全解答了。

**这一章的目标**：让你看到 `softmax(z)` 时脑子里能浮现"分数变概率"，看到 `cross_entropy(y, p)` 时能浮现"预测越准交叉熵越小"。

## 要做到（Goal）

- **输入**：高中数学（知道什么是概率、什么是 log）。
- **输出**：理解概率分布、期望、方差、交叉熵、softmax、one-hot。
- **成功标准**：给定 `logits = [2.0, 1.0, 0.1]`，能手算 softmax 后约等于 `[0.66, 0.24, 0.10]`；能解释交叉熵为什么用 log。

## 做了什么（What）

概率论在深度学习里主要用五个概念：

```
概率分布（各概率和为1）
   │
   ├──> 期望（加权平均）
   │         │
   │         └──> 方差（偏离期望的程度）
   │
   └──> softmax（把任意分数压成概率分布）
             │
             └──> 交叉熵（衡量预测概率与真实标签的差异）
                     │
                     └──> one-hot（真实标签的编码方式）
```

### 逐组件拆解

**概率分布（Probability Distribution）**：每个可能值的概率，总和为 1。比如骰子的概率分布是 `[1/6, 1/6, 1/6, 1/6, 1/6, 1/6]`，加起来等于 1。

**期望（Expectation）**：加权平均。**赌场比喻**：抛硬币赌 10 元，正面赢 10 元反面输 10 元，期望是 0（长期玩不赚不赔）。

**方差（Variance）**：偏离期望的程度。方差大 = 结果波动大。**投资比喻**：股票方差大（大起大落），国债方差小（稳定收益）。

**softmax**：把任意实数向量"压"成概率分布的函数。**分数变概率比喻**：考试 3 科分数 `[90, 80, 70]`，softmax 把它们变成"哪科最强的置信度"，加起来等于 1。

**交叉熵（Cross-Entropy）**：衡量两个分布的差异。**惩罚比喻**：你预测"明天 99% 不下雨"，结果下了雨，交叉熵狠狠罚你；你预测"50% 下雨"，结果下了雨，罚得轻一些。

**one-hot 编码**：真实标签的表示方式。3 类分类中，真实类别是第 0 类，one-hot 就是 `[1, 0, 0]`；是第 2 类就是 `[0, 0, 1]`。**独热比喻**：只有一个位置是 1（热），其他全是 0（冷）。

## 怎么算（How）

### 1. 期望与方差

公式：
- 期望：`E[X] = Σ p_i × x_i`
- 方差：`Var(X) = E[(X - E[X])²]`

**数值小例子**（骰子）：

- `E[X] = (1/6)×1 + (1/6)×2 + (1/6)×3 + (1/6)×4 + (1/6)×5 + (1/6)×6`
  - `= (1 + 2 + 3 + 4 + 5 + 6) / 6`
  - `= 21 / 6`
  - `= 3.5`

注意：期望 3.5 不是骰子的任何一面——期望不一定是可能值。

- `Var(X) = E[(X - 3.5)²]`
  - `= (1/6)×[(1-3.5)² + (2-3.5)² + (3-3.5)² + (4-3.5)² + (5-3.5)² + (6-3.5)²]`
  - `= (1/6)×[6.25 + 2.25 + 0.25 + 0.25 + 2.25 + 6.25]`
  - `= 17.5 / 6`
  - `≈ 2.9167`

### 2. softmax

公式：`p_i = exp(z_i) / Σ_j exp(z_j)`

**数值小例子**：

设 `z = [2.0, 1.0, 0.1]`。

**第 1 步：算每个 exp**
- `exp(2.0) = 7.389`
- `exp(1.0) = 2.718`
- `exp(0.1) = 1.105`

**第 2 步：求和**
- `sum = 7.389 + 2.718 + 1.105 = 11.212`

**第 3 步：归一化**
- `p_0 = 7.389 / 11.212 = 0.659`
- `p_1 = 2.718 / 11.212 = 0.242`
- `p_2 = 1.105 / 11.212 = 0.099`

所以 `softmax([2.0, 1.0, 0.1]) = [0.659, 0.242, 0.099]`，加起来 `0.659 + 0.242 + 0.099 = 1.000` ✅。

**直觉**：z 里最大的 2.0 对应的概率最大（0.659），最小的 0.1 对应的概率最小（0.099）。softmax 把"分数差距"放大成了"概率差距"。

### 3. 交叉熵

公式：`H(y_true, y_pred) = -Σ y_true_i × log(y_pred_i)`

**数值小例子**：

设真实标签 `y_true = [1, 0, 0]`（one-hot，表示真实类别是第 0 类），预测概率 `y_pred = [0.659, 0.242, 0.099]`（上面 softmax 的结果）。

逐步计算：
- 第 0 项：`1 × log(0.659) = 1 × (-0.417) = -0.417`
- 第 1 项：`0 × log(0.242) = 0`（one-hot 把非真实类别的项清零了）
- 第 2 项：`0 × log(0.099) = 0`
- 求和：`-0.417 + 0 + 0 = -0.417`
- 加负号：`H = -(-0.417) = 0.417`

所以交叉熵 `H = 0.417`。

**one-hot 的妙处**：因为 one-hot 只有一个 1，其余全是 0，所以交叉熵实际上只算"真实类别那一项的 -log(p)"。公式简化为 `H = -log(p_真实类别)`。

### 4. 为什么交叉熵用 log？

这是模拟读者反馈的中度缺口，必须想清楚。

**原因 1：log 对"自信的错误"施以重罚**。

看 `y_true = [1, 0, 0]`（真实是第 0 类），预测概率 `p_0` 不同时的 `-log(p_0)`：

| 预测概率 p_0 | -log(p_0) | 含义 |
|--------------|-----------|------|
| 0.99 | 0.01 | 几乎确定是对，惩罚极小 |
| 0.5 | 0.69 | 一半一半，惩罚中等 |
| 0.1 | 2.30 | 自信地错了，惩罚大 |
| 0.01 | 4.61 | 非常自信地错了，惩罚巨大 |
| 0.001 | 6.91 | 极端自信地错了，惩罚爆炸 |

`log` 在 `p → 0` 时趋向 `-∞`，所以 `-log(p)` 在 `p → 0` 时趋向 `+∞`。这意味着：**你越自信地把真实类别预测成低概率，惩罚越重**。这正是我们想要的——"自信的错误"比"犹豫的错误"更该罚。

**原因 2：与最大似然估计（MLE）数学等价**。

假设样本独立同分布，所有样本的联合概率是各样本概率的乘积。取 log 把乘法变加法（便于求导优化），就得到 `-Σ log(p_真实类别)`，正好是交叉熵。所以最小化交叉熵 = 最大似然估计，有严格的统计学依据。

**为什么不用平方误差？** 因为平方误差对 softmax 输出求导时，梯度会消失（当预测已经接近 0 或 1 时梯度几乎为 0），学不动。交叉熵配 softmax 的梯度是 `p - y`，形式简洁且不会消失，这是深度学习用交叉熵而不平方误差的根本原因。

```python
import numpy as np

# 数值稳定的 softmax（必学技巧）
def softmax_stable(z):
    z = np.asarray(z, dtype=np.float64)
    z_max = np.max(z)            # 减最大值防溢出
    e = np.exp(z - z_max)
    return e / e.sum()

z = np.array([2.0, 1.0, 0.1])
print(softmax_stable(z))   # [0.659 0.242 0.099]
```

## 想多一点

> 为什么 softmax 要除以 exp 的总和，而不是直接除以总和？
>
> 提示：`z / sum(z)` 也能让结果和为 1，但它处理不了负数（负数除以总和还是负数，不是概率）。`exp` 保证非负，且放大差异——`z=[2,1,0]` 直接归一化得 `[0.67, 0.33, 0]`，softmax 得 `[0.67, 0.24, 0.09]`，softmax 让大概率更突出、小概率不至于为 0，更适合分类。

## 易错点预警

- ❌ softmax 直接算 `exp(1000)` 溢出得到 `nan` → ✅ 正确：先减最大值 `exp(z - max(z))`。数学上完全等价，但让 exp 的输入都 ≤ 0，不会溢出。
- ❌ 交叉熵用 `log(0)` 报错（预测概率为 0 时） → ✅ 正确：给预测概率加小常数 `p = max(p, 1e-15)`，或用 `np.clip(p, 1e-15, 1.0)`。
- ❌ 把 one-hot 和 softmax 搞混 → ✅ 正确：one-hot 是**真实标签**的表示（整数 0/1，人为指定），softmax 是**模型预测**的输出（0~1 之间的浮点数，加起来为 1）。交叉熵就是衡量这两者的差距。

## 章末小结

| 概念 | 一句话解释 | 易错点 |
|------|-----------|--------|
| 概率分布 | 各概率总和为 1 | 概率不能为负，不能大于 1 |
| 期望（Expectation） | 加权平均 | 期望不一定是可能值（骰子期望 3.5） |
| 方差（Variance） | 偏离期望的程度 | 方差是平方，单位与原变量不同 |
| softmax | 把分数压成概率 | 减最大值防溢出 |
| one-hot | 真实标签的编码，只有一个 1 | 不是模型输出，是人为指定的标签 |
| 交叉熵（Cross-Entropy） | 衡量预测概率与真实标签的差异 | 预测越准交叉熵越小，用 log 惩罚自信的错误 |
| 数值稳定技巧 | softmax 减最大值 | 不减会溢出，减了结果不变 |
