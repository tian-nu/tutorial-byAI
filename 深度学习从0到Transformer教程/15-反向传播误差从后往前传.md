# Ch15 · 反向传播 — 误差从后往前传

> 所属篇：第二篇 · 预计耗时：35 分钟

前向传播是"做题"，反向传播是"对答案改错"。你做错了一道题，老师告诉你"你第 3 步算错了"，你就知道去改第 3 步的计算。反向传播就是让网络知道**每个参数该为误差负多少责任**——误差大的参数多调一点，没责任的参数不动。这是深度学习能训练百万级参数的核心算法。

---

## 为了什么（Why）

**核心痛点**：网络有上百万个参数，手动算每个参数的梯度不现实；需要一个高效算法自动算所有梯度。

举个反例：用数值梯度（有限差分法）算 100 万个参数的梯度，每个参数要跑两次前向传播（加 ε 和减 ε），总共要跑 200 万次前向传播。而反向传播只需要 **1 次前向 + 1 次反向** 就能得到所有参数的梯度。速度快了约 100 万倍。

**这一章的目标**：理解反向传播的数学原理（链式法则）、手算完整梯度、并用数值梯度验证正确性。

## 要做到（Goal）

- **输入**：前向传播的所有中间值（z⁽ˡ⁾, a⁽ˡ⁾）和损失 L。
- **输出**：所有参数的梯度 ∂L/∂W⁽ˡ⁾, ∂L/∂b⁽ˡ⁾。
- **成功标准**：手算的解析梯度与数值梯度的误差 < 1e-7。

## 做了什么（What）

反向传播的过程就像"追责"——从损失出发，一层层往回问：

```
损失 L = 1.5
    │
    ▼ "谁导致的？"
输出层误差 δ³ = ∂L/∂z⁽³⁾   ← 输出层该负多大责任？
    │
    ▼ "传给上一层"
隐藏层误差 δ² = (W₃ᵀ·δ³) ⊙ σ'(z²)  ← 隐藏层被连累了多少？
    │
    ▼ "继续往前传"
隐藏层误差 δ¹ = (W₂ᵀ·δ²) ⊙ σ'(z¹)
    │
    ▼ "落实到具体参数"
∂L/∂W₂ = δ² · (a¹)ᵀ          ← W₂ 的每个元素该调多少？
∂L/∂b₂ = δ²                   ← b₂ 该调多少？
```

### 逐组件拆解

**δ（Delta / 误差信号）**：每一层的"责任分数"。表示"如果这层的 z 变化一点点，最终损失会变化多少"。δ 越大，说明这层对误差的贡献越大。

**链式法则的反向应用**：正向是 `L → z⁽³⁾ → a⁽²⁾ → z⁽²⁾ → ...`，反向就是 `L ← z⁽³⁾ ← a⁽²⁾ ← z⁽²⁾ ← ...`。每一步都乘以局部导数。

**计算图（Computational Graph）**：把前向传播画成一张有向无环图（节点=操作，边=数据流）。反向传播就是在这张图上从输出节点往回遍历，每经过一条边就乘以这条边代表的偏导数。PyTorch 的 `autograd` 就是这个过程的自动化实现。

## 怎么算（How）

### 核心公式（接 Ch14 的网络）

我们继续使用 Ch14 的网络和前向结果：
- x = [1.0, 0.5, -1.0]
- W₁ (4×3), b₁ (4,) → z⁽¹⁾ = [2.0, -0.5, -0.5, 0.5], a⁽¹⁾ = [2.0, 0, 0, 0.5]
- W₂ (2×4), b₂ (2,) → z⁽²⁾ = [2.5, 0], ŷ = [0.924, 0.076]

真实标签 y = [1, 0]（第 1 类）

#### 第 1 步：输出层误差 δ³

当损失函数是**交叉熵 + softmax** 时，有一个非常漂亮的简化：

```
δ³ = ŷ - y
```

**为什么？** （这是很多人卡住的地方）

softmax + 交叉熵的联合梯度推导：
- 交叉熵损失：L = -Σ yᵢ log(ŷᵢ)
- softmax 输出：ŷᵢ = e^(zᵢ) / Σⱼ e^(zⱼ)
- 经过求导化简后：∂L/∂zᵢ = ŷᵢ - yᵢ

直觉理解：如果预测概率 ŷᵢ 大于真实标签 yᵢ（预测过高），梯度为正，需要减小 zᵢ；反之亦然。差值越大，调整幅度越大。

**数值计算**：
```
δ³ = ŷ - y = [0.924 - 1, 0.076 - 0] = [-0.076, 0.076]
```

含义：第 1 个输出神经元预测偏高（0.924 > 真实值 1 的差距为 -0.076），第 2 个预测偏高（0.076 > 真实值 0 的差距为 +0.076）。

#### 第 2 步：误差反传到隐藏层 δ¹

我们的网络只有两层（一个隐藏层 + 一个输出层），所以直接把 δ³ 往回传到隐藏层：

```
δ¹ = (W₂ᵀ · δ³) ⊙ ReLU'(z⁽¹⁾)
```

这里有两个操作：

**(a) W₂ᵀ · δ³ — 通过权重矩阵反传**

W₂ 是 (2×4)，转置后 W₂ᵀ 是 (4×2)：
```
W₂ᵀ = [[1,  0],   ← 原 W₂ 第 0 列
       [0,  1],   ← 原 W₂ 第 1 列
       [0,  1],   ← 原 W₂ 第 2 列
       [1,  0]]   ← 原 W₂ 第 3 列
```

W₂ᵀ · δ³（(4×2) @ (2,) = (4,)）：
- 第 1 个元素：1×(-0.076) + 0×0.076 = **-0.076**
- 第 2 个元素：0×(-0.076) + 1×0.076 = **0.076**
- 第 3 个元素：0×(-0.076) + 1×0.076 = **0.076**
- 第 4 个元素：1×(-0.076) + 0×0.076 = **-0.076**

结果：**[-0.076, 0.076, 0.076, -0.076]**

**(b) ⊙ ReLU'(z⁽¹⁾) — 乘激活函数导数**

ReLU 导数规则：z > 0 时导数为 1，z ≤ 0 时导数为 0。

z⁽¹⁾ = [2.0, -0.5, -0.5, 0.5]，所以：
```
ReLU'(z⁽¹⁾) = [1, 0, 0, 1]
```

逐元素相乘（⊙ 表示 Hadamard 积）：
```
δ¹ = [-0.076×1, 0.076×0, 0.076×0, -0.076×1]
   = [-0.076, 0, 0, -0.076]
```

注意！第 2、3 个隐藏神经元的 δ 变成了 0——因为它们在前向传播时被 ReLU 关掉了（输入是负数），所以它们"不背锅"。

#### 第 3 步：计算参数梯度

**∂L/∂W₂（输出层权重的梯度）**：

```
∂L/∂W₂ = δ³ · (a⁽¹⁾)ᵀ     → shape: (2,) outer (4,) = (2, 4)
```

外积展开（δ³ 有 2 个元素，a⁽¹⁾ 有 4 个元素，结果 2×4 矩阵）：

| | a₁=2.0 | a₂=0 | a₃=0 | a₄=0.5 |
|--|--------|------|-----|--------|
| δ₃[0]=-0.076 | -0.152 | 0 | 0 | -0.038 |
| δ₃[1]=0.076 | 0.152 | 0 | 0 | 0.038 |

关键值：
- `∂L/∂W₂[0][0] = -0.076 × 2.0 = -0.152`
- `∂L/∂W₂[0][3] = -0.076 × 0.5 = -0.038`

shape: **(2, 4)** ✅ 与 W₂ 形状一致！

**∂L/∂b₂（输出层偏置的梯度）**：

```
∂L/∂b₂ = δ³ = [-0.076, 0.076]
```

shape: **(2,)** ✅ 与 b₂ 形状一致！

**∂L/∂W₁（隐藏层权重的梯度）**：

```
∂L/∂W₁ = δ¹ · xᵀ      → shape: (4,) outer (3,) = (4, 3)
```

外积展开：

| | x₁=1.0 | x₂=0.5 | x₃=-1.0 |
|--|--------|-------|---------|
| δ¹[0]=-0.076 | -0.076 | -0.038 | 0.076 |
| δ¹[1]=0 | 0 | 0 | 0 |
| δ¹[2]=0 | 0 | 0 | 0 |
| δ¹[3]=-0.076 | -0.076 | -0.038 | 0.076 |

shape: **(4, 3)** ✅ 与 W₁ 形状一致！

**∂L/∂b₁（隐藏层偏置的梯度）**：

```
∂L/∂b₁ = δ¹ = [-0.076, 0, 0, -0.076]
```

shape: **(4,)** ✅ 与 b₁ 形状一致！

### 完整梯度汇总

| 参数 | 梯度 | Shape | 是否匹配参数形状 |
|------|------|-------|----------------|
| W₂ | 见上表 | (2, 4) | ✅ W₂ 也是 (2,4) |
| b₂ | [-0.076, 0.076] | (2,) | ✅ b₂ 也是 (2,) |
| W₁ | 见上表 | (4, 3) | ✅ W₁ 也是 (4,3) |
| b₁ | [-0.076, 0, 0, -0.076] | (4,) | ✅ b₁ 也是 (4,) |

### 数值梯度验证

解析梯度算得再漂亮，也可能有 bug。**数值梯度**是用定义来验证的金标准：

```
∂L/∂w ≈ (L(w+ε) - L(w-ε)) / (2ε)
```

以 W₁[0,0] 为例（扰动 ±1e-5）：

```python
eps = 1e-5
# 1. 计算 L(W₁[0,0] + eps)
W1_save = W1[0, 0].copy()
W1[0, 0] += eps
loss_plus = compute_loss(x, y, W1, b1, W2, b2)

# 2. 计算 L(W₁[0,0] - eps)
W1[0, 0] = W1_save - 2*eps  # 从原值减 eps（因为之前加了 eps）
loss_minus = compute_loss(x, y, W1, b1, W2, b2)

# 3. 数值梯度
num_grad = (loss_plus - loss_minus) / (2*eps)

# 4. 恢复原值
W1[0, 0] = W1_save
```

预期结果：解析梯度 ≈ -0.076，数值梯度 ≈ -0.076，差值 < 1e-7 ✅

## 怎么用（Use）

代码文件：`深度学习从0到Transformer教程/code/ch15_backpropagation.py`

关键片段：

```python
import numpy as np

def compute_loss(x, y, W1, b1, W2, b2):
    """完整的前向传播 + 交叉熵损失（用于数值梯度验证）"""
    # 前向传播（与 Ch14 一致）
    z1 = W1 @ x + b1
    a1 = np.maximum(0, z1)           # ReLU
    z2 = W2 @ a1 + b2
    # Softmax
    exp_z2 = np.exp(z2 - np.max(z2))
    y_hat = exp_z2 / np.sum(exp_z2)
    # 交叉熵损失
    loss = -np.sum(y * np.log(y_hat + 1e-8))
    return loss

# === 前向传播（复用 Ch14 结果）===
x = np.array([1.0, 0.5, -1.0])
y = np.array([1, 0])
# ... W1, b1, W2, b2 同 Ch14 ...
z1 = W1 @ x + b1
a1 = np.maximum(0, z1)
z2 = W2 @ a1 + b2
exp_z2 = np.exp(z2 - np.max(z2))
y_hat = exp_z2 / np.sum(exp_z2)

# === 反向传播 ===
delta3 = y_hat - y              # 输出层误差 (2,)
dW2 = np.outer(delta3, a1)      # (2,4)
db2 = delta3.copy()             # (2,)
da1 = W2.T @ delta3             # (4,)
dz1 = da1 * (z1 > 0).astype(float)  # ReLU' (4,)
dW1 = np.outer(dz1, x)          # (4,3)
db1 = dz1.copy()                # (4,)

# === 数值梯度验证 ===
eps = 1e-5
W1_orig = W1[0, 0].copy()
W1[0, 0] += eps;  loss_plus = compute_loss(x, y, W1, b1, W2, b2)
W1[0, 0] -= 2*eps; loss_minus = compute_loss(x, y, W1, b1, W2, b2)
W1[0, 0] = W1_orig
num_grad = (loss_plus - loss_minus) / (2*eps)
print(f"analytic dW1[0,0]={dW1[0,0]:.6f}, numeric={num_grad:.6f}")
```

## 想多一点

> 为什么反向传播比数值梯度快这么多？
>
> **数值梯度**：对每个参数 wᵢ，都要算 `(L(wᵢ+ε) - L(wᵢ-ε)) / 2ε`。这意味着每次要跑一次完整的前向传播（可能涉及几十亿次的乘加运算）。如果有 N 个参数，就要跑 2N 次前向传播。
>
> **反向传播**：只跑 **1 次前向 + 1 次反向**。反向传播利用了链式法则的共享计算——中间结果（如 a⁽¹⁾, z⁽¹⁾）在计算不同参数的梯度时可以重复使用。复杂度与前向传播同级 O(n)，其中 n 是网络的总运算量。
>
> 具体数字：假设网络有 100 万个参数，前向传播耗时 1ms：
> - 数值梯度：200 万次前向 = 2000 秒（33 分钟）
> - 反向传播：1 次前向 + 1 次反向 ≈ 2ms
>
> 快了约 **100 万倍**。这就是为什么反向传播被称为深度学习的"引擎"。

## 易错点预警

- ❌ 忘记在误差反传时乘以激活函数的导数（即漏掉了 `⊙ σ'(z⁽ˡ⁾)` 这一步）→ ✅ 正确：**每一层的 δ 都必须乘以该层激活函数的导数**，公式为 `δ⁽ˡ⁾ = (W⁽ˡ⁺¹⁾ᵀ · δ⁽ˡ⁺¹⁾) ⊙ σ'(z⁽ˡ⁾)`。漏掉这一步会导致梯度完全错误。
- ❌ 梯度的形状与参数的形状不匹配（比如 `dW.shape != W.shape`）→ ✅ 正确：`dW` 的 shape 必须等于 `W` 的 shape。用 `np.outer(delta, a)` 计算权重梯度时，注意两个向量的顺序——第一个是"下游误差"，第二个是"上游激活值"。顺序搞反了 shape 就会变成转置。
- ❌ 数值梯度验证时忘记恢复被扰动的参数值→ ✅ 正确：每次扰动参数（`w += eps` 和 `w -= 2*eps`）之后必须恢复原值（`w = original`），否则后续的验证全部基于错误的基础值。

## 章末小结

| 概念 | 一句话解释 | 易错点 |
|------|-----------|--------|
| 反向传播（Backprop） | 链式法则在计算图上的工程实现 | 方向是从输出层**往回**传，别搞反 |
| δ（误差信号） | 损失对该层 z 的偏导数 | 每层都要**乘以激活函数的导数** |
| 链式法则 | ∂L/∂w = (∂L/∂z) × (∂z/∂w)，复合函数求导 | 多层嵌套时逐步分解，不要跳步 |
| 计算图 | 前向传播的有向无环图（DAG） | 反向传播就是在图上做拓扑排序的逆序遍历 |
| 自动微分（autograd） | 框架自动完成反向传播 | PyTorch 的 `loss.backward()` 就是调用它 |
| 数值梯度验证 | 用差分法定义验证解析梯度的正确性 | **开发阶段必做**，上线前可去掉 |
| softmax+CE 梯度 | δ = ŷ - y，极简形式 | 只在 softmax 接交叉熵时成立，其他组合不适用 |
