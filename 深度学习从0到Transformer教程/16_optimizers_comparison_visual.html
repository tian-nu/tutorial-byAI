优化器对比 — 四种优化器在损失曲面上的下降轨迹

损失曲面是一条倾斜的狭长山谷 L = (x−3)² + 10·(y−0.6x)²（谷底在 (3, 1.8)）。 四个点从同一起点 (−3, 4) 出发，分别用 SGD / Momentum / RMSprop / Adam 下降。 观察：SGD 在窄谷中来回抖动；Momentum 用惯性平滑加速；RMSprop 自适应步长；Adam 兼具两者，直奔谷底。
