# Ch22 · 为什么 RNN 记不住长序列

> 所属篇：第四篇 · 预计耗时：20 分钟

你让 RNN 背一首诗，它背到第3句就忘了第1句。这不是它笨，是它的记忆机制有结构性缺陷。要修这个缺陷，得先搞清楚病根在哪。上一章（Ch21）我们已经从数学上看到 RNN 的梯度连乘会消失或爆炸，这一章我们换一个视角——从"记忆的结构"看 RNN 为什么记不住长序列，为下一章引出 LSTM 的门控思想做准备。

---

## 为了什么（Why）

**核心痛点**：RNN 在长序列上失效，需要分析其记忆机制的本质缺陷，而不只是看梯度公式。

举个反例：句子"我出生在法国……（100 词后）……我会说法语"。RNN 读到"法语"时，理论上应该想起 100 步前的"法国"，但它的隐藏状态已经被中间 100 个词的信息覆盖殆尽，"法国"早就被冲刷干净了。结果就是模型根本无法把"法国"和"法语"这两条本该关联的信息搭上桥。

**这一章的目标**：理解 RNN 记忆机制的三大结构性缺陷，能解释为什么 RNN 记不住 100 步前的信息。

> 📌 **与 Ch21 的边界**：Ch21 聚焦"梯度连乘的数学根源"——用矩阵元素值分析 ∂L/∂h₁ 为什么趋近 0；Ch22 聚焦"信息瓶颈和记忆覆盖的结构性缺陷"——从 RNN 的更新公式结构看为什么信息会被冲掉。两章是同一病根的两个侧面，本章为 Ch23 引入门控思想铺路。

## 要做到（Goal）

- **输入**：RNN 的隐藏状态更新公式 `hₜ = tanh(W_xh·xₜ + W_hh·hₜ₋₁)`，以及 Ch21 的梯度流分析结论。
- **输出**：理解 RNN 记忆机制的三大本质缺陷（记忆覆盖、梯度连乘、信息瓶颈）。
- **成功标准**：能用自己的话解释为什么 RNN 记不住 100 步前的信息，并说出"特征值"在这个分析里扮演什么角色。

## 做了什么（What）

RNN 的记忆像一块黑板，每步都被擦掉重写。具体看三大缺陷：

```
缺陷1：记忆覆盖              缺陷2：梯度连乘              缺陷3：信息瓶颈
hₜ = tanh(W_xh·xₜ + W_hh·hₜ₋₁)   ∂L/∂h₁ ≈ ∏(W_hh·tanh')      所有历史信息都压
每步都重写 hₜ               T 步连乘，T 大时趋近 0        在固定大小的 hₜ 里
旧信息被新信息覆盖           梯度反传不回去                固定容量装不下长序列
```

### 逐组件拆解

**记忆覆盖**：RNN 的隐藏状态 `hₜ = tanh(W_xh·xₜ + W_hh·hₜ₋₁)`，每一步都用当前输入 `xₜ` 和上一步状态 `hₜ₋₁` 算出一个新值，**整个** `hₜ` 都被重写。`tanh` 还会把值压到 [-1, 1]，进一步削弱旧信息。旧信息没有"保险箱"可以躲，每步都被动地被新信息稀释、覆盖。

**梯度连乘**：反向传播时，梯度要从 `h_T` 一路传回 `h_1`，公式是 `∂L/∂h₁ ≈ ∏ₜ₌₁ᵀ (W_hh · tanh'(zₜ))`。每一项都包含一个 `W_hh` 和一个 `tanh'`，T 步连乘下来，要么趋近 0（梯度消失），要么趋近 ∞（梯度爆炸）。Ch21 已用矩阵元素值分析过这个现象，本章用更严格的"特征值"重新审视。

**信息瓶颈**：无论序列多长（10 词还是 10000 词），RNN 都把所有历史信息压缩进一个**固定大小**的 `hₜ` 向量。序列越长，要装的信息越多，但 `hₜ` 的维度不变——就像一个固定大小的背包要装下整个仓库的货，必然丢东西。

## 怎么算（How）

### 核心公式

```
∂L/∂h₁ ≈ ∏ₜ₌₁ᵀ (W_hh · tanh'(zₜ))
```

T 步连乘，每一项是"权重矩阵 W_hh 乘以 tanh 的导数"。

### 关键概念：特征值（Eigenvalue）

> 📌 **重要澄清（模拟读者反馈缺口）**：上一章 Ch21 我们用"矩阵元素值"（如 0.5）来粗略估计 W_hh 的缩放效果。这里我们要用更严格的工具——**特征值**。
>
> **矩阵元素值 vs 特征值**：
> - **矩阵元素值**（如 W_hh[0,0]=0.5）：只是矩阵里的一个数，不能反映矩阵对向量的整体作用。
> - **特征值**（如 λ=0.9）：衡量矩阵对**特定方向**上向量的整体缩放程度。如果一个矩阵的最大特征值是 0.9，意味着任何向量被它乘一次，长度最多乘 0.9（在那个方向上）。
>
> **直觉**：把矩阵想象成一个"变形器"，它会把向量拉长或压扁。特征值就是"在某个方向上拉长/压扁的倍数"。最大特征值决定了矩阵对向量的"最强缩放能力"。
>
> **为什么用特征值**：分析梯度连乘时，我们要看"梯度向量经过 T 次 W_hh 变换后会变成什么样"。特征值恰好能回答这个问题——如果 W_hh 的特征值是 0.9，每经过一次 W_hh，向量在那个方向上长度乘 0.9；T 次后乘 0.9^T。这比"看矩阵某个元素是 0.5"严谨得多。

### 数值小例子：梯度随时间步衰减

假设：
- W_hh 的最大特征值 = 0.9（意味着每经过一次 W_hh，向量在那个方向最多乘 0.9）
- tanh 的导数 tanh'(zₜ) 平均取 0.5（tanh 在 0 附近导数为 1，在饱和区趋近 0，平均按 0.5 估）

那么每一步梯度乘上：`0.9 × 0.5 = 0.45`

T 步连乘后：

| T（时间步） | 梯度 (0.45)^T | 说明 |
|------------|--------------|------|
| 5          | 0.45⁵ = 1.85e-2 | 还有点信号 |
| 10         | 0.45¹⁰ = 3.41e-4 | 信号很弱 |
| 20         | 0.45²⁰ = 1.16e-7 | 几乎没了 |
| 50         | 0.45⁵⁰ = 4.58e-18 | **完全消失**（计算机浮点数下溢） |
| 100        | 0.45¹⁰⁰ = 2.10e-35 | 比 float32 精度还小 |

**结论**：50 步前的信息对梯度的贡献已经是 4.58e-18——这个数小到连 64 位浮点数都表示不出来，实际上等于 0。所以"我出生在法国"经过 100 词后，模型在反向传播时根本无法把"法语"的误差信号传回"法国"那一步。

### 三大缺陷的因果关系

```
RNN 的更新公式 hₜ = tanh(W_xh·xₜ + W_hh·hₜ₋₁)
        │
        ├─→ 缺陷1：hₜ 每步被重写 → 旧信息被覆盖（前向视角）
        │
        ├─→ 缺陷2：梯度 ∏(W_hh·tanh') 连乘 → 反传不回去（反向视角）
        │
        └─→ 缺陷3：hₜ 维度固定 → 装不下长序列（容量视角）
```

这三个缺陷是同一病根（hₜ 既存历史又参与下一步计算）的三个侧面。要解决，得换一种记忆机制——这就是下一章 LSTM 的"门控"思想要做的。

## 怎么用（Use）

代码文件：`深度学习从0到Transformer教程/code/ch22_rnn_long_dependency.py`

关键片段：

```python
import numpy as np

# === 模拟梯度随时间步衰减 ===
# W_hh 的最大特征值 = 0.9（每经过一次 W_hh，向量长度最多乘 0.9）
W_hh_eigenvalue = 0.9
# tanh 的导数平均取 0.5
tanh_deriv = 0.5

print("=== RNN 梯度随时间步衰减 ===")
print(f"每步缩放因子 = W_hh 特征值 × tanh' = {W_hh_eigenvalue} × {tanh_deriv} = {W_hh_eigenvalue * tanh_deriv}")
print()
for T in [5, 10, 20, 50, 100]:
    grad = (W_hh_eigenvalue * tanh_deriv) ** T
    print(f"T={T:3d} 步: 梯度 = {grad:.2e}")

# === 对比：如果 W_hh 特征值 = 1.1（>1）会怎样？===
print()
print("=== 如果 W_hh 特征值 = 1.1（梯度爆炸）===")
W_hh_eigenvalue_big = 1.1
for T in [5, 10, 20, 50, 100]:
    grad = (W_hh_eigenvalue_big * tanh_deriv) ** T
    print(f"T={T:3d} 步: 梯度 = {grad:.2e}")
```

可以看到：特征值 < 1 时梯度指数衰减（消失）；特征值 > 1 时虽然 tanh'（0.5）把它压到 0.55 仍在衰减，但只要 W_hh 特征值更大（比如 2.5，使 2.5×0.5=1.25>1）就会爆炸。RNN 的基因缺陷在于：无论特征值怎么选都有问题——选小了消失，选大了爆炸。

## 想多一点

> 能不能通过增大 W_hh 的特征值来解决梯度消失？
>
> 答案：**不能**，会按下葫芦浮起瓢。
>
> - 特征值 < 1：梯度消失（前面分析的情况）
> - 特征值 = 1：理论上梯度不衰减，但 tanh 的导数还是会乘进去（tanh' 在饱和区趋近 0），所以仍会衰减
> - 特征值 > 1：梯度爆炸——前向时 `hₜ` 也会指数增长，被 tanh 压成 ±1 后丢失区分度；反向时梯度变成 NaN
>
> 这就是 RNN 的"基因缺陷"：W_hh 的特征值无论怎么选都有问题。要根治，必须改变记忆的更新方式——从"乘法链"改成"加法链"。这就是 LSTM 的核心思想，下一章详谈。
>
> 顺带一提：实际工程中常用的"梯度裁剪"（Gradient Clipping）只是给爆炸情况贴个创可贴——把梯度强行截断到一个上限，治标不治本。消失问题它根本管不了。

## 易错点预警

- ❌ **错误**：认为增大 W_hh 能解决梯度消失。→ ✅ **正确**：W_hh 特征值 > 1 会导致梯度爆炸，且前向时 hₜ 会发散（被 tanh 压成 ±1 后丢失区分度）。RNN 的基因缺陷在于"乘法更新"本身，调参数治不了。
- ❌ **错误**：认为加更多 RNN 层能解决长依赖问题。→ ✅ **正确**：层数越多，梯度连乘的链越长，梯度消失越严重。深层 RNN 比浅层 RNN 更难训练，不是更容易。
- ❌ **错误**：把"矩阵元素值"和"特征值"混为一谈，看到 `W_hh[0,0]=0.5` 就说"梯度每步乘 0.5"。→ ✅ **正确**：矩阵对向量的整体缩放要用**特征值**衡量，单个元素值不能代表整体。分析梯度连乘务必用特征值。

## 章末小结

| 概念 | 一句话解释 | 易错点 |
|------|-----------|--------|
| 记忆覆盖 | hₜ 每步被 tanh 重写 | 旧信息被新信息覆盖，无保险箱 |
| 梯度连乘 | T 步 ∏(W_hh·tanh') 连乘 | 特征值<1 消失，>1 爆炸，调参治不了 |
| 信息瓶颈 | 所有历史压在固定大小 hₜ 中 | 序列越长丢得越多 |
| 特征值 | 矩阵对向量在某方向的缩放倍数 | 不是矩阵元素值，是整体衡量 |
| 长依赖失效 | RNN 记不住 50+ 步前的信息 | 是结构性缺陷，非调参可解 |
