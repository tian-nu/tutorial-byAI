# Ch38 · 生成模型简介 — VAE/GAN/Diffusion

> 所属篇：第六篇 · 预计耗时：30 分钟

> **本章说明**：这是"简介"性质的一章。"做了什么（What）"精简到只点出三大流派的核心思想；"怎么算（How）"聚焦 VAE 的 ELBO（顺带解释 KL 散度）和 Diffusion 的 3 步加噪数值小例子，不展开训练细节；"怎么用（Use）"用 HuggingFace 调一次 Diffusion 模型。其它模块按 Ch01 风格保留。

前面 37 章里，所有模型都在做一件事——**判别**。给一张图，告诉你是猫还是狗；给一句话，告诉你是正面还是负面。但 AI 能不能**创造**？给它一堆噪声，能画出一张没见过的逼真人脸吗？能写一段没人写过的文章吗？这就是**生成模型**要解决的问题。这一章我们快速过一遍生成模型的三大流派：VAE、GAN、Diffusion——它们各自用什么思路"无中生有"。

---

## 为了什么（Why）

**核心痛点**：判别模型只能"贴标签"，不能"造新东西"。

举个反例：你想用 Ch14 的 MLP 做一个人脸生成器。你训练它"这是人脸 / 这不是人脸"，然后呢？你没法让它**输出**一张新的人脸——它的输出端是一个"是不是人脸"的概率值，不是一张图片。它能判断，但生不出来。

如果你硬要让判别模型"生成"，唯一的办法是从训练集里挑一张最像的图返回——这叫**检索**，不叫生成。你拿不到训练集里没有的新样本。

**生成模型的目标**：学训练数据的分布 `p(x)`，然后从这个分布里**采样**出新的、训练集里没有的样本。三大流派用了三种完全不同的思路：

| 流派 | 核心比喻 | 一句话思路 |
|------|---------|-----------|
| VAE | 压缩再还原 | 把图压成一组"特征码"，再从码还原回图 |
| GAN | 造假者 vs 警察 | 造假者造图，警察辨真伪，对抗到造假者以假乱真 |
| Diffusion | 慢慢擦掉再慢慢画回来 | 一步步给图加噪到纯噪声，再学着一步步去噪还原 |

## 要做到（Goal）

- **输入**：Ch11-15 的神经网络基础、Ch03 的概率论（知道什么是分布、什么是高斯分布）。
- **输出**：能说清 VAE/GAN/Diffusion 三大流派的核心思想和区别；能看懂 ELBO 公式里 KL 散度的含义；能用 HuggingFace 调一次 Diffusion 模型。
- **成功标准**：能用自己的话回答这三个问题——① VAE 的"正则项"为什么要加？② GAN 的生成器和判别器谁最小化谁最大化？③ Diffusion 的 ε 是什么？

## 做了什么（What）

### 1. VAE（变分自编码器 Variational Autoencoder）—— 压缩再还原

VAE 像一个**压缩-解压**的过程。你把一张 1024×1024 的人脸图，压成一个小小的"特征码"（比如 128 个数，叫**潜在表示 z**），存起来。要用的时候，再从这 128 个数还原回一张人脸图。

```
人脸图 x ──[编码器 Encoder]──> 潜在码 z（128 个数）──[解码器 Decoder]──> 还原图 x'
         压缩                                                还原
```

但光会"压缩-还原"还不够——那只是个自编码器，你没法**生成新图**（随便给一个 z，还原出来的是乱码）。VAE 的关键创新：**让 z 服从一个标准正态分布 N(0, I)**。这样你随便从 N(0, I) 采一个 z，解码器都能还原出一张合理的人脸——这就是"生成"。

**潜在空间（Latent Space）**：所有 z 组成的空间。VAE 训练好后，这个空间里的每个点都对应一张"合理的人脸"。你可以在这个空间里"漫游"，从一个点滑到另一个点，人脸就从一个样子渐变到另一个样子。

### 2. GAN（生成对抗网络 Generative Adversarial Network）—— 造假者 vs 警察

GAN 的思路更像一场**博弈**。两个网络一起训练：

- **生成器 G**（造假者）：输入随机噪声 z，输出一张假图。目标是骗过警察。
- **判别器 D**（警察）：输入一张图（可能是真的训练图，也可能是 G 造的假图），输出"这是真图的概率"。目标是分辨真伪。

```
随机噪声 z ──[生成器 G]──> 假图 G(z) ──┐
                                       ├──> [判别器 D] ──> 真/假？
              真训练图 x ──────────────┘
```

两者对抗：G 越来越会造假，D 越来越会辨真，最后 G 造的图连 D 都分辨不出——生成成功。

### 3. Diffusion（扩散模型）—— 慢慢擦掉再慢慢画回来

Diffusion 的灵感来自热力学。想象你有一张清晰的图，你**一步步往上面撒噪声**，撒够多步之后，图就变成了纯噪声（啥也看不出来）。然后你训练一个网络，**学着反过来**：从纯噪声开始，一步步把噪声去掉，最后还原出一张清晰的图。

```
正向（加噪，不可学习）：清晰图 x₀ ──加噪──> x₁ ──加噪──> x₂ ──...──> x_T（纯噪声）
反向（去噪，要学习）：  纯噪声 x_T ──去噪──> x_{T-1} ──...──> x₁ ──去噪──> 生成图 x₀
```

生成时，你从纯噪声开始，让学好的去噪网络一步步"画回来"，就得到一张新图。

## 怎么算（How）

### 1. VAE 的损失：ELBO（证据下界）

VAE 要同时干两件事：① 还原得准（x' 要像 x）；② z 要服从标准正态分布（否则没法随机采样生成）。所以它的损失函数也有两项：

```
L = E[log p(x|z)]  -  KL(q(z|x) || p(z))
    └── 重构项 ──┘    └── 正则项 ──┘
    （越大越好：还原得越准）  （越小越好：z 越接近标准正态）
```

- **重构项 `E[log p(x|z)]`**：编码再解码后，还原出的图 x' 和原图 x 有多像。越大表示还原越准。
- **正则项 `KL(q(z|x) || p(z))`**：让编码器输出的分布 `q(z|x)` 接近标准正态分布 `p(z)=N(0, I)`。

**KL 散度是什么？** KL 散度（Kullback-Leibler divergence）是衡量**两个概率分布差异**的度量。给定两个分布 P 和 Q，`KL(P || Q)` 表示"如果真实分布是 P，但你用 Q 去近似，会损失多少信息"。

- **值域**：`KL(P || Q) ≥ 0`，永远非负。
- **越小越相似**：KL = 0 当且仅当 P 和 Q 完全相同。KL 越大，两个分布差得越远。
- **不对称**：`KL(P || Q) ≠ KL(Q || P)`，所以写的时候要注意顺序（这里前一个是编码器输出 q，后一个是目标 p）。

直觉理解：你让编码器把每张人脸图都映射成"均值=0、方差=1"的正态分布。如果不加这个 KL 项，编码器可能把不同人脸映射到潜在空间里隔得老远的点（每张图一个"独立小山头"），那中间的空隙就是乱码——你没法在中间采样。加了 KL 项，所有"小山头"被拉到一起、挤成标准正态分布那个"大山头"，整个潜在空间就被"填满"了，随便采一个点都能生成合理的人脸。

### 2. GAN 的损失：minimax 对抗

```
min_G max_D  E[log D(x)]  +  E[log(1 - D(G(z)))]
                     └─ 真图项 ─┘   └── 假图项 ──┘
```

- **判别器 D 最大化**：希望 `D(x)` 趋近 1（真图判真），`D(G(z))` 趋近 0（假图判假）。
- **生成器 G 最小化**：希望 `D(G(z))` 趋近 1（假图骗过 D）。

两者方向相反，互相拉扯，这就是"对抗"。

### 3. Diffusion 的前向加噪：3 步数值小例子

Diffusion 前向过程每一步加一点高斯噪声，公式：

```
q(x_t | x_{t-1}) = N(x_t; √(1-β_t)·x_{t-1}, β_t·I)
```

翻译成人话：`x_t = √(1-β_t)·x_{t-1} + √β_t·ε`

- `β_t` 是第 t 步的噪声调度（一个小数，控制这一步加多少噪声）。
- **`ε`（epsilon）是什么？** 是从**标准正态分布 N(0, I)** 采样的**随机噪声**。每一步都重新采一个新的 ε——它就是"撒上去的噪声"本身。`√β_t·ε` 这一项保证了加进去的噪声方差正好是 β_t。
- `√(1-β_t)·x_{t-1}` 这一项把上一图稍微缩小一点（保证加噪后整体方差不会越来越大到爆炸）。

**数值小例子**（3 步加噪，2 维向量当作"图"）：

设原始样本 `x_0 = [1.0, 0.5]`，噪声调度 `β_1=0.1, β_2=0.2, β_3=0.3`。

每一步采一个随机噪声 ε（这里我们"假装"采到具体的值，方便手算；实际训练时是随机采的）：

#### 第 1 步：x_0 → x_1

- `β_1 = 0.1`，`√(1-0.1) = √0.9 ≈ 0.949`，`√0.1 ≈ 0.316`
- 假设采到噪声 `ε_1 = [0.1, -0.2]`
- `x_1 = 0.949 × [1.0, 0.5] + 0.316 × [0.1, -0.2]`
- 第 1 维：`0.949 × 1.0 + 0.316 × 0.1 = 0.949 + 0.032 = 0.981`
- 第 2 维：`0.949 × 0.5 + 0.316 × (-0.2) = 0.475 - 0.063 = 0.412`
- **`x_1 = [0.981, 0.412]`**

#### 第 2 步：x_1 → x_2

- `β_2 = 0.2`，`√(1-0.2) = √0.8 ≈ 0.894`，`√0.2 ≈ 0.447`
- 假设采到噪声 `ε_2 = [0.3, 0.1]`（注意：每步重新采一个新的 ε）
- `x_2 = 0.894 × [0.981, 0.412] + 0.447 × [0.3, 0.1]`
- 第 1 维：`0.894 × 0.981 + 0.447 × 0.3 = 0.877 + 0.134 = 1.011`
- 第 2 维：`0.894 × 0.412 + 0.447 × 0.1 = 0.368 + 0.045 = 0.413`
- **`x_2 = [1.011, 0.413]`**

#### 第 3 步：x_2 → x_3

- `β_3 = 0.3`，`√(1-0.3) = √0.7 ≈ 0.837`，`√0.3 ≈ 0.548`
- 假设采到噪声 `ε_3 = [-0.2, 0.5]`（又重新采一个）
- `x_3 = 0.837 × [1.011, 0.413] + 0.548 × [-0.2, 0.5]`
- 第 1 维：`0.837 × 1.011 + 0.548 × (-0.2) = 0.846 - 0.110 = 0.736`
- 第 2 维：`0.837 × 0.413 + 0.548 × 0.5 = 0.346 + 0.274 = 0.620`
- **`x_3 = [0.736, 0.620]`**

**观察**：从 `x_0 = [1.0, 0.5]` 到 `x_3 = [0.736, 0.620]`，原始信号被一步步"稀释"，噪声占比越来越大。如果继续加噪几十上百步，`x_T` 就几乎完全是噪声了——这就是 Diffusion 前向过程的终点：纯噪声。

**反向过程**就是学一个网络 `p_θ(x_{t-1}|x_t)`，给定带噪图 `x_t`，预测上一步的 `x_{t-1}`（本质上是预测这一步加的噪声 ε，再减掉它）。训练时只学这个去噪网络，生成时从纯噪声开始反复去噪，就得到新图。

## 怎么用（Use）

代码文件：`深度学习从0到Transformer教程/code/ch38_diffusion_demo.py`

关键片段：

```python
import numpy as np

# 1. 手写 Diffusion 3 步加噪（对应上面数值小例子）
x = np.array([1.0, 0.5])
betas = [0.1, 0.2, 0.3]
epsilons = [np.array([0.1, -0.2]),
            np.array([0.3, 0.1]),
            np.array([-0.2, 0.5])]  # 每步采一个新噪声
for t, (beta, eps) in enumerate(zip(betas, epsilons), 1):
    x = np.sqrt(1 - beta) * x + np.sqrt(beta) * eps
    print(f"x_{t} = {x}")
# x_3 ≈ [0.736, 0.620]

# 2. 用 HuggingFace 调用 Diffusion 模型生成图片（需联网下载模型）
from diffusers import StableDiffusionPipeline
import torch
pipe = StableDiffusionPipeline.from_pretrained(
    "runwayml/stable-diffusion-v1-5", torch_dtype=torch.float16
)
pipe = pipe.to("cuda")
image = pipe("a cat wearing a hat").images[0]
image.save("cat_hat.png")
```

## 想多一点

> 为什么 Diffusion 能超越 GAN 成为图像生成的 SOTA（State of the Art）？
>
> 提示：GAN 的训练是个"二人博弈"，生成器和判别器要小心翼翼地保持平衡——一方太强另一方就学不动，很容易**模式崩溃（Mode Collapse）**：生成器只敢造那一两种能骗过判别器的图，多样性极差。Diffusion 完全没有这个博弈结构，它只是让网络学"去噪"这一个简单任务，训练目标稳定、可预测。加上 Diffusion 的"逐步去噪"天然覆盖多种模式（每一步都有多种去噪可能），生成的样本多样性好。代价是慢——GAN 一次前向就出图，Diffusion 要迭代几十上百步去噪。所以现在很多研究在做"加速 Diffusion"。

## 易错点预警

- ❌ 以为 Diffusion 直接生成图片 → ✅ 正确：Diffusion 学习的是**去噪过程**。生成时从纯噪声开始，一步步去噪还原出图。前向加噪过程（`q(x_t|x_{t-1})`）是不可学习的、固定的，只是用来"制造训练数据"——给网络看带噪图 x_t，让它预测噪声 ε。
- ❌ GAN 的生成器和判别器用同一个 loss、朝同一个方向优化 → ✅ 正确：两者是**对抗**的。判别器 D **最大化** loss（想分辨真伪），生成器 G **最小化** loss（想骗过 D）。训练时交替进行：先更新 D 一次，再更新 G 一次。
- ❌ 把 VAE 的 KL 项当成"越小越好整体就越好" → ✅ 正确：ELBO = 重构项 - KL 项。你要**最大化** ELBO，等价于**最大化重构项**（还原准）同时**最小化 KL 项**（z 接近标准正态）。两项是**此消彼长**的权衡：KL 压太狠，z 都挤在 0 附近，分辨不出不同图，还原就糊；KL 放太松，z 散开没法采样生成。所以 VAE 生成的图往往偏"模糊"——这是它的固有代价。
- ❌ 以为 Diffusion 每一步用的 ε 是同一个 → ✅ 正确：每一步都**重新采样**一个新的 ε ~ N(0, I)。前向加噪时每步一个新噪声，反向去噪时网络预测的也是"这一步的"噪声。

## 章末小结

| 模型 | 核心思想 | 优势 | 劣势 |
|------|---------|------|------|
| VAE | 编码到潜在空间 + 解码，加 KL 正则让 z 服从 N(0,I) | 训练稳定、潜在空间可解释、能插值 | 生成图偏模糊（重构与正则的权衡）|
| GAN | 生成器 vs 判别器对抗博弈 | 生成图清晰锐利 | 训练难、易模式崩溃、不可控 |
| Diffusion | 逐步加噪（前向）+ 逐步去噪（反向）| 质量高、训练稳定、可控性强 | 生成慢（要迭代多步去噪）|
| KL 散度 | 衡量两个分布差异，≥0，越小越相似 | — | 不对称，不是真正的距离 |
| ε（epsilon）| 标准正态分布 N(0,I) 采样的随机噪声 | — | 每步重新采样 |
