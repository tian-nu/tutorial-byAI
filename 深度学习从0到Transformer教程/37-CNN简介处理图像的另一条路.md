# Ch37 · CNN简介 — 处理图像的另一条路

> 所属篇：第六篇 · 预计耗时：25 分钟

> **本章说明**：这是"简介"性质的一章。"做了什么（What）"模块精简到只点出三个核心组件；"怎么算（How）"只聚焦 3×3 卷积的数值小例子，不展开反向传播（那是 Ch15 已经讲过、迁移到 CNN 的内容，本章不重复）；"怎么用（Use）"用 PyTorch 跑一层卷积和一层池化，不拼完整分类网络。其它模块按 Ch01 风格保留。

你拍一张猫的照片，传给 AI，它得告诉你"这是一只猫"。这件事对人来说毫不费力——猫的耳朵在头顶、胡须在嘴边、眼睛圆圆的。但对全连接网络来说，这事儿灾难性地难：一张 224×224 的彩色图片展开是 150528 个数，第一层哪怕只有 1000 个神经元，参数量就 1.5 亿。更要命的是，猫稍微往左挪一点，所有像素位置全变了，网络就认不出来了——它得为"左上角的猫"和"右下角的猫"各学一遍。

卷积神经网络（CNN）就是为图像量身定做的解法。它的核心思想简单得像一句话：**拿一个放大镜在图上滑来滑去，看到啥特征就记下来**。这一章我们看看这个"放大镜"长什么样。

---

## 为了什么（Why）

**核心痛点**：全连接网络处理图像有两个死结。

1. **参数爆炸**：一张 224×224×3 的图片，第一层如果输出 1000 维，参数量是 `224×224×3×1000 ≈ 1.5 亿`。十层下来参数量比地球人口还多。
2. **空间结构丢失**：全连接网络把图片展平成一维向量，"猫的耳朵在头顶"这种空间关系全没了。更糟的是，猫往左挪 10 像素，输入向量完全变样，网络得重新学一遍——它不懂"猫"这个概念和猫在图里的位置无关。

CNN 用两个动作同时解决这两个问题：

- **卷积**：一个小小的"放大镜"（卷积核）在图上滑动，每个位置都用同一组权重做局部特征检测。参数量从"整图全连接"降到"卷积核大小"。
- **池化**：把图缩小一点，让特征更紧凑，也让位置变化不那么敏感。

## 要做到（Goal）

- **输入**：会矩阵乘法（Ch01）、会 PyTorch 写一层 Linear（Ch14）。
- **输出**：能说清卷积、池化、通道、感受野四个词；能用 PyTorch 写一层 Conv2d 并算出输出形状和参数量。
- **成功标准**：给定 `nn.Conv2d(3, 16, 3, padding=1)`，能口算出输入 `(1,3,32,32)` 时输出形状是 `(1,16,32,32)`，参数量是 448。

## 做了什么（What）

CNN 的核心就三个组件，像流水线一样串起来：

```
输入图像 (C × H × W)
   │
   ├──> 卷积层 Conv  (用放大镜扫一遍，提取局部特征)
   │       └─ 输出特征图 (C_out × H × W)
   │
   ├──> 池化层 Pool  (把图缩一半，特征更紧凑)
   │       └─ 输出特征图 (C × H/2 × W/2)
   │
   └──> 反复堆叠 Conv + Pool 多层
           │
           └──> 最后展平 + 全连接 → 分类结果
```

### 逐组件拆解

**卷积层（Convolution）**：核心是**卷积核（Kernel/Filter）**——一个小矩阵（比如 3×3）。把它盖在图像的一个 3×3 区域上，对应位置相乘再求和，得到一个数。然后按**步长（Stride）**滑动一格，继续算。整张图扫完，得到一张"特征图"。

- 卷积核就是个"特征探测器"。比如 `[[1,0,-1],[1,0,-1],[1,0,-1]]` 这个核，专门检测**垂直边缘**（左右明暗交界处）。
- **通道（Channel）**：彩色图有 R、G、B 三个通道，理解成"三张叠在一起的灰度图"，用三色滤镜分别看。卷积核的深度等于输入通道数——一个 3×3 卷积核其实是 `3×3×3` 的"长方体"，覆盖三个通道。
- 输出通道数 = 卷积核的个数。16 个卷积核就输出 16 张特征图。

**池化层（Pooling）**：把特征图缩小。最常见的 MaxPool 2×2：在每个 2×2 小块里挑最大的那个数，图就缩到原来的一半。作用是降维 + 让特征对位置不那么敏感（猫稍微挪一点，最大值还在）。

**感受野（Receptive Field）**：这是 CNN 里最重要的概念之一。**一个输出像素对应了输入图像的多少区域**，那个区域就是它的感受野。

- 第一层卷积用 3×3 核，每个输出像素看 3×3 的输入区域，感受野 = 3。
- 第二层卷积再用 3×3 核，它的每个输入已经是上一层 3×3 的"压缩"，所以第二层输出像素看的是输入图上 5×5 的区域，感受野 = 5（公式：`r_l = r_{l-1} + (k_l - 1)`，`r_1 = k_1`）。
- 层数越深，感受野越大，能看到的"全局结构"越多。深层神经元能识别"整只猫"，浅层只能识别"猫耳朵的边缘"。

**全连接层**：把最后的特征图展平成向量，接一个 Linear 层输出分类结果。

## 怎么算（How）

### 1. 3×3 卷积数值小例子

我们用最简单的灰度图（单通道）来手算一次卷积。

**输入**（4×4 矩阵，左半暗=1，右半亮=2，中间是一条垂直边缘）：

```
[[1, 1, 2, 2],
 [1, 1, 2, 2],
 [1, 1, 2, 2],
 [1, 1, 2, 2]]
```

**3×3 卷积核**（垂直边缘检测器：左列 +1，中间 0，右列 -1）：

```
[[ 1,  0, -1],
 [ 1,  0, -1],
 [ 1,  0, -1]]
```

**参数**：无 padding（padding=0），步长 stride=1。输出尺寸公式：`(H - k) / stride + 1 = (4 - 3) / 1 + 1 = 2`，所以输出是 2×2。

**滑动过程**（4 个位置）：

#### 位置 (0, 0)：盖住输入左上角 3×3

```
输入窗口：          卷积核：
[[1, 1, 2],        [[ 1,  0, -1],
 [1, 1, 2],         [ 1,  0, -1],
 [1, 1, 2]]         [ 1,  0, -1]]
```

逐元素相乘再求和：
- 第 1 行：1×1 + 1×0 + 2×(-1) = 1 + 0 - 2 = -1
- 第 2 行：1×1 + 1×0 + 2×(-1) = -1
- 第 3 行：1×1 + 1×0 + 2×(-1) = -1
- 求和：-1 + (-1) + (-1) = **-3**

#### 位置 (0, 1)：盖住输入右上角 3×3

```
输入窗口：          卷积核：
[[1, 2, 2],        [[ 1,  0, -1],
 [1, 2, 2],         [ 1,  0, -1],
 [1, 2, 2]]         [ 1,  0, -1]]
```

- 第 1 行：1×1 + 2×0 + 2×(-1) = -1
- 第 2 行：1×1 + 2×0 + 2×(-1) = -1
- 第 3 行：1×1 + 2×0 + 2×(-1) = -1
- 求和：**-3**

#### 位置 (1, 0)：盖住输入左下角 3×3

```
输入窗口：          卷积核：
[[1, 1, 2],        [[ 1,  0, -1],
 [1, 1, 2],         [ 1,  0, -1],
 [1, 1, 2]]         [ 1,  0, -1]]
```

- 同位置 (0,0)，结果 = **-3**

#### 位置 (1, 1)：盖住输入右下角 3×3

```
输入窗口：          卷积核：
[[1, 2, 2],        [[ 1,  0, -1],
 [1, 2, 2],         [ 1,  0, -1],
 [1, 2, 2]]         [ 1,  0, -1]]
```

- 同位置 (0,1)，结果 = **-3**

**最终输出**：

```
[[-3, -3],
 [-3, -3]]
```

**怎么理解？** 四个位置都是 -3，因为这个 4×4 图每个 3×3 窗口里都是"左 1 右 2"的结构，卷积核在每个位置都检测到同样的垂直边缘。-3 是负数，表示"右侧比左侧亮"（左 +1 右 -1 的核看到右亮就输出负）。如果换成"左 2 右 1"的图，结果就会是 +3。

**关键观察**：卷积核**在所有位置用同样的权重**。这就是 CNN 的两个核心性质：

1. **平移不变性（Translation Invariance）**：同一个特征（比如垂直边缘）无论出现在图的哪个位置，同一个卷积核都能检测到，输出同样的响应。猫在左上角还是右下角，"猫耳朵边缘检测器"都能识别出来——因为用的是同一个核同一组权重。
2. **参数共享**：整张图只学一组 3×3 的权重（9 个数），而不是每个位置都学一组。这是 CNN 比全连接省参数的根本原因。

### 2. 参数量计算：那个 +1 是什么

来看 `nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3)` 这一层的参数量。

**单个卷积核的参数量**：`3 × 3 × 3 = 27`（高 × 宽 × 输入通道数）。注意卷积核是立体的，深度必须等于输入通道数，否则没法在彩色图上做对应相乘。

**16 个卷积核**：`27 × 16 = 432`。

**偏置（Bias）**：`16` 个。每个输出通道有一个偏置标量。

**总参数量**：`(3×3×3 + 1) × 16 = 28 × 16 = 448`

**那个 +1 是什么？** 是**偏置（bias）**。每个输出通道配一个偏置标量，相当于神经元的"偏置项"——把卷积结果整体加一个常数。

为什么要加偏置？想象一张全黑的图（所有像素都是 0），卷积结果全是 0。如果没有偏置，无论卷积核学到什么，输出都是 0，激活函数（ReLU）输出也是 0，整个网络死掉。偏置让卷积核有一个"基础激活阈值"，可以学"特征强度超过多少才算检测到"。

**对比全连接的参数量**：同样的输入 `3×32×32 = 3072` 维，输出 16 维，全连接参数量 = `3072 × 16 + 16 = 49168`。CNN 的 448 是它的 1/110。这就是参数共享的威力。

## 怎么用（Use）

代码文件：`深度学习从0到Transformer教程/code/ch37_cnn_basics.py`

关键片段：

```python
import torch
import torch.nn as nn
import numpy as np

# 手写 3×3 卷积数值小例子（对应上面 4×4 输入的例子）
x = np.array([[1,1,2,2],[1,1,2,2],[1,1,2,2],[1,1,2,2]], dtype=float)
k = np.array([[1,0,-1],[1,0,-1],[1,0,-1]], dtype=float)
out = np.zeros((2,2))
for i in range(2):
    for j in range(2):
        out[i,j] = np.sum(x[i:i+3, j:j+3] * k)
print(out)  # [[-3, -3], [-3, -3]]

# 一层 Conv2d
conv = nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, padding=1)
x = torch.randn(1, 3, 32, 32)  # batch=1, C=3, H=32, W=32
print(conv(x).shape)            # (1, 16, 32, 32)  padding=1 保持尺寸
print(conv.weight.shape)        # (16, 3, 3, 3)   16 个核 × 3 通道 × 3×3
print(sum(p.numel() for p in conv.parameters()))  # 448

# 一层 MaxPool2d
pool = nn.MaxPool2d(kernel_size=2, stride=2)
print(pool(conv(x)).shape)      # (1, 16, 16, 16)  尺寸减半
```

## 想多一点

> CNN 的卷积核为什么能"自动学会"检测边缘？
>
> 提示：没有人手写那些 `[[1,0,-1],[1,0,-1],[1,0,-1]]` 的核。它们是反向传播学出来的。当你让 CNN 去做"猫狗分类"，损失函数会告诉网络"哪些卷积核有用"。能检测边缘的核（因为边缘是猫耳朵、猫眼睛的组成部分）能降低分类 loss，梯度就会强化这些核的权重；没用到的核权重会被弱化。最后学出来的卷积核，第一层往往长得像 Gabor 滤波器（一种经典的边缘/纹理检测算子）——网络自己"重新发现"了视觉科学里几十年前就知道的原理。这正是深度学习最迷人的地方：给网络一个目标，它会自己学出人类专家手工设计的特征。

## 易错点预警

- ❌ 忘了 padding，输出尺寸莫名变小 → ✅ 正确：`padding=1` 配 `kernel_size=3` 保持尺寸不变（输出尺寸公式 `(H + 2×padding - k) / stride + 1`，`padding=1, k=3, stride=1` 时 `(H+2-3)/1+1 = H`）。`padding=0` 时输出会从 32 变成 30。
- ❌ 把 `in_channels` 和 `out_channels` 搞反 → ✅ 正确：`in_channels` 是输入图的通道数（彩色图就是 3），`out_channels` 是你要几个卷积核（=输出特征图的通道数）。`Conv2d(3, 16, 3)` 是"3 通道输入，16 个核，3×3 大小"。
- ❌ 以为卷积核的深度等于 1 → ✅ 正确：卷积核的深度**必须**等于输入通道数。`Conv2d(3, 16, 3)` 的每个核是 `3×3×3` 的立体，不是 `3×3` 的平面。`conv.weight.shape = (16, 3, 3, 3)` 就是"16 个核，每个 3 通道 × 3×3"。

## 章末小结

| 组件 | 作用 | 关键参数 |
|------|------|---------|
| 卷积层 Conv | 用卷积核滑动提取局部特征 | `(k×k×C_in + 1) × C_out`，参数共享 |
| 池化层 Pool | 降维 + 平移不变性 | 0 个参数（MaxPool 无可学习参数）|
| 通道 Channel | 不同视角的特征图 | 输入=图本身通道数，输出=卷积核个数 |
| 感受野 Receptive Field | 一个输出像素看输入多少区域 | 层数越深越大，3 → 5 → 7 ... |
| 平移不变性 | 同特征无论在哪都能被检测 | 来自卷积核权重共享 |
