OSI 七层模型

7. 应用层 ApplicationPDU: 数据 Data | 代表协议: HTTP、FTP、SMTP、DNS
职责: 为用户直接提供网络服务
6. 表示层 PresentationPDU: 数据 Data | 代表功能: 加密(TLS/SSL)、压缩(gzip)、编码转换
职责: 数据格式转换、加密解密、压缩解压
5. 会话层 SessionPDU: 数据 Data | 代表功能: 会话建立/维持/终止
职责: 建立、管理和终止会话
4. 传输层 TransportPDU: 段 Segment | 代表协议: TCP、UDP
职责: 端到端可靠/不可靠传输、端口号
3. 网络层 NetworkPDU: 包 Packet | 代表协议: IP、ICMP、ARP
职责: 跨网络寻址和路由
2. 数据链路层 Data LinkPDU: 帧 Frame | 代表: MAC地址、交换机、ARP
职责: 局域网内帧的可靠传输
1. 物理层 PhysicalPDU: 比特 Bit | 代表: 双绞线、光纤、无线电
职责: 在物理介质上传输比特流

TCP/IP 四层模型

应用层 Application合并 OSI 会话+表示+应用层
核心: HTTP、HTTPS、DNS、FTP、SMTP
传输层 TransportTCP（可靠、保送到） / UDP（快速、不保）
核心词: 可靠/不可靠
网际层 Internet核心: IP（IPv4/IPv6）、ICMP（ping）、ARP（IP→MAC翻译）
核心词: 寻址路由
网络接口层 Network Access合并 OSI 物理+数据链路层
核心: 以太网、WiFi、MAC地址、交换机
核心词: 局域网传输
