## 为了什么（Why）

**核心痛点**：前面学的都是孤立概念。你会调用 `model.fit()` 和 `model.predict()`，但面对真实数据时你发现——数据有缺失值！类别不是数字！特征太多了需要筛选！这些实际问题在教科书例子里都不会出现。

举个反例：很多人学完理论后直接 `pd.read_csv("data.csv")` → `model.fit(X, y)` → 完事。结果准确率只有 50%（跟瞎猜一样），因为没做任何数据清洗和特征工程。**好特征比好模型更重要**。

## 要做到（Goal）

- **输入**：乘客信息数据集（舱位等级、性别、年龄、票价等）。
- **输出**：预测乘客是否生还的二分类模型，交叉验证准确率 > 78%。
- **成功标准**：完整走通"数据加载→清洗→特征工程→训练→评估"全流程，理解每一步为什么做。

## 做了什么（What）

完整 ML 项目的流程就像一条流水线：

```
原始数据
   ↓
[1. 数据清洗]     ← 填缺失值、删无用列
   ↓
[2. 类别编码]     ← 文字变数字（male→0, female→1）
   ↓
[3. 特征工程]     ← 构造新特征（家庭大小等）
   ↓
[4. 划分数据集]   ← 训练集 / 测试集
   ↓
[5. 模型训练]     ← fit()
   ↓
[6. 模型评估]     ← 准确率、混淆矩阵、F1 分数
   ↓
输出: 可用于预测的模型
```

### 逐组件拆解

**数据清洗**：处理缺失值（如年龄用中位数填充）、删除对预测无用的列（如姓名、票号）。**不要直接删除所有有缺失的行**——那样会丢掉大量有用数据。

**类别编码**：机器只能处理数字。"male"/"female" 要变成 0/1，"C"/"Q"/"S"（登船港口）要做 One-Hot 编码或 Ordinal 编码。

**特征工程**：从原始数据中构造更有用的特征。比如从"姓名"提取称谓（Mr/Mrs/Miss）、计算家庭规模（兄弟姐妹数+父母子女数+1）。

**模型选择**：
- 逻辑回归（Logistic Regression）：简单可解释
- 随机森林（Random Forest）：通常效果更好，自带正则化

**评估指标**：
- 准确率（Accuracy）：预测正确的比例
- **混淆矩阵（Confusion Matrix）**：展示四种预测情况（TP/FP/TN/FN）
- **F1 分数（F1 Score）**：精确率和召回率的调和平均，比准确率更全面

## 怎么算（How）

### 数值小例子：数据处理过程

假设原始数据长这样：

| PassengerId | Pclass | Sex    | Age  | Fare | Survived |
|-------------|--------|--------|------|------|----------|
| 1           | 3      | male   | 22.0 | 7.25 | 0        |
| 2           | 1      | female | 38.0 | 71.3 | 1        |
| 3           | 3      | female | NaN  | 7.92 | 1        |

**第1步：填补缺失值**

Age 列有 NaN（第3行），用所有已知 Age 的中位数填充：

中位数 = median([22.0, 38.0, ...]) ≈ **28.0**

第3行的 NaN 变成 28.0。

**第2步：类别编码**

Sex 列：`male → 0`，`female → 1`

Pclass 已经是数字（1/2/3），可以直接用。

**第3步：构造特征向量**

处理后第3行的特征向量：

`[Pclass=3, Sex=1, Age=28.0, Fare=7.92]`

输入模型 → 预测 Survived = 1（生还）

### 混淆矩阵（Confusion Matrix）

模型预测完之后，结果可以归纳为四种情况：

```
                预测
              正类(1)  负类(0)
真实  正类(1)   TP       FN    ← 召回率 = TP/(TP+FN)
      负类(0)   FP       TN    ←

              ↑
         精确率 = TP/(TP+FP)
```

- **TP（True Positive）**：实际为1，预测也为1 ✅
- **FN（False Negative）**：实际为1，但预测为0 ❌（漏报）
- **FP（False Positive）**：实际为0，但预测为1 ❌（误报）
- **TN（True Negative）**：实际为0，预测也为0 ✅

**F1 分数 = 2 × (精确率 × 召回率) / (精确率 + 召回率)**

当数据不平衡时（比如只有10%的人生还），准确率可能虚高（全猜"死亡"就有90%准确率），此时 F1 更能反映真实性能。

关键片段：

```python
import numpy as np
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import cross_val_score, train_test_split
from sklearn.metrics import confusion_matrix, classification_report, f1_score

# 1. 加载数据（用模拟数据，无需下载外部文件）
df = make_titanic_data()

# 2. 数据清洗
df["Age"] = df["Age"].fillna(df["Age"].median())  # 年龄用中位数填充
df["Sex"] = df["Sex"].map({"male": 0, "female": 1})  # 性别编码

# 3. 选择特征
features = ["Pclass", "Sex", "Age", "Fare"]
X = df[features].fillna(0)
y = df["Survived"]

# 4. 划分 + 训练
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)
model = RandomForestClassifier(n_estimators=100, max_depth=5, random_state=42)
model.fit(X_train, y_train)

# 5. 评估
scores = cross_val_score(model, X, y, cv=5)
print(f"CV accuracy: {scores.mean():.4f} ± {scores.std():.4f}")

# 6. 混淆矩阵和 F1
y_pred = model.predict(X_test)
print(confusion_matrix(y_test, y_pred))
print(f"F1 Score: {f1_score(y_test, y_pred):.4f}")
```

## 想多一点

> 传统机器学习的"天花板"在哪里？
>
> 传统 ML（逻辑回归、随机森林、SVM 等）的效果很大程度上取决于**特征工程的质量**——你需要人工设计哪些特征可能有用。这依赖领域知识和大量试错。
>
> 而**深度学习**的核心优势就是**自动特征提取**：原始像素/文本/音频直接喂进去，网络自己学会从低级特征组合出高级特征（边缘→形状→物体部件→整个物体）。这就是为什么深度学习在图像、语音、NLP 领域碾压传统方法。
>
> 但传统 ML 并没有过时——在表格数据（如 Titanic 这种结构化数据）上，随机森林/XGBoost 往往还是最实用的选择。

## 易错点预警

- ❌ 数据泄露：在划分训练/测试集之前做了全局归一化（用了测试集的信息） → ✅ 正确做法：先划分，再对训练集 fit_transform，对测试集只 transform。或者直接用 Pipeline 把所有步骤串起来。
- ❌ 只看准确率不看 F1 或混淆矩阵 → ✅ 正确做法：尤其在不平衡数据集上，一定要看精确率、召回率和 F1。全部猜多数类的模型准确率可能很高但毫无用处。

## 章末小结

| 概念 | 一句话解释 | 易错点 |
|------|-----------|--------|
| 数据清洗 | 处理缺失值、异常值和无用列 | 不要直接 dropna() 全删，会丢失太多数据 |
| 类别编码 | 把文字特征转为数值（如 male→0, female→1） | 注意 One-Hot vs Ordinal 的适用场景 |
| 特征工程 | 从原始数据构造更有用的特征 | **好特征比好模型更重要** |
| 交叉验证（Cross Validation） | 多次随机划分取平均，评估更稳定 | 测试集不能参与 CV，否则数据泄露 |
| 混淆矩阵（Confusion Matrix） | TP/FP/FN/TN 四种预测情况的汇总表 | 能看出模型在哪类上容易犯错 |
| F1 分数（F1 Score） | 精确率和召回率的调和平均值 | 不平衡数据集上比准确率更可靠 |
| 传统ML天花板 | 依赖人工特征工程，无法自动提取高阶特征 | 表格数据上仍然很强，图像/NLP 上被深度学习超越 |
