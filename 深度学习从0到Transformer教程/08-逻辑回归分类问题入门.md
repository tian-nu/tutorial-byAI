# Ch08 · 逻辑回归 — 分类问题入门

> 所属篇：第一篇 · 预计耗时：20 分钟

线性回归预测"房价是多少"（连续值，可以是 100.5 万、100.51 万……）。但很多时候你要预测的是"这封邮件是不是垃圾邮件"——答案只有两个：是 或 否。你需要一个能把"任意实数"压到"0~1之间"的函数——sigmoid。这一章我们从线性回归跨出一步，进入分类问题的世界。

---

## 为了什么（Why）

**核心痛点**：分类问题要求输出概率（0~1），但线性回归输出任意实数。如果你用线性回归做垃圾邮件分类，它可能输出"概率=2.3"或"-1.5"——这完全没法解释。

**解决方案**：在线性回归的输出上套一个 sigmoid 函数，把 (-∞, +∞) 的实数压缩到 (0, 1) 区间。这就是逻辑回归。

## 要做到（Goal）

- **输入**：特征 X（如邮件中包含"免费"的次数），二分类标签 Y ∈ {0, 1}。
- **输出**：概率 p ∈ (0, 1)。p > 0.5 判为类别 1，否则判为类别 0。
- **成功标准**：在简单二分类数据集上准确率 > 90%。

## 做了什么（What）

逻辑回归的结构就是在线性回归外面套了一层 sigmoid：

```
特征 x → [线性组合 z=wx+b] → [sigmoid σ(z)] → 概率 p ∈ (0,1)
                                    ↓
                              p > 0.5? → 类别 1
                              p ≤ 0.5? → 类别 0
```

### 逐组件拆解

**线性部分 z = wx + b**：和线性回归一样，先算一个线性组合。

**sigmoid 函数 σ(z) = 1 / (1 + e^(-z))**：S 形曲线，把任意实数映射到 (0, 1)。
- z = 0 时，σ(0) = 0.5（分界点）
- z → +∞ 时，σ(z) → 1
- z → -∞ 时，σ(z) → 0

**交叉熵损失（Cross-Entropy Loss）**：衡量"预测的概率分布"和"真实的标签分布"之间的差异。

`L = -[y × log(p) + (1-y) × log(1-p)]`

当 y=1 时，L = -log(p)，p 越接近 1 损失越小；
当 y=0 时，L = -log(1-p)，p 越接近 0 损失越小。

**决策边界（Decision Boundary）**：p = 0.5 对应的线/面。在二维空间里就是一条直线，把两类数据分开。

## 怎么算（How）

### 核心公式

```
线性组合：z = w × x + b
Sigmoid：  p = σ(z) = 1 / (1 + e^(-z))
交叉熵损失：L = -[y·log(p) + (1-y)·log(1-p)]
梯度：∂L/∂w = (p - y) × x    （注意这个形式多简洁！）
     ∂L/∂b = p - y
更新：w = w - η × ∂L/∂w
      b = b - η × ∂L/∂b
```

### 数值小例子：单样本完整手推

**设定**：
- 单个样本：x = 2.0，真实标签 y = 1（正类）
- 初始参数：w = 0.5，b = 0
- 学习率：η = 0.1

**第1步：计算线性组合**

z = w × x + b = 0.5 × 2.0 + 0 = **1.0**

**第2步：通过 sigmoid 得到概率**

σ(1.0) = 1 / (1 + e^(-1.0))

e^(-1.0) ≈ 0.3679

σ(1.0) = 1 / (1 + 0.3679) = 1 / 1.3679 ≈ **0.731**

所以模型认为这个样本是正类的概率是 73.1%。（因为 y=1 是正类，这个预测方向是对的，只是还不够自信。）

**第3步：计算交叉熵损失**

因为 y = 1：

L = -[1 × log(0.731) + 0 × log(1 - 0.731)]
  = -log(0.731)
  = -(-0.313)
  = **0.313**

如果模型预测 p=0.99（很确信），损失只有 -log(0.99) ≈ 0.01（很小 ✅）。
如果模型预测 p=0.1（搞反了），损失有 -log(0.1) = 2.30（很大 ❌）。

**第4步：计算梯度并更新参数**

∂L/∂w = (p - y) × x = (0.731 - 1) × 2.0 = (-0.269) × 2.0 = **-0.538**
∂L/∂b = p - y = 0.731 - 1 = **-0.269**

注意梯度都是负数！这意味着增大 w 和 b 可以减小损失（让 p 更接近 1）。

更新（η = 0.1）：

w_new = 0.5 - 0.1 × (-0.538) = 0.5 + 0.054 = **0.554**
b_new = 0 - 0.1 × (-0.269) = 0 + 0.027 = **0.027**

w 从 0.5 增加到了 0.554，向正确方向前进了一步！重复这个过程几百次，模型就会学到合适的 w 和 b。

### ⚠️ 维度问题（重要！）

在代码实现时，最容易踩坑的就是维度不匹配。来看具体说明：

```python
X = np.array([[2.0], [3.0], [1.0], [0.5]])  # shape (4, 1)：4 个样本，每样本 1 个特征
y = np.array([1, 1, 0, 0])                   # shape (4,)：4 个标签

# ❌ 错误：w 是 Python 标量
w = 0.0
z = X @ w   # 报错！不能对 (4,1) 矩阵和标量做矩阵乘法

# ✅ 正确：w 必须是形状 (1,) 的数组
w = np.array([0.0])  # shape (1,)，与 X 的列数（1）对齐
z = X @ w            # (4,1) @ (1,) = (4,)  ✅ 正确！
```

**为什么？** `X @ w` 做的是矩阵乘法：`(n_samples, n_features) @ (n_features,) = (n_samples,)`。w 的长度必须等于 X 的特征数（列数）。

## 怎么用（Use）

代码文件：`深度学习从0到Transformer教程/code/ch08_logistic_regression.py`

关键片段：

```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

# 数据：4个样本，每个1个特征
X = np.array([[2.0], [3.0], [1.0], [0.5]], dtype=float)  # shape (4, 1)
y = np.array([1, 1, 0, 0], dtype=float)                  # shape (4,)

# 参数初始化 —— 注意维度！
w = np.array([0.0])  # shape (1,) 不是标量！
b = 0.0
lr = 0.1

for epoch in range(200):
    z = X @ w + b              # (4,1) @ (1,) = (4,)
    p = sigmoid(z)             # shape (4,)
    loss = -np.mean(y * np.log(p + 1e-15) + (1-y) * np.log(1-p + 1e-15))
    dw = np.mean((p - y) * X.flatten())  # 标量
    db = np.mean(p - y)                 # 标量
    w -= lr * dw                        # 更新 w[0]
    b -= lr * db

print(f"w={w[0]:.4f}, b={b:.4f}")
```

## 想多一点

> 为什么分类用交叉熵而不用 MSE？
>
> 这是很多初学者会困惑的问题——MSE 在回归里用得好好的，为什么分类要换？
>
> **根本原因在于梯度的行为不同。**
>
> 用 MSE 做分类损失的梯度是：`∂L_MSE/∂w = (p-y) × σ'(z) × x`
>
> 用交叉熵的梯度是：`∂L_CE/∂w = (p-y) × x`
>
> 注意到区别了吗？MSE 的梯度多了一个 **σ'(z)** 因子（sigmoid 的导数）！而 sigmoid 的导数在 z 很大或很小时趋近于 0。这意味着：
> - 当模型预测很确信（z 很大或很小），sigmoid 导数≈0，**MSE 的梯度也≈0**，训练停滞
> - 但此时如果预测是错的（比如 y=1 但 p≈0.01），我们反而需要大的梯度来纠正！
>
> 交叉熵巧妙地抵消了这个因子（数学推导可以证明），使得梯度始终与 `(p-y)` 成正比——**错得越狠，梯度越大，纠正越猛**。这就是为什么分类任务几乎都用交叉熵。

## 易错点预警

- ❌ 用 MSE（均方误差）做分类任务的损失函数，发现训练不动或收敛极慢 → ✅ 正确做法：分类问题统一用交叉熵损失（Cross-Entropy Loss）。PyTorch 里叫 `BCELoss`，sklearn 的逻辑回归内部自动用交叉熵。
- ❌ 计算 `np.log(p)` 时 p=0 导致 `-inf`（NaN） → ✅ 正确：始终加一个小常数避免 log(0)，即 `np.log(p + 1e-15)`。1e-15 足够小不影响精度，又能防止数值爆炸。

## 章末小结

| 概念 | 一句话解释 | 易错点 |
|------|-----------|--------|
| 逻辑回归（Logistic Regression） | 线性回归 + sigmoid，用于二分类 | 名字里有"回归"但实际是分类算法 |
| Sigmoid 函数 | σ(z)=1/(1+e^(-z))，把实数压到(0,1) | 输入很大/很小时梯度趋近0（饱和区） |
| 交叉熵损失（Cross-Entropy） | 衡量预测概率分布与真实分布的差异 | 预测概率为0时log爆炸，必须加1e-15 |
| 决策边界（Decision Boundary） | p=0.5 的分界线，一侧判为1另一侧判为0 | 逻辑回归的决策边界一定是直线（超平面） |
| 维度匹配 | X shape=(n, d) 时 w 必须是 shape=(d,) | w 不能是标量，必须是数组 |
