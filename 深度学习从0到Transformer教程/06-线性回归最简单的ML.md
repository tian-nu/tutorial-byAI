# Ch06 · 线性回归 — 最简单的 ML

> 所属篇：第一篇 · 预计耗时：20 分钟

你朋友告诉你："我家80平米，卖了100万。"另一个朋友："我家120平米，卖了150万。"你猜100平米能卖多少？大概125万。你脑子里做的就是一个线性回归——找一条直线穿过这些数据点，然后用这条线来预测未知的数据。这一章我们把这件事用数学精确地写出来，并用代码从零实现。

---

## 为了什么（Why）

**核心痛点**：预测连续值（房价、温度、股价）是最常见的实际任务。线性回归是最简单、最可解释的模型——你能明确说出"每平米值多少钱"。

举个反例：你用一个有1000万参数的深度神经网络来预测房价。它可能预测得很准，但你完全不知道模型内部在干什么。如果预测出"每平米值-5万"，你也无法解释原因。线性回归的优势就是：**简单、可解释、够用**。

## 要做到（Goal）

- **输入**：特征矩阵 X（如面积），真实值向量 Y（如房价）。
- **输出**：参数 W 和 b，使得 `Ŷ = XW + b ≈ Y`。
- **成功标准**：MSE（均方误差）足够小，且参数 W 有合理的物理意义。

## 做了什么（What）

线性回归做的事情一句话概括：**找一条直线（或超平面），让它尽可能靠近所有数据点**。

```
房价(万)
  ^
  |        ● (120, 150)
  |      /
  |    /   ← 回归直线 ŷ = wx + b
  |  /
  |●         ●
  +-----------------> 面积(㎡)
   (50,60)  (80,100)
```

### 逐组件拆解

**权重 W（Weight）**：每个特征的"重要程度"。在一元线性回归中，W 就是直线的斜率——x 每增加1个单位，y 增加多少。比如 W=1.25 表示"每平米值1.25万"。

**偏置 b（Bias）**：基础值（截距）。当所有特征都为0时，y 的值。比如 b=3.75 表示"即使面积为0，也有3.75万的基准价"（现实中可能是地段费之类的）。

**MSE 损失（Mean Squared Error）**：每个点的预测误差平方后取平均。

`L = (1/n) × Σ(ŷ_i - y_i)²`

为什么用平方？① 保证误差都是正数（不会正负抵消）；② 大误差被放大（更惩罚离群点）。

## 怎么算（How）

### 核心公式

```
预测：ŷ = w × x + b
MSE损失：L = (1/n) × Σ(ŷ_i - y_i)²
梯度（对w）：∂L/∂w = (2/n) × Σ(ŷ_i - y_i) × x_i
梯度（对b）：∂L/∂b = (2/n) × Σ(ŷ_i - y_i)
更新规则：w = w - η × ∂L/∂w    （η 是学习率）
          b = b - η × ∂L/∂b
```

### 数值小例子：完整手推

数据：X = [1, 2, 3, 4]，Y = [2, 4, 6, 8]

这组数据完美符合 y = 2x（没有噪声）。我们来看看不同的参数会产生多大的误差。

**场景 A：参数 w=1.0, b=0**

逐点计算：

| 样本i | x_i | y_i(真实) | ŷ_i = 1×x_i+0 | 误差 = ŷ_i-y_i | (误差)² |
|-------|-----|-----------|---------------|----------------|---------|
| 0     | 1   | 2         | 1             | -1             | 1       |
| 1     | 2   | 4         | 2             | -2             | 4       |
| 2     | 3   | 6         | 3             | -3             | 9       |
| 3     | 4   | 8         | 4             | -4             | 16      |

MSE = (1 + 4 + 9 + 16) / 4 = **30 / 4 = 7.5**

**场景 B：参数 w=2.0, b=0**

逐点计算：

| 样本i | x_i | y_i(真实) | ŷ_i = 2×x_i+0 | 误差 = ŷ_i-y_i | (误差)² |
|-------|-----|-----------|---------------|----------------|---------|
| 0     | 1   | 2         | 2             | 0              | 0       |
| 1     | 2   | 4         | 4             | 0              | 0       |
| 2     | 3   | 6         | 6             | 0              | 0       |
| 3     | 4   | 8         | 8             | 0              | 0       |

MSE = (0 + 0 + 0 + 0) / 4 = **0** ✅ 完美拟合！

**场景 A 的梯度计算**（以 w=1.0 为起点，展示如何往正确方向调整）：

∂L/∂w = (2/4) × [(-1)×1 + (-2)×2 + (-3)×3 + (-4)×4]
       = 0.5 × [-1 + (-4) + (-9) + (-16)]
       = 0.5 × (-30)
       = **-15.0**

∂L/∂b = (2/4) × [-1 + (-2) + (-3) + (-4)]
       = 0.5 × (-10)
       = **-5.0**

注意：梯度是负数！这意味着增大 w 可以减小损失（因为预测值整体偏小）。更新：

假设学习率 η = 0.01：
- w_new = 1.0 - 0.01 × (-15.0) = 1.0 + 0.15 = **1.15**
- b_new = 0.0 - 0.01 × (-5.0) = 0.0 + 0.05 = **0.05**

w 从 1.0 变成了 1.15，向正确的方向（2.0）前进了一小步！重复这个过程几百次，w 就会收敛到 2.0。

### 解析解 vs 梯度下降

对于线性回归，其实有一个"一步到位"的公式（解析解）：

`W = (X^T X)^{-1} X^T Y`

这个公式的意思是：直接通过矩阵运算求出最优 W，不需要迭代。

**什么时候用什么？**

| 方法 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 解析解 | 一步到位，精确最优 | 需要求逆矩阵 O(n³)，特征多时极慢 | 特征少（< 10000） |
| 梯度下降 | 不需要求逆，可处理海量特征 | 需要调学习率，迭代多次 | 特征多（> 10000）、神经网络 |

## 怎么用（Use）

代码文件：`深度学习从0到Transformer教程/code/ch06_linear_regression.py`

关键片段：

```python
import numpy as np

# 数据：X=[1,2,3,4], Y=[2,4,6,8]（完美线性 y=2x）
X = np.array([[1], [2], [3], [4]], dtype=float)
y = np.array([[2], [4], [6], [8]], dtype=float)

# 初始化参数
w = 0.0
b = 0.0
lr = 0.01  # 学习率

# 梯度下降训练
for epoch in range(500):
    # 前向传播：计算预测值
    y_pred = X * w + b           # ŷ = wx + b

    # 计算损失（MSE）
    loss = np.mean((y_pred - y) ** 2)

    # 计算梯度
    dw = np.mean(2 * (y_pred - y) * X)  # ∂L/∂w
    db = np.mean(2 * (y_pred - y))       # ∂L/∂b

    # 更新参数
    w -= lr * dw
    b -= lr * db

print(f"w={w:.4f}, b={b:.4f}, loss={loss:.6f}")
```

## 想多一点

> 什么时候用解析解，什么时候用梯度下降？
>
> **特征数量是关键分界线**。特征少于 1 万时，解析解 `(X^T X)^{-1} X^T Y` 一行代码就算完了，又快又准。但特征超过 1 万时（比如图像处理，每个像素是一个特征），求一个 10000×10000 矩阵的逆需要约 10^12 次运算——普通电脑跑不动。这时候梯度下降就派上用场了：它不需要求逆，每次只看一小批数据就能更新参数，内存占用也小得多。
>
> 另外，神经网络根本不存在解析解（因为非线性激活函数的存在），所以梯度下降是唯一选择。

## 易错点预警

- ❌ 特征未归一化就直接跑梯度下降，导致收敛极慢甚至不收敛 → ✅ 正确做法：先做归一化 `(X - X.mean()) / X.std()`，让所有特征都在相近的数量级上。比如"面积80~120"和"房龄1~30"差距很大，不归一化的话面积特征的梯度会主导整个优化过程。
- ❌ 学习率设太大（如 η=1.0），loss 反而越来越大（发散） → ✅ 正确：从 η=0.01 开始尝试，观察 loss 曲线。如果 loss 下降太慢就适当加倍（如 0.02、0.05），如果 loss 开始震荡或上升就减半（如 0.005）。

## 章末小结

| 概念 | 一句话解释 | 易错点 |
|------|-----------|--------|
| 线性回归（Linear Regression） | 用 ŷ=wx+b 拟合数据，找最佳直线 | 假设数据呈线性关系，非线性数据效果差 |
| MSE（Mean Squared Error） | 均方误差，预测与真实的差的平方平均 | 对异常值敏感（平方会放大大误差） |
| 解析解（Closed-form Solution） | 用公式一步求出最优参数 | 特征多时矩阵求逆太慢 O(n³) |
| 梯度下降（Gradient Descent） | 迭代式地一步步逼近最优参数 | 学习率选择是关键，太大发散太小太慢 |
| 权重 W（Weight） | 每个特征的系数，表示重要程度 | 多元回归中不同特征的 W 不能直接比较大小（量纲不同） |
| 偏置 b（Bias） | 截距，当所有特征为0时的输出 | 不要忘记初始化和更新 b |
