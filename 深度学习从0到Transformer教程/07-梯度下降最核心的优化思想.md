# Ch07 · 梯度下降 — 最核心的优化思想

> 所属篇：第一篇 · 预计耗时：25 分钟

蒙眼下山。你不知道山底在哪，但你能用脚感受"哪边最陡"。你每次往最陡的下坡方向迈一小步，重复千百次，最终走到谷底。这就是梯度下降——深度学习所有训练的基石。不管你的模型是线性回归还是 GPT-4，训练的核心动作都是这一件事：**算梯度，沿负梯度方向走一小步**。

---

## 为了什么（Why）

**核心痛点**：神经网络有上亿个参数。上一章的线性回归可以一步求出解析解 `W = (X^T X)^{-1} X^T Y`，但 ResNet 有几千万参数——求一个几千万维矩阵的逆？计算量爆炸，内存也装不下。

我们需要一个"不依赖解析解、能处理任意参数量"的通用方法。梯度下降就是答案。

## 要做到（Goal）

- **输入**：损失函数 L(W)、初始参数 W₀、学习率 η。
- **输出**：使 L 最小的参数 W*。
- **成功标准**：loss 随迭代单调下降并收敛（不再明显变化）。

## 做了什么（What）

梯度下降在参数空间中的行为可以这样想象：

```
损失值(L)
   ^
   |     ● 起点 (w₀=5)
   |    / \
   |   /   \     ← 沿负梯度方向一步步往下走
   |  /     \
   | /       \  ● 终点 (w≈0, 谷底)
   |/         \
   +-------------> 参数 w
```

### 逐组件拆解

**梯度（Gradient）∇L**：损失对每个参数的偏导数组成的向量。它指向函数值**上升最快**的方向。所以我们取**负梯度**方向来下降。

`∇L = [∂L/∂w₁, ∂L/∂w₂, ...]`

**学习率 η（Learning Rate）**：每步走多远。太大→跨过谷底（发散），太小→走到天荒地老（收敛慢）。

**收敛（Convergence）**：当 loss 不再明显下降（或梯度接近0）时，认为已经到达或接近最优解。

## 怎么算（How）

### 核心公式

`W_{t+1} = W_t - η × ∇L(W_t)`

翻译成人话：新参数 = 旧参数 - 学习率 × 梯度

注意那个**减号**！因为梯度指向上升方向，我们要下降所以取反。

### 数值小例子：L(w) = w² 的完整10步

这是最简单的损失函数——一个抛物线，最小值在 w=0 处。

**设定**：
- 损失函数：L(w) = w²
- 初始参数：w₀ = 5.0
- 学习率：η = 0.1
- 梯度：∇L = d(w²)/dw = **2w**

**逐步展开（前10步）**：

| 步骤 t | 当前 w_t | 梯度 2×w_t | 更新量 η×梯度 | 新 w_{t+1} | 损失 L=w² |
|--------|----------|-----------|-------------|-----------|----------|
| 0      | 5.000    | 10.000    | 1.000       | **4.000** | 25.00    |
| 1      | 4.000    | 8.000     | 0.800       | **3.200** | 16.00    |
| 2      | 3.200    | 6.400     | 0.640       | **2.560** | 10.24    |
| 3      | 2.560    | 5.120     | 0.512       | **2.048** | 6.55     |
| 4      | 2.048    | 4.096     | 0.410       | **1.638** | 4.20     |
| 5      | 1.638    | 3.277     | 0.328       | **1.311** | 2.68     |
| 6      | 1.311    | 2.621     | 0.262       | **1.049** | 1.72     |
| 7      | 1.049    | 2.098     | 0.210       | **0.839** | 1.10     |
| 8      | 0.839    | 1.678     | 0.168       | **0.671** | 0.70     |
| 9      | 0.671    | 1.342     | 0.134       | **0.537** | 0.45     |

**继续到第50步和第100步**：

| 步骤 | w 值        | 损失 L      |
|------|-------------|------------|
| 10   | ≈ 0.537     | ≈ 0.29     |
| 20   | ≈ 0.1215    | ≈ 0.0148   |
| 30   | ≈ 0.0275    | ≈ 0.00076  |
| 40   | ≈ 0.0062    | ≈ 0.000039 |
| 50   | ≈ 0.0014    | ≈ 0.000002 |
| 100  | ≈ 0.0000019 | ≈ 3.6e-12  |

可以看到：w 从 5.0 一点点趋近于 0，损失从 25.0 一点点趋近于 0。每一步都在变小，但**减小的速度越来越慢**（因为越接近谷底，坡度越缓/梯度越小）。这就是梯度下降的基本节奏。

### 三种学习率的对比

同样的起点 w₀=5.0，不同的学习率效果完全不同：

**η = 0.01（太小——收敛极慢）**

| 步骤 | w 值    | 说明 |
|------|---------|------|
| 0    | 5.000   | 起点 |
| 50   | ≈ 1.90  | 才走了不到一半！|
| 500  | ≈ 0.007  | 还没完全收敛 |

每步只挪一点点，像蜗牛爬。虽然不会发散，但太慢了。

**η = 0.1（合适——稳步收敛）**

就是上面展示的结果：50步后 w≈0.0014，基本到位。

**η = 1.1（太大——发散！）**

| 步骤 | 计算过程                    | w 值    |
|------|----------------------------|---------|
| 0    | 起点                       | 5.000   |
| 1    | 5 - 1.1×(2×5) = 5 - 11    | **-6.0** |
| 2    | -6 - 1.1×(2×(-6)) = -6 +13.2 | **7.2**  |
| 3    | 7.2 - 1.1×(2×7.2) = 7.2 -15.84 | **-8.64** |

w 在正负之间疯狂震荡，而且绝对值越来越大——这就是**发散**，永远到不了谷底！

### 鞍点（Saddle Point）

你可能想问：梯度为0的地方一定是最低点吗？

**不一定！** 还有一种情况叫鞍点——某个方向是山谷，另一个方向是山脊，整体看起来像个马鞍：

```
     山脊(上升) →
        ↗
       /
  ←山谷(下降)
```

在鞍点处，梯度确实为0，但它不是最小值。好消息是：在高维空间中（深度学习的参数空间通常是几万甚至几百万维），鞍点的概率远大于局部最小值的概率。而随机梯度下降（SGD）中的噪声通常能帮你"晃"出鞍点。所以**鞍点是深度学习中比局部最优更常见的"卡点"**。

## 怎么用（Use）

代码文件：`深度学习从0到Transformer教程/code/ch07_gradient_descent.py`

关键片段：

```python
import numpy as np

# 损失函数: L(w) = w²
def loss_fn(w):
    return w ** 2

# 梯度: dL/dw = 2w
def gradient(w):
    return 2 * w

# 梯度下降
w = 5.0          # 初始值
lr = 0.1         # 学习率
steps = 100      # 迭代次数

for step in range(steps):
    grad = gradient(w)
    w = w - lr * grad  # 关键：减号！
    if step % 10 == 0:
        print(f"step {step:3d}: w={w:.6f}, L={loss_fn(w):.8f}")

print(f"final: w={w:.8f}")
```

## 想多一点

> 梯度下降找到的"谷底"一定是全局最优吗？
>
> **不一定。** 这取决于损失函数的形状。
>
> - **凸函数**（如 L=w²）：只有一个谷底，梯度下降一定能找到全局最优 ✅
> - **非凸函数**（如神经网络的损失曲面）：有多个局部最优和大量鞍点，梯度下降可能停在局部最优 ⚠️
>
> 但实际经验告诉我们：**深度学习中局部最优通常够好**。真正让人头疼的不是局部最优，而是**鞍点**——高维空间中鞍点远多于局部最小值，SGD 的随机性通常能帮你滑过鞍点。这也是为什么大家更关心学习率调度、batch size 这些超参数，而不是全局最优问题。

## 易错点预警

- ❌ 学习率设成 1.0 或更大，导致 loss 越来越大（发散） → ✅ 正确做法：从 0.01 开始观察 loss 曲线。如果下降太慢就加倍（0.02、0.05、0.1），一旦发现 loss 震荡或上升就立刻减半（0.005、0.001）。
- ❌ 忘记取负梯度方向，写成 `w = w + lr * grad` → ✅ 正确：`w = w - lr * grad`（减号！）。梯度指向上升方向，要往下降就得取反。这个符号错误是最常见的新手 bug 之一。

## 章末小结

| 概念 | 一句话解释 | 易错点 |
|------|-----------|--------|
| 梯度（Gradient） | 损失对每个参数的偏导数组成的向量 | 梯度指向**上升最快**方向，要取**负梯度**才能下降 |
| 学习率 η（Learning Rate） | 每步沿梯度方向走多远 | 太大发散，太小太慢，需要仔细调参 |
| 收敛（Convergence） | loss 不再明显下降的状态 | 收敛不等于到了全局最优，可能停在局部最优或鞍点 |
| 鞍点（Saddle Point） | 梯度为0但不是极值点（像马鞍形状） | 高维空间中远比局部最优常见，是深度学习的主要"卡点" |
| 局部最优（Local Minimum） | 某区域内的最低点，但不一定是全局最低 | 深度学习中局部最优通常够用，不必过度担心 |
| 全局最优（Global Minimum） | 整个参数空间中损失最小的点 | 凸函数才有保证能找到，非凸函数不保证 |
