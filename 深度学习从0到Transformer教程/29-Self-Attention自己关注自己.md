# Ch29 · Self-Attention 自己关注自己

> 所属篇：第五篇 · 预计耗时：35 分钟

Ch28 的 Attention 是 Decoder 看 Encoder——两个序列之间的注意力。那如果一句话自己看自己呢？"我爱深度学习"里"爱"要理解"我"是谁，"学习"要理解"深度"是什么。如果让序列内每个位置都能直接看其他所有位置，距离就不再是问题——任意两步之间一步直达，O(1) 的距离。这就是 Self-Attention，2017 年《Attention Is All You Need》论文的核心。它扔掉了 RNN 的循环结构，让每个词同时和所有词算注意力。Transformer 的全部魔法就从这里开始。

---

## 为了什么（Why）

**核心痛点**：RNN 靠时间步传递信息，长距离依赖靠 LSTM 缓解但仍有瓶颈——信息要一步步传，距离越远衰减越严重。

**举个反例**：处理"The cat, which already ate fish, was full"这句话。"was"要关联到"cat"（主语），但中间隔了 6 个词。RNN 要把"cat"的信息从第 1 步传到第 8 步，每一步都要过 LSTM 的门控，6 步之后哪怕 LSTM 也难保信息不衰减。

**Self-Attention 的解法**：让"was"直接和"cat"算一次注意力，距离是 O(1)，不管中间隔几个词。每个词都能一步直达其他任意词。这就是 Transformer 比 RNN 强的根本原因——并行 + 长距离友好。

**这一章的目标**：理解 Q/K/V 三个矩阵的来源，能手算一个 3×2 的 Self-Attention 完整流程，知道为什么要除以 √d_k。

## 要做到（Goal）

- **输入**：Ch28 的 Attention 概念、Ch01 的矩阵乘法、知道 softmax 怎么算。
- **输出**：理解 Q/K/V 三矩阵，能手算 Self-Attention 输出。
- **成功标准**：给定 3×2 的输入矩阵，能算出 `Attention(Q,K,V)` 输出的第 1 行是 `[0.749, 0.458]`。

## 做了什么（What）

Self-Attention 的核心思想：**输入序列 X 自己对自己做 Attention**。X 通过三个权重矩阵 `W_Q, W_K, W_V` 投影成 Q、K、V 三个矩阵，然后 `Attention(Q,K,V) = softmax(QK^T / √d_k) · V`。

打个比方：Self-Attention 像开一个圆桌会议，每个词都发言一次。每个词同时扮演三个角色：
- **Q（Query，提问视角）**：我这个位置"想问什么"
- **K（Key，标签视角）**：我这个位置"能答什么"
- **V（Value，内容视角）**：我这个位置"具体答案是什么"

每个词用自己的 Q 去和所有词的 K 算相似度（点积），得到一组 attention 权重，再用权重对所有词的 V 加权求和。结果就是这个位置的"新表示"——它融合了所有相关词的信息。

```
                X (输入矩阵, T×d)
                │
        ┌───────┼───────┐
        ▼       ▼       ▼
       X·W_Q  X·W_K  X·W_V
        │       │       │
        ▼       ▼       ▼
        Q       K       V
        │       │       │
        └───┬───┘       │
            ▼           │
       QK^T / √d_k      │
            │           │
            ▼           │
        softmax         │
            │           │
            ▼           │
        attention 权重  │
            │           │
            └─────┬─────┘
                  ▼
              权重 · V
                  │
                  ▼
            输出 (T×d_v)
```

### 逐组件拆解

**Query (Q)**：`Q = X · W_Q`，形状 `(T, d_k)`。每一行是"这个位置想问什么"。`W_Q` 是 `(d_model, d_k)` 的可学习矩阵。

**Key (K)**：`K = X · W_K`，形状 `(T, d_k)`。每一行是"这个位置能答什么"。`W_K` 也是 `(d_model, d_k)`。

**Value (V)**：`V = X · W_V`，形状 `(T, d_v)`。每一行是"这个位置的具体答案"。`W_V` 是 `(d_model, d_v)`。通常 `d_k = d_v = d_model / h`（h 是头数，见 Ch30）。

**缩放因子 √d_k**：点积 `QK^T` 除以 `√d_k`。**为什么要除以这个数，下一节专门讲。**

**注意力矩阵**：`softmax(QK^T / √d_k)`，形状 `(T, T)`。每行是一个 query 对所有 key 的权重分布，和为 1。

**输出**：`softmax(QK^T / √d_k) · V`，形状 `(T, d_v)`。每个位置的输出是所有位置 V 的加权求和。

## 怎么算（How）

### 核心公式

```
Attention(Q, K, V) = softmax(QK^T / √d_k) · V
```

其中：

```
Q = X · W_Q
K = X · W_K
V = X · W_V
```

### 为什么除以 √d_k 而不是 d_k？

这是 Self-Attention 最容易被忽略但很关键的设计。推导如下：

假设 Q 和 K 的各分量独立、均值 0、方差 1（这是训练初期常见的状态）。那么点积 `q · k = Σ_{i=1}^{d_k} q_i · k_i`：

- 每个 `q_i · k_i` 是两个独立标准正态的乘积，均值 0、方差 1
- `d_k` 个独立项求和，**方差等于 d_k**，标准差等于 √d_k

也就是说：**点积的方差与 d_k 成正比**。`d_k` 越大，点积数值的波动范围越大。

如果直接把点积喂给 softmax 会怎样？

- 点积数值大 → softmax 输入的差距大 → softmax 输出接近 one-hot（最大的项接近 1，其他接近 0）
- softmax 在 one-hot 区域梯度趋近于 0 → **梯度消失**，模型训不动

所以需要把点积"拉回"到方差为 1 的尺度。除以 √d_k 后：

- 新方差 = 原方差 / (√d_k)² = d_k / d_k = 1
- 数值稳定，softmax 输出不会变成 one-hot

**为什么不是除以 d_k？** 因为除以 √d_k 已经让方差回到 1 了——再除以 d_k 就过度缩放，点积数值会被压得太小，softmax 输出接近均匀分布，**失去区分能力**。√d_k 是"刚好让方差回到 1"的缩放因子，是从概率论严格推出来的，不是拍脑袋。

### 数值小例子（3 个词，2 维嵌入，d_k=2）

设：
```
X = [[1.0, 0.5],     # 第 1 个词
     [0.3, 0.7],     # 第 2 个词
     [0.8, 0.2]]     # 第 3 个词
```

简化假设：`W_Q = W_K = W_V = I_2`（2 阶单位矩阵），即 `Q = K = V = X`。这样能突出 Self-Attention 的结构，不被权重干扰。实际训练时 W 是可学习参数。

**第 1 步：算 QK^T**

`QK^T = X · X^T`，逐元素算：

- `[0][0] = 1.0×1.0 + 0.5×0.5 = 1.0 + 0.25 = 1.25`
- `[0][1] = 1.0×0.3 + 0.5×0.7 = 0.3 + 0.35 = 0.65`
- `[0][2] = 1.0×0.8 + 0.5×0.2 = 0.8 + 0.10 = 0.90`
- `[1][0] = 0.3×1.0 + 0.7×0.5 = 0.3 + 0.35 = 0.65`（对称）
- `[1][1] = 0.3×0.3 + 0.7×0.7 = 0.09 + 0.49 = 0.58`
- `[1][2] = 0.3×0.8 + 0.7×0.2 = 0.24 + 0.14 = 0.38`
- `[2][0] = 0.8×1.0 + 0.2×0.5 = 0.8 + 0.10 = 0.90`（对称）
- `[2][1] = 0.8×0.3 + 0.2×0.7 = 0.24 + 0.14 = 0.38`（对称）
- `[2][2] = 0.8×0.8 + 0.2×0.2 = 0.64 + 0.04 = 0.68`

所以：

```
QK^T = [[1.25, 0.65, 0.90],
        [0.65, 0.58, 0.38],
        [0.90, 0.38, 0.68]]
```

注意矩阵是对称的（因为 Q=K=X）。

**第 2 步：除以 √d_k**

`d_k = 2`，`√d_k = √2 ≈ 1.4142`

```
QK^T / √d_k = [[1.25/1.4142, 0.65/1.4142, 0.90/1.4142],
                [0.65/1.4142, 0.58/1.4142, 0.38/1.4142],
                [0.90/1.4142, 0.38/1.4142, 0.68/1.4142]]
            = [[0.884, 0.460, 0.636],
               [0.460, 0.410, 0.269],
               [0.636, 0.269, 0.481]]
```

**第 3 步：对每行做 softmax**

> ⚠️ **维度**：每行是一个 query 对所有 key 的权重，所以对**每行**做 softmax，不是对整列做。这个最容易搞错。

以第 1 行 `[0.884, 0.460, 0.636]` 为例：

- 减最大值（数值稳定）：`[0.884-0.884, 0.460-0.884, 0.636-0.884] = [0, -0.424, -0.248]`
- exp：`[exp(0)=1.000, exp(-0.424)=0.654, exp(-0.248)=0.780]`
- 总和：`1.000 + 0.654 + 0.780 = 2.434`
- 归一化：`α_1 = [1.000/2.434, 0.654/2.434, 0.780/2.434] = [0.411, 0.269, 0.321]`

同理算出第 2 行和第 3 行（详细数字略，代码里会打印），最终：

```
attention 权重 α ≈ [[0.411, 0.269, 0.321],
                    [0.345, 0.385, 0.271],
                    [0.388, 0.244, 0.368]]
```

**第 4 步：用 α 对 V 加权求和**

`V = X`，所以输出 = α · X。

第 1 行输出：

```
out[0] = 0.411 × [1.0, 0.5] + 0.269 × [0.3, 0.7] + 0.321 × [0.8, 0.2]
```

逐维算：

- `out[0][0] = 0.411×1.0 + 0.269×0.3 + 0.321×0.8 = 0.411 + 0.0807 + 0.2568 = 0.749`
- `out[0][1] = 0.411×0.5 + 0.269×0.7 + 0.321×0.2 = 0.2055 + 0.1883 + 0.0642 = 0.458`

所以 `out[0] ≈ [0.749, 0.458]`（用 3 位小数 α 手算的近似值；全精度计算为 `[0.748, 0.458]`，差异来自分步四舍五入，代码里以全精度为准）。

**直觉解读**：第 1 个词的新表示是三个词的加权融合——41.1% 来自自己（最大权重），27% 来自第 2 个词，32% 来自第 3 个词。原始表示 `[1.0, 0.5]` 被柔化成 `[0.749, 0.458]`，吸收了上下文信息。

## 怎么用（Use）

代码文件：`深度学习从0到Transformer教程/code/ch29_self_attention.py`

关键片段：

```python
import numpy as np

def softmax(x, axis=-1):
    """数值稳定的 softmax。"""
    x = x - np.max(x, axis=axis, keepdims=True)
    e = np.exp(x)
    return e / e.sum(axis=axis, keepdims=True)

def self_attention(X, WQ, WK, WV):
    Q, K, V = X @ WQ, X @ WK, X @ WV
    d_k = K.shape[-1]
    scores = Q @ K.T / np.sqrt(d_k)   # 缩放
    alpha = softmax(scores, axis=-1)   # 对每行做 softmax
    return alpha @ V, alpha

X = np.array([[1.0, 0.5], [0.3, 0.7], [0.8, 0.2]])
W = np.eye(2)  # 简化为单位矩阵
out, alpha = self_attention(X, W, W, W)
print(alpha[0])  # [0.411, 0.269, 0.321]
print(out[0])    # [0.749, 0.458]
```

## 想多一点

> 为什么 Q、K、V 要用三个不同的矩阵投影，而不是直接用 X？
>
> 答案是：**投影让模型能学习"以不同视角看自己"**。如果直接用 X，那 Q=K=V 永远相同，每个位置的"想问什么"和"能答什么"完全耦合，模型学不到"我用 A 视角提问、用 B 视角匹配、用 C 视角给答案"的灵活能力。三个独立的 `W_Q, W_K, W_V` 让模型能学会：
> - 用 Q 视角表达"我想找什么类型的信息"
> - 用 K 视角表达"我能提供什么类型的信息"
> - 用 V 视角表达"具体的内容是什么"
>
> 这三种视角是同一份数据 X 的不同"投影"，类似你在不同光线下看同一物体——投影矩阵就是"打光的角度"。

## 易错点预警

- ❌ 忘记除以 √d_k → ✅ 正确：必须缩放，否则点积过大让 softmax 进入饱和区，梯度消失。√d_k 不是随便选的，是从方差分析严格推出来的。
- ❌ softmax 维度搞错，对列做而非对行做 → ✅ 正确：对**每行**做 softmax。每行是一个 query 对所有 key 的权重，和必须为 1。PyTorch 里写 `softmax(scores, dim=-1)`。
- ❌ 把 `QK^T` 写成 `KQ^T` → ✅ 正确：`QK^T` 形状是 `(T_q, T_k)`，第 i 行第 j 列是"第 i 个 query 对第 j 个 key 的分数"。搞反了形状会变成 `(T_k, T_q)`，结果完全不同。
- ❌ W_Q, W_K, W_V 形状写错 → ✅ 正确：`W_Q` 是 `(d_model, d_k)`，X 是 `(T, d_model)`，所以 `X @ W_Q` 形状 `(T, d_k)`。

## 章末小结

| 组件 | 公式 | 作用 | 维度 |
|------|------|------|------|
| Q（Query） | `Q = X · W_Q` | 提问视角 | `(T, d_k)` |
| K（Key） | `K = X · W_K` | 匹配视角 | `(T, d_k)` |
| V（Value） | `V = X · W_V` | 内容视角 | `(T, d_v)` |
| 缩放因子 | `/ √d_k` | 让点积方差回到 1，防止 softmax 饱和 | 标量 |
| 注意力矩阵 | `softmax(QK^T / √d_k)` | 每行是一个 query 对所有 key 的权重 | `(T, T)` |
| 输出 | `α · V` | 所有位置 V 的加权求和 | `(T, d_v)` |
