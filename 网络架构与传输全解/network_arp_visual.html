ARP 交互日志

准备PC-A 查看本机 ARP 缓存 — 没有 192.168.1.5 的记录
广播PC-A 广播 ARP 请求："谁是 192.168.1.5？"（目标 MAC = FF:FF:FF:FF:FF:FF）
泛洪交换机收到广播帧 → 泛洪到所有端口（除来源端口）
检查PC-B 收到：目标 IP = 192.168.1.5 ✓ 这就是我！PC-C 收到：目标 IP ≠ 自己 → 丢弃
单播PC-B 单播 ARP 响应："我是 192.168.1.5，MAC = BB:BB:BB:BB:BB:BB" → 发给 PC-A
完成PC-A 收到 ARP 响应 → 写入 ARP 缓存：192.168.1.5 → BB:BB:BB:BB:BB:BB
