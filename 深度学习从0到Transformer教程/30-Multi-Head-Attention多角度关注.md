# Ch30 · Multi-Head Attention 多角度关注

> 所属篇：第五篇 · 预计耗时：30 分钟

一句话里同时有好多层关系。"猫追老鼠"里"追"既要关联"猫"（主语），也要关联"老鼠"（宾语）。"我爱深度学习"里"爱"要绑定"我"（施事者），"学习"要绑定"深度"（修饰关系）。一个 Self-Attention 头只能学一种注意力模式，硬让它同时学主谓、动宾、修饰，它会顾此失彼。Multi-Head Attention 的解法简单粗暴：**派多个翻译官同时干活，每个头关注一种关系，最后汇总**。这是 Transformer 论文里最巧妙的设计之一——把 `d_model` 维向量拆成 `h` 个子空间，每个子空间独立做 Self-Attention，并行捕捉不同关系。

---

## 为了什么（Why）

**核心痛点**：单头 Self-Attention 只能学一种注意力模式。语言里同时存在语法关系（主谓宾）、语义关系（同义反义）、指代关系（"他"指谁）等多重结构，一个头装不下。

**举个反例**：用单头 Self-Attention 处理"The animal didn't cross the street because it was too tired"。"it" 指代 "animal" 还是 "street"？单头 Attention 只能学一组 Q/K/V 权重，要兼顾"指代关系"和"语法关系"，权重容易打架，注意力分散，效果打折。

**Multi-Head 的解法**：让 8 个头并行，每个头学一种关系——可能第 1 个头专门抓指代，第 2 个头专门抓主谓，第 3 个头抓修饰……每个头在自己 64 维子空间里独立算 Self-Attention，最后把 8 个头的输出拼起来过一层线性变换。

**这一章的目标**：理解多头并行的拆分、计算、拼接流程，能用 PyTorch 实现 Multi-Head Attention，能手算一个 2 头小例子。

## 要做到（Goal）

- **输入**：Ch29 的 Self-Attention、知道矩阵分块。
- **输出**：理解多头并行的计算和拼接，能用 PyTorch 实现 Multi-Head Attention。
- **成功标准**：给定 `h=2 头`、`d_model=4`、3 个词，能说出每个头维度 `d_k=2`，能手算头 1 和头 2 的输出，再算出拼接后的最终输出。

## 做了什么（What）

Multi-Head 的核心思想：**把高维向量切成多个低维子空间，每个子空间独立做 Self-Attention，最后拼回高维**。

打个比方：你要翻译一句话，单个翻译官可能只关注字面意思。如果你派 8 个翻译官同时翻译——一个关注语法、一个关注语义、一个关注指代、一个关注语气、一个关注人名地名……每个翻译官独立思考，最后汇总成一份译稿。这就是 Multi-Head Attention。

```
                  X (T × d_model)
                  │
        ┌─────────┴─────────┐
        │  W_Q, W_K, W_V 投影 │
        └─────────┬─────────┘
                  │
       ┌──────────┼──────────┐
       ▼          ▼          ▼
       Q          K          V     (都是 T × d_model)
       │          │          │
   ┌───┴───┐  ┌───┴───┐  ┌───┴───┐
   │拆 h 头 │  │拆 h 头 │  │拆 h 头 │  (每头 d_k = d_model/h)
   └───┬───┘  └───┬───┘  └───┬───┘
       │          │          │
   头1: Q_1,K_1,V_1  ──> Attention ──> out_1   (T × d_k)
   头2: Q_2,K_2,V_2  ──> Attention ──> out_2   (T × d_k)
       ...           ...            ...
   头h: Q_h,K_h,V_h  ──> Attention ──> out_h   (T × d_k)
       │
       ▼
   Concat(out_1, ..., out_h)  (T × d_model)
       │
       ▼
   W_O 线性变换
       │
       ▼
   最终输出 (T × d_model)
```

### 逐组件拆解

**头数 h**：把 `d_model` 维拆成几份。原始论文用 `h=8`，BERT-base 用 `h=12`，大模型用更多。`h` 必须能整除 `d_model`。

**每头维度 d_k**：`d_k = d_model / h`。原始论文 `d_model=512, h=8`，每头 64 维。

**每头独立权重**：每个头有自己的 `W_Q^i, W_K^i, W_V^i`（形状都是 `d_model × d_k`）。在 PyTorch 实现里通常合并成一个大矩阵 `W_Q` 形状 `d_model × d_model`，然后 `view` 成 `(B, T, h, d_k)` 再 `transpose` 把头维度提前。

**拼接 Concat**：把 `h` 个头的输出沿特征维拼起来，形状从 `h × (T, d_k)` 变成 `(T, h·d_k) = (T, d_model)`。

**输出投影 W_O**：拼接后再过一层线性变换 `W_O`（`d_model × d_model`），让头之间的信息能混合。`W_O` 是可学习的。

## 怎么算（How）

### 核心公式

```
MultiHead(Q, K, V) = Concat(head_1, ..., head_h) · W_O

其中 head_i = Attention(Q · W_Q^i, K · W_K^i, V · W_V^i)
            = softmax(Q_i · K_i^T / √d_k) · V_i
```

### 数值小例子（2 头，d_model=4，d_k=2，3 个词）

设：
```
X = [[1.0, 0.5, 0.3, 0.7],     # 第 1 个词
     [0.2, 0.8, 0.4, 0.6],     # 第 2 个词
     [0.9, 0.1, 0.5, 0.5]]     # 第 3 个词
```

形状 `(3, 4)`，`d_model = 4`。`h = 2`，所以 `d_k = 4/2 = 2`。

**拆分**：把 X 沿特征维切成两半。
- 头 1 用前 2 维：`X_1 = [[1.0, 0.5], [0.2, 0.8], [0.9, 0.1]]`
- 头 2 用后 2 维：`X_2 = [[0.3, 0.7], [0.4, 0.6], [0.5, 0.5]]`

**简化假设**：每个头的 `W_Q = W_K = W_V = I_2`（单位矩阵），即 `Q = K = V = X_i`。这样能突出多头结构本身，不被权重干扰。

### 头 1 做 Self-Attention

**第 1 步：算 QK^T = X_1 · X_1^T**

逐元素算：

- `[0][0] = 1.0×1.0 + 0.5×0.5 = 1.0 + 0.25 = 1.25`
- `[0][1] = 1.0×0.2 + 0.5×0.8 = 0.2 + 0.4 = 0.60`
- `[0][2] = 1.0×0.9 + 0.5×0.1 = 0.9 + 0.05 = 0.95`
- `[1][1] = 0.2×0.2 + 0.8×0.8 = 0.04 + 0.64 = 0.68`
- `[1][2] = 0.2×0.9 + 0.8×0.1 = 0.18 + 0.08 = 0.26`
- `[2][2] = 0.9×0.9 + 0.1×0.1 = 0.81 + 0.01 = 0.82`

```
QK^T_1 = [[1.25, 0.60, 0.95],
          [0.60, 0.68, 0.26],
          [0.95, 0.26, 0.82]]
```

**第 2 步：除以 √d_k**

`√d_k = √2 ≈ 1.4142`

```
QK^T_1 / √d_k = [[0.884, 0.424, 0.672],
                 [0.424, 0.481, 0.184],
                 [0.672, 0.184, 0.580]]
```

**第 3 步：每行 softmax**

第 1 行 `[0.884, 0.424, 0.672]`：
- exp: `[2.421, 1.528, 1.958]`，和 = 5.907
- α_1 = [0.410, 0.259, 0.331]

第 2 行 `[0.424, 0.481, 0.184]`：
- exp: `[1.528, 1.618, 1.202]`，和 = 4.348
- α_2 = [0.351, 0.372, 0.276]

第 3 行 `[0.672, 0.184, 0.580]`：
- exp: `[1.958, 1.202, 1.786]`，和 = 4.946
- α_3 = [0.396, 0.243, 0.361]

**第 4 步：用 α 对 V_1 = X_1 加权求和**

`out_1 = α · X_1`

第 1 行：
- `out_1[0][0] = 0.410×1.0 + 0.259×0.2 + 0.331×0.9 = 0.410 + 0.0518 + 0.2979 = 0.7597 ≈ 0.760`
- `out_1[0][1] = 0.410×0.5 + 0.259×0.8 + 0.331×0.1 = 0.205 + 0.2072 + 0.0331 = 0.4453 ≈ 0.445`

第 2 行：
- `out_1[1][0] = 0.351×1.0 + 0.372×0.2 + 0.276×0.9 = 0.351 + 0.0744 + 0.2484 = 0.6738 ≈ 0.673`
- `out_1[1][1] = 0.351×0.5 + 0.372×0.8 + 0.276×0.1 = 0.1755 + 0.2976 + 0.0276 = 0.5007 ≈ 0.502`

第 3 行：
- `out_1[2][0] = 0.396×1.0 + 0.243×0.2 + 0.361×0.9 = 0.396 + 0.0486 + 0.3249 = 0.7695 ≈ 0.770`
- `out_1[2][1] = 0.396×0.5 + 0.243×0.8 + 0.361×0.1 = 0.198 + 0.1944 + 0.0361 = 0.4285 ≈ 0.428`

**头 1 输出**：

```
out_1 ≈ [[0.760, 0.445],
         [0.673, 0.502],
         [0.770, 0.428]]
```

### 头 2 做 Self-Attention

**第 1 步：算 QK^T = X_2 · X_2^T**

`X_2 = [[0.3, 0.7], [0.4, 0.6], [0.5, 0.5]]`

逐元素算：

- `[0][0] = 0.3×0.3 + 0.7×0.7 = 0.09 + 0.49 = 0.58`
- `[0][1] = 0.3×0.4 + 0.7×0.6 = 0.12 + 0.42 = 0.54`
- `[0][2] = 0.3×0.5 + 0.7×0.5 = 0.15 + 0.35 = 0.50`
- `[1][1] = 0.4×0.4 + 0.6×0.6 = 0.16 + 0.36 = 0.52`
- `[1][2] = 0.4×0.5 + 0.6×0.5 = 0.20 + 0.30 = 0.50`
- `[2][2] = 0.5×0.5 + 0.5×0.5 = 0.25 + 0.25 = 0.50`

```
QK^T_2 = [[0.58, 0.54, 0.50],
          [0.54, 0.52, 0.50],
          [0.50, 0.50, 0.50]]
```

注意三个词的 X_2 各分量很接近（都在 0.3~0.7 之间），所以点积分布很均匀。

**第 2 步：除以 √d_k**

```
QK^T_2 / √d_k = [[0.410, 0.382, 0.354],
                 [0.382, 0.368, 0.354],
                 [0.354, 0.354, 0.354]]
```

**第 3 步：每行 softmax**

第 1 行 `[0.410, 0.382, 0.354]`：
- exp: `[1.507, 1.465, 1.425]`，和 = 4.397
- α_1 = [0.343, 0.333, 0.324]

第 2 行 `[0.382, 0.368, 0.354]`：
- exp: `[1.465, 1.445, 1.425]`，和 = 4.335
- α_2 = [0.338, 0.333, 0.329]

第 3 行 `[0.354, 0.354, 0.354]`：三值相等
- exp: 三个相等，归一化后各占 1/3
- α_3 = [0.333, 0.333, 0.333]

**第 4 步：用 α 对 V_2 = X_2 加权求和**

第 1 行：
- `out_2[0][0] = 0.343×0.3 + 0.333×0.4 + 0.324×0.5 = 0.1029 + 0.1332 + 0.1620 = 0.3981 ≈ 0.398`
- `out_2[0][1] = 0.343×0.7 + 0.333×0.6 + 0.324×0.5 = 0.2401 + 0.1998 + 0.1620 = 0.6019 ≈ 0.602`

第 2 行：
- `out_2[1][0] = 0.338×0.3 + 0.333×0.4 + 0.329×0.5 = 0.1014 + 0.1332 + 0.1645 = 0.3991 ≈ 0.399`
- `out_2[1][1] = 0.338×0.7 + 0.333×0.6 + 0.329×0.5 = 0.2366 + 0.1998 + 0.1645 = 0.6009 ≈ 0.602`

第 3 行：
- `out_2[2][0] = 0.333×0.3 + 0.333×0.4 + 0.333×0.5 = 0.0999 + 0.1332 + 0.1665 = 0.3996 ≈ 0.400`
- `out_2[2][1] = 0.333×0.7 + 0.333×0.6 + 0.333×0.5 = 0.2331 + 0.1998 + 0.1665 = 0.5994 ≈ 0.600`

**头 2 输出**：

```
out_2 ≈ [[0.398, 0.602],
         [0.399, 0.602],
         [0.400, 0.600]]
```

### 拼接 Concat

把头 1 和头 2 的输出沿特征维拼起来，形状 `(3, 4)`：

```
concat = [[0.760, 0.445, 0.398, 0.602],
          [0.673, 0.502, 0.399, 0.602],
          [0.770, 0.428, 0.400, 0.600]]
```

前 2 列来自头 1，后 2 列来自头 2。

### 输出投影 W_O

简化假设：`W_O = I_4`（4 阶单位矩阵），则最终输出 = concat · I_4 = concat：

```
最终输出 ≈ [[0.760, 0.445, 0.398, 0.602],
            [0.673, 0.502, 0.399, 0.602],
            [0.770, 0.428, 0.400, 0.600]]
```

### 关键观察：两个头的输出对比

- **头 1（前 2 列）**：数值波动较大（0.673~0.770），因为 `X_1` 各行差异大（第 1 行 `[1.0, 0.5]` 和第 2 行 `[0.2, 0.8]` 截然不同），attention 权重有明显偏向。
- **头 2（后 2 列）**：数值接近均匀（0.398~0.400），因为 `X_2` 各行相似（都在 0.3~0.7 之间），attention 权重几乎均分，输出退化成三行的平均。

这就是 Multi-Head 的价值：**不同头关注不同子空间**。在这个例子里，头 1 学到了"位置 1 和位置 3 强相关"的模式（α_1 第 1 项 0.410 最大），头 2 几乎学不到模式（因为输入太相似）。在大模型里，不同头会分化成关注语法、指代、修饰等不同关系的"专家"。

## 怎么用（Use）

代码文件：`深度学习从0到Transformer教程/code/ch30_multi_head_attention.py`

关键片段（PyTorch 标准实现）：

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        assert d_model % n_heads == 0, "d_model 必须能被 n_heads 整除"
        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, x):
        B, T, _ = x.shape
        # 投影 + 拆头: (B, T, d_model) -> (B, n_heads, T, d_k)
        Q = self.W_q(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        K = self.W_k(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        V = self.W_v(x).view(B, T, self.n_heads, self.d_k).transpose(1, 2)
        # 注意力: (B, n_heads, T, d_k)
        scores = Q @ K.transpose(-2, -1) / (self.d_k ** 0.5)
        attn = F.softmax(scores, dim=-1)
        out = attn @ V
        # 拼头: (B, n_heads, T, d_k) -> (B, T, d_model)
        out = out.transpose(1, 2).contiguous().view(B, T, self.d_model)
        return self.W_o(out)

mha = MultiHeadAttention(d_model=512, n_heads=8)
x = torch.randn(2, 10, 512)
print(mha(x).shape)  # torch.Size([2, 10, 512])
```

## 想多一点

> 头数越多越好吗？
>
> 答案是：**不是**。头数过多有两个问题：
> 1. **每头维度太小**：`d_k = d_model / h`。如果 `d_model=512, h=64`，则 `d_k=8`，每头只有 8 维空间算 attention，表达力不足。经验上 `d_k ≥ 32` 比较稳，即 `d_model=512` 时最多 16 头。
> 2. **冗余**：研究表明很多头学到的是高度相似的模式，部分头可以剪掉而不掉性能。论文《Are Sixteen Heads Really Better than One?》就证明不少头是冗余的。
>
> 实践中 `d_model=512, h=8`（每头 64 维）是经过大量实验验证的甜点配置。盲目加头不会带来线性收益，反而增加参数和计算开销。

## 易错点预警

- ❌ `d_model` 不能被 `n_heads` 整除 → ✅ 正确：必须整除，否则 `d_k` 不是整数。代码里写 `assert d_model % n_heads == 0` 提前拦截。
- ❌ 拆头时忘记 `transpose(1, 2)` → ✅ 正确：`view(B, T, h, d_k)` 后必须 `transpose(1, 2)` 把头维度提前到 `(B, h, T, d_k)`，否则矩阵乘法维度对不上。
- ❌ 拼头时忘记 `contiguous()` → ✅ 正确：`transpose` 后张量不连续，直接 `view` 会报错。必须 `.contiguous().view(B, T, d_model)`。
- ❌ 头数过多导致 `d_k` 太小 → ✅ 正确：保持 `d_k ≥ 32`。`d_model=512` 最多 16 头，再多每头表达力不足。
- ❌ 把每个头看成完全独立的"小 Self-Attention 模块" → ✅ 正确：每个头共享同一份输入 X，只是用不同的 `W_Q^i, W_K^i, W_V^i` 投影到不同的子空间。它们是同一份数据的不同视角，不是看不同的数据。

## 章末小结

| 步骤 | 操作 | 维度变化 | 关键点 |
|------|------|---------|--------|
| 投影 | `x · W_Q`, `x · W_K`, `x · W_V` | `(B,T,d_model) → (B,T,d_model)` | 三个独立可学习矩阵 |
| 拆头 | `view + transpose(1,2)` | `(B,T,d_model) → (B,h,T,d_k)` | `d_k = d_model/h` 必须整数 |
| 注意力 | `softmax(QK^T/√d_k)·V` | `(B,h,T,d_k)` | 每头独立算，可并行 |
| 拼头 | `transpose + contiguous + view` | `(B,h,T,d_k) → (B,T,d_model)` | 沿特征维拼接 |
| 输出投影 | `· W_O` | `(B,T,d_model) → (B,T,d_model)` | 让头之间信息混合 |
