# Ch23 · LSTM 的核心思想 — 门控

> 所属篇：第四篇 · 预计耗时：25 分钟

RNN 的记忆像一块黑板，每步都被擦掉重写。LSTM 的记忆像一本笔记本——你可以选择擦不擦、写不写、读不读。这就是"门控"：用几个开关控制信息的遗忘、写入、输出。本章只讲门控的**核心思想**（为什么用"加法更新"能治 RNN 的病），**不**引入具体的门符号和公式——那些是下一章 Ch24 的事。先搞懂"为什么"，再去看"怎么算"。

---

## 为了什么（Why）

**核心痛点**：上一章我们看到 RNN 用"乘法更新"记忆（`hₜ = tanh(W_xh·xₜ + W_hh·hₜ₋₁)`），导致梯度连乘消失。LSTM 的破局思路是：把记忆更新改成"加法"——`新记忆 = 旧记忆 + 增量`，让梯度沿加法顺畅流动。

举个反例：RNN 的隐藏状态 `hₜ` 是一条乘法链 `hₜ = tanh(... W_hh·hₜ₋₁)`，每一步都把 `hₜ₋₁` 乘进 `W_hh` 里，反向时梯度就要连乘 W_hh。LSTM 引入一条独立的"细胞状态"通道，用加法更新：`Cₜ = (保留比例) × Cₜ₋₁ + (写入比例) × (新候选信息)`。注意这里是**加号**，不是把 `Cₜ₋₁` 塞进某个矩阵再 tanh。

**这一章的目标**：理解 LSTM 用"加法替代乘法"的核心思想，能解释为什么加法能避免梯度消失。

> 📌 **与 Ch24 的边界**：Ch23 只讲"门控思想"和"加法更新为什么治本"，用描述性词汇（"保留比例"、"写入比例"）代替正式符号；Ch24 才正式引入遗忘门 f_t、输入门 i_t、输出门 o_t 等符号和具体公式。本章末尾会给出"门控三件事"的直觉图，但不下沉到公式。

## 做了什么（What）

LSTM 给 RNN 装了两个核心改造：

```
改造1：引入"细胞状态" Cₜ（独立的记忆通道）
   - 像一条传送带，信息沿传送带流动
   - 用"加法"更新：Cₜ = (保留比例) × Cₜ₋₁ + (写入比例) × (新候选信息)
   - 不经过 tanh 压缩，旧信息不会被"重写"

改造2：用"门"控制信息的流量
   - 门 = sigmoid 输出 0~1，像水龙头控制水流大小
   - 1 = 完全打开（全保留/全写入/全输出）
   - 0 = 完全关闭（全丢弃/不写/不输出）
```

### 逐组件拆解

**门（Gate）**：一个 sigmoid 函数，输出值在 [0, 1] 之间。直觉上像水龙头——0 表示关紧（信息流不过去），1 表示全开（信息全部流过），0.5 表示半开（流一半）。LSTM 用门来"按比例"控制信息的遗忘、写入、输出，而不是 RNN 那种"全量重写"。

**细胞状态（Cell State）Cₜ**：LSTM 新增的一条"记忆传送带"。它和 RNN 的 `hₜ` 最大的不同是：**Cₜ 用加法更新**，不是用 `tanh(W·h + ...)` 重写。你可以把 Cₜ 想象成一条贯穿所有时间步的传送带，门控就是传送带上的几个闸门，决定多少旧货留下、多少新货上车。

**加法更新**：核心公式（先用文字描述，符号留到 Ch24）：

```
Cₜ = (保留比例) ⊙ Cₜ₋₁ + (写入比例) ⊙ (新候选信息)
     ↑水龙头1控制旧货      ↑水龙头2控制新货
```

这里 ⊙ 是逐元素乘（"按比例"缩放），+ 是加法（"叠加上去"）。关键在于：`Cₜ₋₁` 不是被塞进某个矩阵再 tanh，而是直接乘一个 [0,1] 的比例后加回来。这样梯度从 `Cₜ` 反传到 `Cₜ₋₁` 时，走的是"乘以保留比例"这条简单路径，不是 RNN 那种"W_hh 连乘"。

**高速公路**：Cₜ 就像一条"信息高速公路"，梯度可以沿这条路顺畅地从 `C_T` 流到 `C_1`，中间只被"保留比例"逐次缩放。如果保留比例接近 1，梯度几乎无损传递——这就是 LSTM 治 RNN 长依赖病的核心。

## 怎么算（How）

### 核心对比：RNN 的乘法链 vs LSTM 的加法链

**RNN 的梯度路径**（Ch22 已分析）：

```
∂L/∂h₁ ≈ ∏ₜ₌₁ᵀ (W_hh · tanh'(zₜ))
```

每一步都要乘一个 W_hh（矩阵）和一个 tanh'（标量），T 步连乘后衰减或爆炸。

**LSTM 的梯度路径**（关键推导）：

LSTM 的细胞状态更新公式（先用描述性符号）：

```
Cₜ = (保留比例) ⊙ Cₜ₋₁ + (写入比例) ⊙ (新候选信息)
```

对 `Cₜ₋₁` 求偏导（链式法则）：

```
∂Cₜ/∂Cₜ₋₁ = (保留比例)
```

> 📌 **关键推导（模拟读者反馈缺口12）**：从 `Cₜ = (保留比例) ⊙ Cₜ₋₁ + (写入比例) ⊙ (新候选信息)` 怎么得到 `∂Cₜ/∂Cₜ₋₁ = (保留比例)`？
>
> 把公式看作 `Cₜ = a ⊙ Cₜ₋₁ + b`，其中 `a = (保留比例)`，`b = (写入比例) ⊙ (新候选信息)`。注意 `b` 虽然依赖 `hₜ₋₁`（间接依赖 `Cₜ₋₁`），但在 LSTM 的标准反向传播推导中，`b` 通过 `hₜ₋₁` 对 `Cₜ₋₁` 的依赖是一条**次路径**，主路径就是 `a ⊙ Cₜ₋₁` 这一项。
>
> 对主路径求偏导：`∂(a ⊙ Cₜ₋₁)/∂Cₜ₋₁ = a`（因为 a 在第 t 步是常数，对 Cₜ₋₁ 求导等于 a 本身，⊙ 逐元素乘的偏导就是逐元素的乘子）。
>
> 所以主路径上：`∂Cₜ/∂Cₜ₋₁ ≈ (保留比例)`。
>
> T 步连乘后（沿主路径）：
>
> ```
> ∂L/∂C₁ ≈ ∏ₜ₌₁ᵀ (保留比例)ₜ
> ```
>
> 注意这里**没有 W_hh 的连乘**！每一项只是一个 [0,1] 的标量（保留比例），不是矩阵。

### 数值小例子：为什么加法避免梯度消失

对比两种更新方式在 T=50 步后的梯度：

**情况 1：RNN（W_hh 特征值 0.9，tanh' 平均 0.5）**

```
每步因子 = 0.9 × 0.5 = 0.45
T=50: 梯度 = 0.45⁵⁰ = 3.2e-18  ← 完全消失
```

**情况 2：LSTM，保留比例 = 1.0（完全保留旧记忆）**

```
每步因子 = 1.0
T=50: 梯度 = 1.0⁵⁰ = 1.0  ← 完全不衰减！
```

**情况 3：LSTM，保留比例 = 0.9（保留 90% 旧记忆）**

```
每步因子 = 0.9
T=50: 梯度 = 0.9⁵⁰ = 0.0052  ← 衰减但远好于 RNN 的 3.2e-18
```

注意对比：同样是 0.9，RNN 因为还要乘 tanh'（0.5），实际每步是 0.45；LSTM 的加法路径上只有"保留比例"这一个因子，没有 W_hh 也没有 tanh'。所以 LSTM 的梯度衰减速度远慢于 RNN。

### 门控的直觉

把 LSTM 的细胞状态 Cₜ 想象成一条传送带，上面有三个水龙头：

```
       遗忘水龙头        输入水龙头         输出水龙头
       (控制旧货留多少)    (控制新货进多少)    (控制对外展示多少)
            │                 │                  │
  Cₜ₋₁ ─→ [水龙头1] ─→  +  ─→ [水龙头2] ─→ Cₜ ─→ [水龙头3] ─→ hₜ
                              ↑
                          新候选信息
```

- **遗忘水龙头**（对应 Ch24 的遗忘门）：开多大，旧记忆 Cₜ₋₁ 就保留多少。开 = 1 全保留，关 = 0 全遗忘。
- **输入水龙头**（对应 Ch24 的输入门）：开多大，新候选信息就写入多少。开 = 1 全写入，关 = 0 不写。
- **输出水龙头**（对应 Ch24 的输出门）：开多大，细胞状态 Cₜ 就对外暴露多少（变成 hₜ）。

> 📌 **关键科普（模拟读者反馈）**：为什么"加法替代乘法"能避免梯度消失？
>
> 用一个生活比喻：你要从北京开车到上海（1000 公里）。
>
> - **RNN（乘法链）**：每过 1 公里就要交一次过路费，过路费 = 当前油量的 50%（比喻 W_hh × tanh' 的缩放）。开 50 公里后油量剩 0.5⁵⁰ ≈ 1e-15，车熄火了。
> - **LSTM（加法链）**：高速公路上不收过路费，只在匝道（门控）按需调整。如果你把"遗忘水龙头"开到 1.0（不遗忘），油量全程无损传递，1000 公里都能开到。
>
> 这和 ResNet 的"残差连接"是同一个思想：`y = F(x) + x` 中的 `+ x` 让梯度可以沿"恒等映射"那条路无损反传，不经过 F(x) 的乘法链。LSTM 的 `Cₜ = (保留) ⊙ Cₜ₋₁ + (写入) ⊙ (新信息)` 中的 `+ (写入) ⊙ (新信息)` 让梯度可以沿"保留 ⊙ Cₜ₋₁"那条路反传，不被新信息的计算图拖累。**思想同源**。

## 怎么用（Use）

关键片段：

```python
import numpy as np

# === 对比 RNN 和 LSTM 的梯度衰减 ===
print("=== RNN vs LSTM 梯度衰减对比 ===")
print()

# RNN: 每步乘 (W_hh 特征值 × tanh')
rnn_W_eigenvalue = 0.9
rnn_tanh_deriv = 0.5
rnn_factor = rnn_W_eigenvalue * rnn_tanh_deriv  # 0.45

# LSTM: 每步乘 (保留比例)
lstm_keep_full = 1.0       # 遗忘水龙头全开
lstm_keep_09 = 0.9         # 遗忘水龙头开 90%

print(f"RNN 每步因子 = {rnn_factor}（W_hh 特征值 × tanh'）")
print(f"LSTM 每步因子 = {lstm_keep_full}（保留比例 = 1.0）或 {lstm_keep_09}（保留比例 = 0.9）")
print()
print(f"{'T':>5} | {'RNN':>15} | {'LSTM(保留=1.0)':>18} | {'LSTM(保留=0.9)':>18}")
print("-" * 65)
for T in [5, 10, 20, 50, 100]:
    rnn_grad = rnn_factor ** T
    lstm_full = lstm_keep_full ** T
    lstm_09 = lstm_keep_09 ** T
    print(f"{T:>5} | {rnn_grad:>15.2e} | {lstm_full:>18.2e} | {lstm_09:>18.2e}")

# === 门控的直觉：sigmoid 输出 0~1，像水龙头 ===
print()
print("=== 门控直觉：sigmoid 输出 = 水龙头开度 ===")
def sigmoid(x): return 1 / (1 + np.exp(-x))
for x, label in [(-5, "关紧"), (-1, "微开"), (0, "半开"), (1, "大开"), (5, "全开")]:
    gate = sigmoid(x)
    print(f"  sigmoid({x:>2}) = {gate:.4f}  ← {label}（信息流量 {gate*100:.1f}%）")
```

## 想多一点

> LSTM 的"加法更新"和 ResNet 的"残差连接"有什么共同点？
>
> 答案：**思想同源**——都是用加法让梯度顺畅流动。
>
> - ResNet：`y = F(x) + x`，梯度 `∂y/∂x = F'(x) + 1`，那个 `+1` 让梯度至少能沿恒等映射那条路无损反传，不至于消失。
> - LSTM：`Cₜ = (保留) ⊙ Cₜ₋₁ + (写入) ⊙ (新信息)`，梯度 `∂Cₜ/∂Cₜ₋₁ = (保留)`，如果保留接近 1，梯度沿 C 路径几乎无损传递。
>
> 两者的共同智慧：**给梯度留一条"高速公路"**，让它不必穿过复杂的非线性变换就能反传到远处。这个思想后来在 Transformer 里也有体现——残差连接是 Transformer 能堆深的关键。所以理解了 LSTM 的加法更新，你就提前理解了 ResNet 和 Transformer 残差连接的一半。

## 易错点预警

- ❌ **错误**：以为 LSTM 完全解决了梯度消失。→ ✅ **正确**：LSTM 大大缓解但**非完全解决**。如果保留比例长期 < 1（比如 0.5），T 步后梯度仍是 0.5^T 衰减；超长序列（数千步）上 LSTM 仍有记忆衰退问题。LSTM 的真正优势是"**可选择**地保留"——门控可以让保留比例接近 1，而 RNN 的 W_hh 是学出来的、无法保证接近 1。
- ❌ **错误**：混淆 `hₜ`（隐藏状态）和 `Cₜ`（细胞状态）。→ ✅ **正确**：`Cₜ` 是 LSTM 的"长期记忆通道"，用加法更新、不经过 tanh；`hₜ` 是"对外输出"，由 `Cₜ` 经过 tanh 和输出门得到。两者分工不同——Cₜ 负责跨时间步传递，hₜ 负责给当前步的输出和下一步的门控计算用。
- ❌ **错误**：以为"门控"就是 RNN 的激活函数。→ ✅ **正确**：门控是 LSTM 独有的概念——一个 sigmoid 输出 [0,1]，**按比例**控制信息流量。RNN 的 tanh 是"压扁"信息到 [-1,1]，不是按比例放行；门控是"水龙头"，不是"压扁机"。

## 章末小结

| 概念 | 一句话解释 | 易错点 |
|------|-----------|--------|
| 门控（Gating） | sigmoid 输出 0~1 控制信息流量 | 像"水龙头"不是"压扁机" |
| 加法更新 | Cₜ = (保留)⊙Cₜ₋₁ + (写入)⊙(新信息) | 梯度沿加法路径不衰减 |
| 细胞状态 Cₜ | LSTM 的长期记忆通道 | 用加法更新，不经过 tanh |
| 高速公路 | Cₜ 是梯度顺畅流动的通道 | 保留比例≈1 时梯度无损 |
| 保留比例 | 控制旧记忆 Cₜ₋₁ 留多少 | Ch24 起正式命名为"遗忘门" |
