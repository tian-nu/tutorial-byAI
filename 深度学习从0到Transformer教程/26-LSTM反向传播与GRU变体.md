# Ch26 · LSTM 反向传播与 GRU 变体

> 所属篇：第四篇 · 预计耗时：30 分钟

LSTM 前向传播会了，但参数怎么学？还是靠反向传播。LSTM 的反向传播比 RNN 复杂——有四个门、两条状态线（C 和 h）。但核心仍是链式法则，且 C 路径上的加法更新让梯度可以顺畅反传。本章手算 LSTM 的关键反向梯度，再介绍 LSTM 的"精简版"——GRU，把三门压成两门。第四篇到此结束，下一章进入第五篇 Seq2Seq 与 Attention。

---

## 为了什么（Why）

**核心痛点**：LSTM 训练必须靠 BPTT（沿时间反向传播）反向传播；不掌握则无法理解 PyTorch 的 `loss.backward()` 在 LSTM 上做了什么。

举个反例：不懂 LSTM 反向传播，遇到"梯度爆炸"报警时只会调小学习率，不知道可以梯度裁剪（Gradient Clipping）；遇到"模型学不动长序列"时只会堆更多层，不知道可能是遗忘门饱和导致 C 通道被堵。理解反向传播的梯度路径，才能定位这类问题的根因。

**这一章的目标**：理解 LSTM 反向传播的关键梯度路径（特别是 C 路径的加法高速公路），知道 GRU 与 LSTM 的差异，能说出"LSTM 缓解梯度消失的核心机制"是什么。

## 要做到（Goal）

- **输入**：Ch24 的前向结果（f_t、i_t、o_t、C̃_t、C_t、h_t 的具体数值）、Ch25 的多步前向思想、Ch20 的 BPTT 思想。
- **输出**：手算 ∂L/∂C_t、∂L/∂f_t、∂L/∂i_t、∂L/∂o_t、∂L/∂C̃_t 五个梯度的具体数值；手算 GRU 单步前向的 z_t、r_t、h̃_t、h_t。
- **成功标准**：算出 `∂L/∂C_t = [0.085, 0.104]`、`∂L/∂f_t = [0.051, -0.042]` 等五个梯度；算出 GRU 的 `h_t ≈ [0.468, 0.230]`。

## 做了什么（What）

LSTM 反向传播有两条梯度高速公路——沿 C_t 的加法路径（梯度顺畅）和沿 h_t 的乘法路径（类似 RNN，仍会衰减）。

```
前向: Cₜ₋₁ ──f_t⊙── (+) ──→ Cₜ ──tanh──⊙o_t──→ hₜ ──→ L
                        ↑
                  i_t⊙C̃_t

反向: L ──→ hₜ ──⊙tanh(C_t), ⊙o_t──→ Cₜ ──(+ 反传)──→ Cₜ₋₁
                                              │
                                    f_t⊙ 路径: ∂L/∂f_t = ∂L/∂C_t × C_{t-1}
                                    i_t⊙ 路径: ∂L/∂i_t = ∂L/∂C_t × C̃_t
                                    o_t  路径: ∂L/∂o_t = ∂L/∂h_t × tanh(C_t)
```

### 逐组件拆解

**∂L/∂C_t（细胞状态的梯度）**：由两部分累加——
- 来自 h_t 路径：`∂L/∂h_t × o_t × (1 - tanh²(C_t))`（h_t 经 tanh 和输出门反传到 C_t）
- 来自 C_{t+1} 路径：`∂L/∂C_{t+1} × f_{t+1}`（下一时刻的 C 梯度经遗忘门反传到当前 C_t）

**∂L/∂f_t（遗忘门梯度）**：`∂L/∂C_t × C_{t-1}`（C_t 对 f_t 的偏导是 C_{t-1}）。

**∂L/∂i_t（输入门梯度）**：`∂L/∂C_t × C̃_t`（C_t 对 i_t 的偏导是 C̃_t）。

**∂L/∂C̃_t（候选状态梯度）**：`∂L/∂C_t × i_t`（C_t 对 C̃_t 的偏导是 i_t）。

**∂L/∂o_t（输出门梯度）**：`∂L/∂h_t × tanh(C_t)`（h_t 对 o_t 的偏导是 tanh(C_t)）。

**梯度裁剪（Gradient Clipping）**：把梯度的范数强行截断到一个上限（如 5.0），防止梯度爆炸。`torch.nn.utils.clip_grad_norm_` 就是干这个的。这是治标方案，治本靠 LSTM 的加法更新结构。

### GRU 简化

GRU（Gated Recurrent Unit）是 LSTM 的精简版，核心改动：

```
LSTM (3 门 + 2 状态)              GRU (2 门 + 1 状态)
─────────────────────             ─────────────────────
遗忘门 f_t                         ┐
输入门 i_t  ──合并──→              ┘ 更新门 z_t（同时控制遗忘和输入）
输出门 o_t                         重置门 r_t（控制候选状态对历史依赖）
候选 C̃_t                           候选 h̃_t
细胞状态 C_t  ──合并──→            隐藏状态 h_t（无独立细胞状态）
隐藏状态 h_t
```

GRU 的两个简化：
1. **三门压两门**：把遗忘门和输入门合并为"更新门" z_t。LSTM 里 f_t 和 i_t 是独立的（可以既保留旧记忆又写入新信息），GRU 用 `(1-z_t)` 做遗忘、`z_t` 做输入，二者互补（保留多少 + 写入多少 = 1）。
2. **两状态压一状态**：去掉独立的细胞状态 C_t，直接用 h_t 既存记忆又对外输出。

## 怎么算（How）

### LSTM 反向梯度公式（关键路径）

```
∂L/∂C_t = ∂L/∂h_t ⊙ o_t ⊙ (1 - tanh²(C_t))  +  ∂L/∂C_{t+1} ⊙ f_{t+1}
          └────── h 路径（当前步输出反传）────┘   └─ C 路径（下一步 C 反传）─┘

∂L/∂f_t = ∂L/∂C_t ⊙ C_{t-1}
∂L/∂i_t = ∂L/∂C_t ⊙ C̃_t
∂L/∂C̃_t = ∂L/∂C_t ⊙ i_t
∂L/∂o_t = ∂L/∂h_t ⊙ tanh(C_t)
```

**关键**：第二项 `∂L/∂C_{t+1} ⊙ f_{t+1}` 中，f_{t+1} 接近 1 时，梯度从 C_{t+1} 几乎无损传到 C_t——这就是 LSTM 缓解梯度消失的核心机制。

### 数值小例子（接 Ch24 前向结果）

**已知值（来自 Ch24）**：

| 量 | 数值 |
|----|------|
| C_{t-1} | [0.6, -0.4] |
| C̃_t | [0.446, 0.592] |
| f_t | [0.648, 0.804] |
| i_t | [0.684, 0.596] |
| o_t | [0.625, 0.589] |
| C_t | [0.694, 0.031] |
| tanh(C_t) | ≈ [0.601, 0.031] |

**假设上游梯度**（来自下游损失和下一时间步）：

```
∂L/∂h_t     = [0.1, 0.1]      （损失对当前步输出的梯度）
∂L/∂C_{t+1} = [0.05, 0.05]    （下一时间步 C 的梯度反传过来）
f_{t+1}     = 0.9              （下一时间步遗忘门值，假设两个分量都是 0.9）
```

#### 步骤 1：算 ∂L/∂C_t 的 h 路径分量

先算 `1 - tanh²(C_t)`（tanh 的导数）：

```
1 - tanh²(0.694) = 1 - 0.601² = 1 - 0.361 = 0.639
1 - tanh²(0.031) = 1 - 0.031² = 1 - 0.001 = 0.999

→ [0.639, 0.999]
```

∂L/∂C_t 的 h 路径分量 = ∂L/∂h_t ⊙ o_t ⊙ (1 - tanh²(C_t))：

```
第 1 分量 = 0.1 × 0.625 × 0.639 = 0.040
第 2 分量 = 0.1 × 0.589 × 0.999 = 0.059

→ [0.040, 0.059]
```

#### 步骤 2：累加 C_{t+1} 路径，得完整 ∂L/∂C_t

C 路径分量 = ∂L/∂C_{t+1} ⊙ f_{t+1}：

```
第 1 分量 = 0.05 × 0.9 = 0.045
第 2 分量 = 0.05 × 0.9 = 0.045

→ [0.045, 0.045]
```

完整 ∂L/∂C_t = h 路径 + C 路径：

```
∂L/∂C_t = [0.040 + 0.045, 0.059 + 0.045]
        = [0.085, 0.104]
```

**结果**：`∂L/∂C_t = [0.085, 0.104]`

**关键观察**：第 2 分量 0.104 = 0.059（h 路径）+ 0.045（C 路径）。其中 0.045 来自下一时刻的 C 路径，f_{t+1}=0.9 让梯度几乎无损回传——这就是 LSTM 缓解梯度消失的核心机制。对比 RNN，RNN 的 C 路径上要乘 W_hh × tanh'，0.45 倍衰减；LSTM 只乘 f_{t+1}=0.9，衰减极慢。

#### 步骤 3：算三个门的梯度（对门输出，sigmoid 之前）

**∂L/∂f_t = ∂L/∂C_t ⊙ C_{t-1}**：

```
第 1 分量 = 0.085 × 0.6   = 0.051
第 2 分量 = 0.104 × (-0.4) = -0.042

→ ∂L/∂f_t = [0.051, -0.042]
```

含义：第 1 维遗忘门梯度为正，说明应该增大 f_t[0]（多保留旧记忆）；第 2 维为负，说明应该减小 f_t[1]（少保留旧记忆，因为 C_{t-1}[1]=-0.4 是负的，保留它会让 C_t 变小）。

**∂L/∂i_t = ∂L/∂C_t ⊙ C̃_t**：

```
第 1 分量 = 0.085 × 0.446 = 0.038
第 2 分量 = 0.104 × 0.592 = 0.062

→ ∂L/∂i_t ≈ [0.038, 0.062]（手算四舍五入；代码精确值为 0.061，差异来自中间值精度）
```

含义：两维都为正，说明应该增大输入门（多写入新信息），因为新候选 C̃_t 都是正的，写入它能增大 C_t 进而增大 h_t。

**∂L/∂o_t = ∂L/∂h_t ⊙ tanh(C_t)**：

```
第 1 分量 = 0.1 × 0.601 = 0.060
第 2 分量 = 0.1 × 0.031 = 0.003

→ ∂L/∂o_t = [0.060, 0.003]
```

含义：第 1 维梯度大（0.060），第 2 维几乎为 0（0.003）。因为 C_t[1]=0.031 很小，tanh(0.031)≈0.031 也小，输出门对它的影响微弱。

#### 步骤 4：算候选状态梯度

**∂L/∂C̃_t = ∂L/∂C_t ⊙ i_t**：

```
第 1 分量 = 0.085 × 0.684 = 0.058
第 2 分量 = 0.104 × 0.596 = 0.062

→ ∂L/∂C̃_t = [0.058, 0.062]
```

含义：两维都为正，说明应该增大候选状态 C̃_t（写入更多新信息）。注意 ∂L/∂C̃_t 和 ∂L/∂i_t 都为正，但路径不同——前者是"增大新信息本身的值"，后者是"放行更多新信息"。

### 五个梯度汇总

| 梯度 | 数值 | 物理含义 |
|------|------|----------|
| ∂L/∂C_t | [0.085, 0.104] | 细胞状态梯度（h 路径 + C 路径累加） |
| ∂L/∂f_t | [0.051, -0.042] | 遗忘门梯度（应增大第1维，减小第2维） |
| ∂L/∂i_t | [0.038, 0.061] | 输入门梯度（应增大，多写入新信息） |
| ∂L/∂o_t | [0.060, 0.003] | 输出门梯度（应主要增大第1维） |
| ∂L/∂C̃_t | [0.058, 0.062] | 候选状态梯度（应增大新信息值） |

> 📌 **核心洞察**：∂L/∂C_t 的第 2 分量 0.104 中，有 0.045 来自 `∂L/∂C_{t+1} × f_{t+1}` 这一项。如果 f_{t+1}=0.9，下一时刻的梯度几乎无损传到当前时刻；如果换成 RNN 的 W_hh×tanh'=0.45，只能传回 0.0225。LSTM 的加法更新让长程梯度得以保留，这是它能学长依赖的根本原因。

### GRU 数值小例子（2 维，与 Ch24 同输入便于对比）

**输入**（与 Ch24 完全相同）：

```
h_{t-1} = [0.5, -0.3]
x_t     = [1.0, 0.8]
concat  = [0.5, -0.3, 1.0, 0.8]
```

**权重**（3 个 2×4 矩阵，对比 LSTM 的 4 个）：

```
W_z = [[0.1, 0.2, 0.3, 0.4],      # 更新门
       [0.5, 0.6, 0.7, 0.8]]

W_r = [[0.2, 0.1, 0.3, 0.5],      # 重置门
       [0.4, 0.3, 0.2, 0.1]]

W_h = [[0.3, 0.2, 0.1, 0.4],      # 候选状态
       [0.2, 0.4, 0.3, 0.1]]
```

#### 更新门 z_t

`z_t = σ(W_z · concat)`：

```
W_z · concat:
  第 1 分量 = 0.1×0.5 + 0.2×(-0.3) + 0.3×1.0 + 0.4×0.8
            = 0.05 - 0.06 + 0.3 + 0.32 = 0.61
  第 2 分量 = 0.5×0.5 + 0.6×(-0.3) + 0.7×1.0 + 0.8×0.8
            = 0.25 - 0.18 + 0.7 + 0.64 = 1.41

z_t = sigmoid([0.61, 1.41]) ≈ [0.648, 0.804]
```

**结果**：`z_t ≈ [0.648, 0.804]`

#### 重置门 r_t

`r_t = σ(W_r · concat)`：

```
W_r · concat:
  第 1 分量 = 0.2×0.5 + 0.1×(-0.3) + 0.3×1.0 + 0.5×0.8
            = 0.1 - 0.03 + 0.3 + 0.4 = 0.77
  第 2 分量 = 0.4×0.5 + 0.3×(-0.3) + 0.2×1.0 + 0.1×0.8
            = 0.2 - 0.09 + 0.2 + 0.08 = 0.39

r_t = sigmoid([0.77, 0.39]) ≈ [0.684, 0.596]
```

**结果**：`r_t ≈ [0.684, 0.596]`

#### 候选状态 h̃_t

`h̃_t = tanh(W_h · [r_t ⊙ h_{t-1}, x_t])`

先算 `r_t ⊙ h_{t-1}`（重置门控制历史依赖）：

```
r_t ⊙ h_{t-1} = [0.684×0.5, 0.596×(-0.3)]
              = [0.342, -0.179]
```

拼接 `[r_t ⊙ h_{t-1}, x_t] = [0.342, -0.179, 1.0, 0.8]`

矩阵乘 `W_h · concat`：

```
第 1 分量 = 0.3×0.342 + 0.2×(-0.179) + 0.1×1.0 + 0.4×0.8
         = 0.103 - 0.036 + 0.1 + 0.32 = 0.487

第 2 分量 = 0.2×0.342 + 0.4×(-0.179) + 0.3×1.0 + 0.1×0.8
         = 0.068 - 0.072 + 0.3 + 0.08 = 0.376

→ [0.487, 0.376]
```

过 tanh：

```
h̃_t = tanh([0.487, 0.376]) ≈ [0.452, 0.360]
```

**结果**：`h̃_t ≈ [0.452, 0.360]`

#### 隐藏状态 h_t

`h_t = (1 - z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t`

先算 `(1 - z_t)` 和 `(1 - z_t) ⊙ h_{t-1}`（"遗忘"路径，等价于 LSTM 的 f_t ⊙ C_{t-1}）：

```
1 - z_t = [1 - 0.648, 1 - 0.804] = [0.352, 0.196]

(1 - z_t) ⊙ h_{t-1} = [0.352×0.5, 0.196×(-0.3)]
                    = [0.176, -0.059]
```

再算 `z_t ⊙ h̃_t`（"写入"路径，等价于 LSTM 的 i_t ⊙ C̃_t）：

```
z_t ⊙ h̃_t = [0.648×0.452, 0.804×0.360]
          = [0.293, 0.289]
```

两项相加：

```
h_t = [0.176 + 0.293, -0.059 + 0.289]
    = [0.469, 0.230]
```

**结果**：`h_t ≈ [0.469, 0.230]`

#### 对比 LSTM

| 模型 | h_t | 参数量（权重矩阵数） | 状态数 |
|------|-----|---------------------|--------|
| LSTM（Ch24） | [0.375, 0.018] | 4（W_f, W_i, W_C, W_o） | 2（h, C） |
| GRU（本章）  | [0.469, 0.230] | 3（W_z, W_r, W_h） | 1（h） |

同输入下 LSTM 和 GRU 的 h_t 数值不同（因为公式不同），但都把历史信息 `h_{t-1}=[0.5,-0.3]` 融入了新状态。GRU 用更少参数（3 个 W vs LSTM 的 4 个 W）达到了类似效果——这就是 GRU 的吸引力。

## 怎么用（Use）

代码文件：`深度学习从0到Transformer教程/code/ch26_lstm_backward_gru.py`

关键片段：

```python
import numpy as np
import torch
import torch.nn as nn

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

# === LSTM 反向梯度手算验证 ===
# 前向值（来自 Ch24）
C_prev = np.array([0.6, -0.4])
C_bar  = np.array([0.446, 0.592])
f_t    = np.array([0.648, 0.804])
i_t    = np.array([0.684, 0.596])
o_t    = np.array([0.625, 0.589])
C_t    = np.array([0.694, 0.031])
tanh_Ct = np.tanh(C_t)   # ≈ [0.600, 0.031]

# 上游梯度
dh_t   = np.array([0.1, 0.1])
dC_next = np.array([0.05, 0.05])   # ∂L/∂C_{t+1}
f_next = 0.9                        # f_{t+1}

# 步骤1: h 路径分量
one_minus_tanh2 = 1 - tanh_Ct ** 2   # [0.640, 0.999]
dC_t_from_h = dh_t * o_t * one_minus_tanh2   # [0.040, 0.059]

# 步骤2: 累加 C_{t+1} 路径
dC_t = dC_t_from_h + dC_next * f_next   # [0.085, 0.104]

# 步骤3: 三门梯度
df_t = dC_t * C_prev       # [0.051, -0.042]
di_t = dC_t * C_bar        # [0.038, 0.062]
do_t = dh_t * tanh_Ct      # [0.060, 0.003]

# 步骤4: 候选状态梯度
dC_bar = dC_t * i_t        # [0.058, 0.062]

print(f"∂L/∂C_t  = {dC_t.round(3)}")
print(f"∂L/∂f_t  = {df_t.round(3)}")
print(f"∂L/∂i_t  = {di_t.round(3)}")
print(f"∂L/∂o_t  = {do_t.round(3)}")
print(f"∂L/∂C̃_t = {dC_bar.round(3)}")

# === PyTorch LSTM 自动反向 + 梯度裁剪 ===
lstm = nn.LSTM(input_size=10, hidden_size=20, batch_first=True)
X = torch.randn(1, 5, 10)   # batch=1, T=5, d=10
out, (h, C) = lstm(X)
loss = out.sum()
loss.backward()
# 梯度裁剪（防止爆炸）
torch.nn.utils.clip_grad_norm_(lstm.parameters(), max_norm=5.0)
print(f"LSTM 参数梯度已计算: {lstm.weight_ih_l0.grad is not None}")

# === GRU 对比 ===
gru = nn.GRU(input_size=10, hidden_size=20, batch_first=True)
out_gru, h_gru = gru(X)
print(f"GRU 参数量: {sum(p.numel() for p in gru.parameters())}")
print(f"LSTM 参数量: {sum(p.numel() for p in lstm.parameters())}")
```

## 想多一点

> GRU 比 LSTM 少一个门，效果一定差吗？
>
> 答案：**不一定**，看场景。
>
> - **小数据集 / 浅层模型**：GRU 常优于 LSTM。参数少意味着过拟合风险低，训练快。很多 NLP 任务（情感分类、文本分类）GRU 和 LSTM 打平甚至 GRU 略胜。
> - **大数据集 / 深层模型 / 超长序列**：LSTM 略优。独立的细胞状态 C_t 提供"纯记忆通道"，三门独立可以"既保留又写入"（f_t 和 i_t 都接近 1），而 GRU 的 z_t 和 (1-z_t) 互补，无法同时既保留又写入。长序列上这种灵活性有价值。
> - **工业实践**：两者都被广泛使用，没有绝对赢家。现代 NLP 已经转向 Transformer，但 LSTM/GRU 在轻量级任务、实时系统、资源受限设备上仍是主流选择。
>
> 经验法则：先试 GRU（快、省），效果不够再换 LSTM。不要一上来就 LSTM——它的 4 倍参数量在小数据上反而拖累。

## 易错点预警

- ❌ **错误**：忘记 LSTM 反向传播有两条路径（C 和 h），只算 h 路径。→ ✅ **正确**：`∂L/∂C_t` 必须累加 **h 路径**（`∂L/∂h_t × o_t × (1-tanh²(C_t))`）和 **C_{t+1} 路径**（`∂L/∂C_{t+1} × f_{t+1}`）。漏掉 C_{t+1} 路径会导致长程梯度无法反传——这恰恰是 LSTM 的核心优势所在。本章手算中 `∂L/∂C_t[1] = 0.104`，其中 0.045 来自 C_{t+1} 路径，占 43%，漏掉就完全错了。
- ❌ **错误**：GRU 的 z_t 只控制"写入"，忘了它同时控制"遗忘"。→ ✅ **正确**：GRU 用 `(1-z_t)` 做遗忘、`z_t` 做输入，二者互补（和为 1）。这是 GRU 对 LSTM 的简化——把两个独立的门（f_t 和 i_t）压成一个门（z_t）的两个互补输出。代价是失去了"既保留又写入"的灵活性。
- ❌ **错误**：用"同理算出"跳过 ∂L/∂f_t、∂L/∂i_t、∂L/∂o_t 的计算。→ ✅ **正确**：三个门的梯度路径**完全不同**——∂L/∂f_t 走 `C_{t-1}` 路径，∂L/∂i_t 走 `C̃_t` 路径，∂L/∂o_t 走 `tanh(C_t)` 路径。本章已逐一展开，每个梯度的数值和含义都写清了。
- ❌ **错误**：把梯度裁剪当成解决梯度消失的方案。→ ✅ **正确**：梯度裁剪只治**爆炸**（把过大的梯度截断），不治**消失**（过小的梯度无法放大）。LSTM 解决梯度消失靠的是 C 路径的加法更新结构，不是梯度裁剪。两者是互补的工具：LSTM 结构治本（缓解消失），梯度裁剪治标（防爆炸）。

## 章末小结

| 模型 | 门数 | 状态数 | 优势 | 劣势 |
|------|------|--------|------|------|
| RNN  | 0    | 1 (h)  | 简单 | 梯度消失 |
| LSTM | 3 (f/i/o) | 2 (h, C) | 长程记忆好（C 加法路径） | 参数多（4 组 W） |
| GRU  | 2 (z/r) | 1 (h) | 参数少、训练快 | 表达力略弱（无独立 C） |

**第四篇核心收束**：RNN 的乘法更新导致梯度消失 → LSTM 引入加法更新的 C 通道治本 → GRU 用更少参数达到类似效果。下一篇 Seq2Seq + Attention 将把这些"记忆单元"组装成翻译/摘要架构，并最终引出 Transformer。
