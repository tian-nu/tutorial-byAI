## 八、易混淆符号对照

| 写法 A | 写法 B | 区别 |
|--------|--------|------|
| `A @ B` | `A * B` | `@` 是矩阵乘法（行×列），`*` 是逐元素乘（Hadamard） |
| `Aᵀ` | `A⁻¹` | `ᵀ` 是转置（行列互换），`⁻¹` 是逆矩阵（满足 `AA⁻¹=I`） |
| `∂L/∂W` | `dL/dW` | 同义，多元用 `∂`，一元用 `d`，教程混用 |
| `σ(x)` | `softmax(x)` | `σ` 是 sigmoid（单值映射），softmax 是向量归一化（和为 1） |
| `h_t`（RNN） | `h_t`（LSTM） | RNN 中是隐藏状态，LSTM 中是输出（`h_t = o_t ⊙ tanh(C_t)`） |
| `d_k` | `d_model` | `d_k` 是单头维度，`d_model` 是总维度，`d_model = n_heads · d_k` |
| `C_t`（LSTM） | `c`（类别数） | 上下文不同，LSTM 章节里 `C_t` 是细胞状态，分类章节里 `c` 是类别 |
