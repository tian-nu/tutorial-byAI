# Ch41 · 下一步去哪 — 学习路线图

> 所属篇：第七篇 · 预计耗时：20 分钟

恭喜你走到了第 41 章。从"什么是矩阵"到"手搓 Transformer"，从"梯度下降"到"HuggingFace 微调"，你已经走完了深度学习的核心路径。但学习没有终点——本章不教新知识，只给你一张"下一步去哪"的地图。地图本身不能带你走路，但它能保证你不迷路。

打个比方：本教程是带你从山脚爬到半山腰的营地，教你用绳索、看地图、搭帐篷。接下来登顶有四条路——NLP、CV、多模态、工程优化——每条路风景不同、装备要求不同。本章就是营地里那张标着四条路线的指示牌。

---

## 为了什么（Why）

**核心痛点**：学完基础后容易迷茫，不知道该深入哪个方向。两种典型表现都不可取：

- **盲目跟风型**：刚学完 Transformer 就去看 LLaMA 论文，发现 RoPE、GQA、Flash Attention、SwiGLU 全不懂，挫败感拉满，怀疑自己白学了。
- **原地打转型**：把本教程反复看了三遍，会手推 Attention 了，但不知道接下来该做什么项目，理论没法落地。

**这一章的目标**：给你一张清晰的学习路线图，让你能说出自己感兴趣方向的"接下来 3 本书、3 门课、3 个项目"，不再迷茫。

## 要做到（Goal）

- **输入**：本教程 40 章打下的基础（数学、ML、NN、RNN/LSTM、Transformer）。
- **输出**：一张知识全景图 + 分方向推荐资源 + 时间分配建议。
- **成功标准**：读完本章，你能选定一个方向，并说出该方向接下来该读什么书、上什么课、做什么项目。

## 怎么算（How）

> 本节精简：本章是路线图，无公式。只给一个**时间分配建议**——
>
> - **60% 实战项目**：手写代码、跑通端到端流程，踩坑是最高效的学习。
> - **30% 论文阅读**：先读经典（Attention Is All You Need、BERT、GPT、ResNet），再追前沿。
> - **10% 基础补漏**：发现自己哪块不懂，回本教程或花书对应章节补。
>
> 反例：100% 看论文不看代码 → 面试一问"你跑过什么"就露馅。100% 调包不看论文 → 只会用不会改，遇到新问题抓瞎。两者要平衡。

## 怎么用（Use）

### 推荐书单（从易到难）

1. **《动手学深度学习》（李沐）** — 实战入门首选，代码 + 理论一体，免费在线版。学完本教程后读这本，巩固 + 拓展 CV 部分。
2. **《深度学习》（花书，Ian Goodfellow）** — 理论圣经，数学严谨。不用从头读，当字典查：遇到不懂的概念翻对应章节。
3. **《Attention Is All You Need》** — Transformer 原论文。本教程 Ch27-35 就是拆解这篇论文，现在去读原文会有"原来如此"的快感。
4. **经典论文三件套**：**BERT**（理解类预训练）、**GPT 系列**（生成类预训练）、**ViT**（把 Transformer 搬到视觉）。读完这三篇，你就懂了预训练模型的全貌。

### 推荐课程

1. **李沐《论文精读》系列**（B 站免费）— 每期拆一篇经典论文，讲得通俗。配套本教程食用最佳。
2. **Stanford CS224N**（NLP）— NLP 方向的标杆课程，从词向量讲到 Transformer/预训练。讲义和作业都公开。
3. **Stanford CS231N**（CV）— CV 方向的标杆，CNN 到 ViT 都覆盖。想做视觉必看。
4. **HuggingFace NLP Course**（免费）— 学完本教程 Ch40 后接着上，教你用 Transformers 库做各种 NLP 任务，实战向。

### 推荐项目（按难度递增）

1. **从零实现一个 GPT**（参考 [nanoGPT](https://github.com/karpathy/nanoGPT)）— Karpathy 的最小 GPT 实现，300 行代码训一个能写莎士比亚的小模型。本教程 Ch35 的进阶版。
2. **微调一个开源 LLM**（如 Qwen、LLaMA、ChatGLM）— 用 LoRA/QLoRA 在消费级显卡上微调 7B 模型，做一个自己的对话助手。学会这个，你就具备了"定制大模型"的能力。
3. **搭一个 RAG 系统**（LangChain + 向量数据库）— 把 LLM 接入你自己的知识库，让它"基于你的文档"回答问题。这是目前企业落地最热的方向。

### 社区与资讯

- **HuggingFace** — 模型/数据集的"应用商店"，每天逛逛看有什么新模型。
- **PapersWithCode** — 论文 + 代码 + 排行榜，找 SOTA 必去。
- **GitHub Trending** — 看大家在 star 什么项目，跟上开源动态。
- **知乎 / 掘金** — 中文社区，跟进国内动态和工程经验。

## 想多一点

> AI 发展这么快，学的东西会不会很快过时？
>
> **基础不会。** 矩阵乘法、梯度下降、反向传播、Attention 思想——这些是"第一性原理"，十年内不会过时。框架会变（Theano→TensorFlow→PyTorch→？），模型会变（LSTM→Transformer→？），但"用梯度优化参数让 loss 下降"这个范式从 1986 年到现在没变过。
>
> 会过时的是**具体 API 和具体模型名**。所以策略是：**把基础打到根上，框架/模型保持"会用就行"的熟悉度**。本教程教的就是根——你掌握了 Attention 的本质，以后无论它套上 RoPE 还是 Flash Attention 的外衣，你都能看懂。
>
> 一句话：**学原理，用工具；原理不变，工具常换。**

## 易错点预警

- ❌ 错误：盲目追最新论文（今天 LLaMA3、明天 Mamba、后天 MoE），基础却不牢。✅ 正确：先吃透本教程 + 经典论文（Attention/BERT/GPT/ViT），再追前沿。前沿论文假设你懂基础，不懂基础看前沿等于看天书。
- ❌ 错误：只看不练——把书和视频堆了一堆，代码一行没写过。✅ 正确：每学一个新概念，手写一遍代码。哪怕照抄 nanoGPT，抄一遍也比看十遍视频强。"纸上得来终觉浅，绝知此事要躬行"。
- ❌ 错误：方向贪多——同时学 NLP + CV + 强化学习，每个都浅尝辄止。✅ 正确：先选一个方向深入，做到能独立做项目，再横向扩展。深度优先于广度。
- ❌ 错误：觉得"必须看完所有基础才能开始做项目"。✅ 正确：本教程学完就够开工了。做项目过程中发现哪块不懂，再回来补，带着问题学效率最高。
