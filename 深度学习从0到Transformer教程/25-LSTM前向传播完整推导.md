# Ch25 · LSTM 前向传播完整推导

> 所属篇：第四篇 · 预计耗时：25 分钟

Ch24 我们只算了一步。但真实任务是处理一句话"我爱深度学习"，6 个字，要算 6 步。每一步的 h_t 都要喂给下一步，C_t 也要一路传递。这就是 LSTM 前向传播——把单步公式串成时间链。本章把 Ch24 的单步公式沿时间轴展开 4 步，手算每一步的 h_t 和 C_t，并用 NumPy 和 PyTorch 两种方式验证。

---

## 为了什么（Why）

**核心痛点**：Ch24 只覆盖单步，读者面对序列输入仍不会展开。LSTM 的核心优势"长程记忆"必须在多步前向中才能体现——单步看不出 C_t 怎么沿时间累积，看不出遗忘门怎么在不同时间步动态调整。

举个反例：不懂多步前向，Ch26 的反向传播无从下手（BPTT 就是沿时间轴反传梯度）；遇到 PyTorch 的 `nn.LSTM` 输出 `(output, (h_n, c_n))` 时，你也不知道 `h_n` 是第 T 步的 h_t，还是所有时间步的 h 拼起来。

**这一章的目标**：能展开 4 步 LSTM 前向，输出每步的 h_t 和最终 h_4。

## 要做到（Goal）

- **输入**：Ch24 的单步六公式、长度 T=4 的序列 `x = [[1.0,0.5], [0.3,0.7], [0.8,0.2], [0.4,0.6]]`。
- **输出**：4 步 LSTM 前向的完整数值结果，最终 `h_4 ≈ [0.246, 0.210]`。
- **成功标准**：手算结果与 NumPy 代码输出一致，且与 PyTorch `nn.LSTM`（同权重）输出一致。

## 做了什么（What）

把 LSTM 单元沿时间轴展开成 T 步链式结构，C 和 h 在步与步之间传递：

```
t=1:  x_1 ─→ [LSTM] ─→ h_1, C_1
                  ↑
              h_0=0, C_0=0

t=2:  x_2 ─→ [LSTM] ─→ h_2, C_2
                  ↑
              h_1, C_1   ← 承接上一步

t=3:  x_3 ─→ [LSTM] ─→ h_3, C_3
                  ↑
              h_2, C_2

t=4:  x_4 ─→ [LSTM] ─→ h_4, C_4   ← 最终隐藏状态
                  ↑
              h_3, C_3
```

每一步都执行 Ch24 的六公式，输入是当前的 `x_t` 和上一步的 `h_{t-1}, C_{t-1}`，输出是新的 `h_t, C_t`。

### 逐组件拆解

**时间步 t=1**：输入 `x_1`，初始 `h_0 = [0, 0]`、`C_0 = [0, 0]`，输出 `h_1, C_1`。
**时间步 t=2**：输入 `x_2`，承接 `h_1, C_1`，输出 `h_2, C_2`。
**时间步 t=3**：输入 `x_3`，承接 `h_2, C_2`，输出 `h_3, C_3`。
**时间步 t=4**：输入 `x_4`，承接 `h_3, C_3`，输出 `h_4`（最终隐藏状态）。

> 📌 **关键观察**：C_t 沿时间累积（加法更新），h_t 每步基于 C_t 重新计算。这就是 LSTM 的"记忆"——C_t 是长期记忆，h_t 是当前步的"读出"。

## 怎么算（How）

### 核心公式

对每一步 t（t = 1, 2, 3, 4），重复 Ch24 的六公式：

```
1. f_t = σ(W_f · [h_{t-1}, x_t] + b_f)
2. i_t = σ(W_i · [h_{t-1}, x_t] + b_i)
3. C̃_t = tanh(W_C · [h_{t-1}, x_t] + b_C)
4. o_t = σ(W_o · [h_{t-1}, x_t] + b_o)
5. C_t = f_t ⊙ C_{t-1} + i_t ⊙ C̃_t
6. h_t = o_t ⊙ tanh(C_t)
```

### 简化说明（重要！）

> 📌 **关键修复（模拟读者反馈缺口4）**：本章手算用**对角矩阵**简化，不是单位矩阵，也不是满矩阵。
>
> - **不能假设 W 为单位矩阵**：LSTM 的 W_f / W_i / W_C / W_o 是 (2×4) 矩阵（输入维度 4 = h 维度 2 + x 维度 2），**不是方阵**，单位矩阵根本无定义。
> - **简化方案**：假设 4 个门的权重矩阵都是同一个**对角结构**矩阵：
>
> ```
> W_f = W_i = W_C = W_o = [[0.5, 0.0, 0.5, 0.0],
>                          [0.0, 0.5, 0.0, 0.5]]
> ```
>
> 这个矩阵的作用是：每个隐藏单元只看对应的 h 分量和 x 分量（第 1 个单元看 h[0] 和 x[0]，第 2 个单元看 h[1] 和 x[1]），各取一半加权求和。偏置 `b_f = b_i = b_C = b_o = [0, 0]`。
>
> - **这种简化只为手算演示**：实际 LSTM 中 W_f / W_i / W_C / W_o 是 4 个**不同的满矩阵**，且偏置非零。简化让手算可跟随，但不要把它当成 LSTM 的真实结构。
> - **四个门用同一个 W 的后果**：因为 W 相同且偏置相同，每一步的 `f_t = i_t = o_t`（都是同一个 sigmoid 输出）。这只是为了手算方便，真实 LSTM 三门独立。

### 输入序列

```
x_1 = [1.0, 0.5]
x_2 = [0.3, 0.7]
x_3 = [0.8, 0.2]
x_4 = [0.4, 0.6]

初始: h_0 = [0, 0], C_0 = [0, 0]
```

### t = 1

**拼接**：`[h_0, x_1] = [0, 0, 1.0, 0.5]`

**矩阵乘**（W · concat，W 是上面那个 2×4 对角结构矩阵）：

```
第 1 分量 = 0.5×0 + 0.5×1.0 = 0.5
第 2 分量 = 0.5×0 + 0.5×0.5 = 0.25

→ [0.5, 0.25]
```

**四门计算**（同一 W，所以 f_1 = i_1 = o_1）：

```
f_1 = sigmoid([0.5, 0.25]) = [1/(1+e^-0.5), 1/(1+e^-0.25)]
    ≈ [0.622, 0.562]

i_1 = sigmoid([0.5, 0.25]) ≈ [0.622, 0.562]   （与 f_1 相同，因为 W 相同）

C̃_1 = tanh([0.5, 0.25]) = [(e^0.5-e^-0.5)/(e^0.5+e^-0.5), tanh(0.25)]
     ≈ [0.462, 0.245]

o_1 = sigmoid([0.5, 0.25]) ≈ [0.622, 0.562]   （与 f_1 相同）
```

**细胞状态更新**（C_0 = [0, 0]，所以 f_1 ⊙ C_0 = [0, 0]）：

```
C_1 = f_1 ⊙ C_0 + i_1 ⊙ C̃_1
    = [0.622×0, 0.562×0] + [0.622×0.462, 0.562×0.245]
    = [0, 0] + [0.287, 0.138]
    = [0.287, 0.138]
```

**隐藏状态**：

```
tanh(C_1) = [tanh(0.287), tanh(0.138)] ≈ [0.280, 0.137]

h_1 = o_1 ⊙ tanh(C_1)
    = [0.622×0.280, 0.562×0.137]
    ≈ [0.174, 0.077]
```

**t=1 结果**：`C_1 ≈ [0.288, 0.138]`，`h_1 ≈ [0.174, 0.077]`

### t = 2

**拼接**：`[h_1, x_2] = [0.174, 0.077, 0.3, 0.7]`

**矩阵乘**：

```
第 1 分量 = 0.5×0.174 + 0.5×0.3 = 0.087 + 0.15 = 0.237
第 2 分量 = 0.5×0.077 + 0.5×0.7 = 0.0385 + 0.35 = 0.389

→ [0.237, 0.389]
```

**四门计算**：

```
f_2 = sigmoid([0.237, 0.389]) ≈ [0.559, 0.596]
i_2 = sigmoid([0.237, 0.389]) ≈ [0.559, 0.596]
C̃_2 = tanh([0.237, 0.389]) ≈ [0.233, 0.371]
o_2 = sigmoid([0.237, 0.389]) ≈ [0.559, 0.596]
```

**细胞状态更新**：

```
f_2 ⊙ C_1 = [0.559×0.287, 0.596×0.138] = [0.160, 0.082]
i_2 ⊙ C̃_2 = [0.559×0.233, 0.596×0.371] = [0.130, 0.221]

C_2 = [0.160 + 0.130, 0.082 + 0.221]
    = [0.290, 0.303]
```

**隐藏状态**：

```
tanh(C_2) = [tanh(0.290), tanh(0.303)] ≈ [0.282, 0.294]

h_2 = o_2 ⊙ tanh(C_2)
    = [0.559×0.282, 0.596×0.294]
    ≈ [0.158, 0.175]
```

**t=2 结果**：`C_2 ≈ [0.291, 0.303]`，`h_2 ≈ [0.158, 0.175]`

### t = 3

**拼接**：`[h_2, x_3] = [0.158, 0.175, 0.8, 0.2]`

**矩阵乘**：

```
第 1 分量 = 0.5×0.158 + 0.5×0.8 = 0.079 + 0.4 = 0.479
第 2 分量 = 0.5×0.175 + 0.5×0.2 = 0.0875 + 0.1 = 0.188

→ [0.479, 0.188]
```

**四门计算**：

```
f_3 = sigmoid([0.479, 0.188]) ≈ [0.618, 0.547]
i_3 = sigmoid([0.479, 0.188]) ≈ [0.618, 0.547]
C̃_3 = tanh([0.479, 0.188]) ≈ [0.446, 0.186]
o_3 = sigmoid([0.479, 0.188]) ≈ [0.618, 0.547]
```

**细胞状态更新**：

```
f_3 ⊙ C_2 = [0.618×0.290, 0.547×0.303] = [0.179, 0.166]
i_3 ⊙ C̃_3 = [0.618×0.446, 0.547×0.186] = [0.276, 0.102]

C_3 = [0.179 + 0.276, 0.166 + 0.102]
    = [0.455, 0.268]
```

**隐藏状态**：

```
tanh(C_3) = [tanh(0.455), tanh(0.268)] ≈ [0.426, 0.262]

h_3 = o_3 ⊙ tanh(C_3)
    = [0.618×0.426, 0.547×0.262]
    ≈ [0.263, 0.143]
```

**t=3 结果**：`C_3 ≈ [0.455, 0.267]`，`h_3 ≈ [0.263, 0.142]`

### t = 4

**拼接**：`[h_3, x_4] = [0.263, 0.143, 0.4, 0.6]`

**矩阵乘**：

```
第 1 分量 = 0.5×0.263 + 0.5×0.4 = 0.1315 + 0.2 = 0.332
第 2 分量 = 0.5×0.143 + 0.5×0.6 = 0.0715 + 0.3 = 0.372

→ [0.332, 0.372]
```

**四门计算**：

```
f_4 = sigmoid([0.332, 0.372]) ≈ [0.582, 0.592]
i_4 = sigmoid([0.332, 0.372]) ≈ [0.582, 0.592]
C̃_4 = tanh([0.332, 0.372]) ≈ [0.321, 0.356]
o_4 = sigmoid([0.332, 0.372]) ≈ [0.582, 0.592]
```

**细胞状态更新**：

```
f_4 ⊙ C_3 = [0.582×0.455, 0.592×0.268] = [0.265, 0.159]
i_4 ⊙ C̃_4 = [0.582×0.321, 0.592×0.356] = [0.187, 0.211]

C_4 = [0.265 + 0.187, 0.159 + 0.211]
    = [0.452, 0.370]
```

**隐藏状态**：

```
tanh(C_4) = [tanh(0.452), tanh(0.370)] ≈ [0.423, 0.354]

h_4 = o_4 ⊙ tanh(C_4)
    = [0.582×0.423, 0.592×0.354]
    ≈ [0.246, 0.210]
```

**t=4 最终结果**：`C_4 ≈ [0.451, 0.368]`，`h_4 ≈ [0.246, 0.208]`

> 📌 **关于手算舍入**：以上手算过程每步保留 3 位小数，累积舍入误差会导致最终结果与代码 float64 精确计算有 ±0.002 差异（例如 h_3 手算 0.143、代码 0.142；h_4 手算 0.210、代码 0.208）。这是正常现象——手算的目的是让你理解每步在算什么，精确值以代码输出为准。

### 关键观察

| 时间步 | h_t（代码精确值） | C_t（代码精确值） | C 变化 |
|--------|-----|-----|--------|
| t=1 | [0.174, 0.077] | [0.288, 0.138] | C 从 0 开始累积 |
| t=2 | [0.158, 0.175] | [0.291, 0.303] | C_1 部分保留 + 新信息 |
| t=3 | [0.263, 0.142] | [0.455, 0.267] | 早期信息被遗忘门削弱 |
| t=4 | [0.246, 0.208] | [0.451, 0.368] | 最终状态汇总全序列 |

注意 C_t 沿时间累积（加法更新），而 h_t 每步基于 C_t 重新读出。这就是 LSTM 的"记忆通道"——C_t 不被重写，只被"按比例保留 + 按比例写入"。

## 怎么用（Use）

代码文件：`深度学习从0到Transformer教程/code/ch25_lstm_forward_full.py`

关键片段：

```python
import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def lstm_forward_simple(X, W, b=None):
    """简化版 LSTM 前向（与手算一致，4 门共用 W）
    X: (T, d), W: (h, h+d), b: (h,) 或 None
    """
    T = X.shape[0]
    h = W.shape[0]
    if b is None:
        b = np.zeros(h)
    h_t = np.zeros(h)
    C_t = np.zeros(h)
    history = []
    for t in range(T):
        concat = np.concatenate([h_t, X[t]])
        z = W @ concat + b
        f_t = sigmoid(z)         # 简化：4 门共用 W
        i_t = sigmoid(z)
        C_bar = np.tanh(z)
        o_t = sigmoid(z)
        C_t = f_t * C_t + i_t * C_bar
        h_t = o_t * np.tanh(C_t)
        history.append((h_t.copy(), C_t.copy()))
    return h_t, C_t, history

# === 手算验证 ===
W = np.array([[0.5, 0.0, 0.5, 0.0],
              [0.0, 0.5, 0.0, 0.5]])
X = np.array([[1.0, 0.5],
              [0.3, 0.7],
              [0.8, 0.2],
              [0.4, 0.6]])
h_final, C_final, history = lstm_forward_simple(X, W)
for t, (h_t, C_t) in enumerate(history, 1):
    print(f"t={t}: h_t={h_t.round(3)}, C_t={C_t.round(3)}")
```

## 想多一点

> 为什么 LSTM 处理"我爱深度学习"时，"我"的信息能流到"学习"？
>
> 答案：因为 C_t 通过**加法**更新，遗忘门接近 1 时旧信息几乎无损传递。
>
> 具体看本章的 C_t 变化：t=1 时 C_1 = [0.287, 0.138]（由 x_1 决定）；t=2 时 C_2 的第一分量 = 0.559×0.287 + 0.559×0.233 = 0.290，其中 0.559×0.287 = 0.160 是"保留了 t=1 的 56%"，0.559×0.233 = 0.130 是"写入了 t=2 的新信息"。也就是说，t=2 时 C 的第一分量还有 0.160 来自 t=1——这就是"我"的信息残留。
>
> 对比 RNN：t=2 时 h_2 = tanh(W·h_1 + ...)，h_1 被 W 矩阵变换后再 tanh，旧信息被"变形 + 压扁"，不是按比例保留。10 步后基本看不清 t=1 的影子；50 步后彻底消失。
>
> LSTM 的 C 通道像一条传送带，只要遗忘门不关，信息就能一直流。这是结构性的优势，不是调参能解决的。

## 易错点预警

- ❌ **错误**：每步都用新的 `h_0 = 0` 而非承接上一步的 `h_{t-1}`。→ ✅ **正确**：`h_t` 必须传给 `t+1` 步作为输入。这就是 RNN/LSTM 的"循环"含义——状态沿时间传递。如果每步都重置 h，就退化成普通 MLP 了。
- ❌ **错误**：忘记初始化 `C_0 = 0`，或者每步都重置 C。→ ✅ **正确**：`C_0 = np.zeros(h)`，与 `h_0` 同维。C_t 和 h_t 一样要沿时间传递，不能中途重置。本章手算中 `C_0 = [0, 0]`，t=1 时 `f_1 ⊙ C_0 = [0, 0]`（保留 0 的 56% 还是 0），所以 `C_1` 只由 `i_1 ⊙ C̃_1` 决定。
- ❌ **错误**：把"对角简化"当成 LSTM 的真实结构，以为 4 个门共用一个 W。→ ✅ **正确**：本章简化**只为手算可跟随**。真实 LSTM 的 W_f / W_i / W_C / W_o 是 4 个**不同的满矩阵**，4 个门完全独立。代码文件里同时给出了"简化版"和"标准版"两种实现，对比着看更清楚。
- ❌ **错误**：用"同理算出"跳过 t=2/3/4 的计算。→ ✅ **正确**：每一步的输入 `x_t` 和承接的 `h_{t-1}, C_{t-1}` 都不同，必须逐步算。本章已逐一展开 4 步，每步的矩阵乘、激活、状态更新都写全了。
