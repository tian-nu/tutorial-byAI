# Ch02 · 微积分最小必要知识

> 所属篇：第零篇 · 预计耗时：25 分钟

想象你蒙着眼站在山坡上，要走到谷底。你怎么知道往哪走？用脚感受一下哪边最陡——这就是导数。梯度下降就是"摸着山坡找谷底"。所有神经网络训练的核心都是这件事：算出每个参数往哪走能让损失下降最快。这一章我们把导数、偏导数、链式法则、梯度这四个概念彻底搞懂。

---

## 为了什么（Why）

**核心痛点**：所有神经网络训练都依赖梯度下降，梯度下降依赖导数和链式法则。不懂导数，等于不懂"网络怎么学习"。

举个反例：Ch15 反向传播的核心是链式法则——从损失一路倒推到每个参数的梯度。如果你不懂链式法则，看到 `dL/dw = dL/dy × dy/dz × dz/dw` 这种公式完全是一头雾水，只能死记硬背，换个网络结构就不会推了。

**这一章的目标**：让你看到 `f'(x)` 时脑子里能浮现"山坡坡度"，看到 `∇f` 时能浮现"上升最快的箭头"，看到链式法则时能浮现"一层层剥洋葱"。

## 要做到（Goal）

- **输入**：高中数学（知道什么是函数、什么是斜率）。
- **输出**：能手算简单函数的导数、理解偏导数和链式法则、理解梯度方向。
- **成功标准**：给定 `f(x) = x²`，能算出 `f'(3) = 6`；给定 `y = (2x+1)²`，能用链式法则算出 `dy/dx|_{x=1} = 12`。

## 做了什么（What）

微积分在深度学习里只用四个概念，它们的关系是：

```
导数（单变量瞬时变化率）
   │
   ├──> 偏导数（多变量中沿一个坐标轴的导数）
   │         │
   │         └──> 梯度（所有偏导数组成的向量）
   │
   └──> 链式法则（复合函数的导数 = 各层导数相乘）
```

### 逐组件拆解

**导数（Derivative）**：单变量函数的瞬时变化率。**山坡比喻**：你站在山坡上，导数就是脚下的坡度——正数表示上坡，负数表示下坡，绝对值越大越陡。

**偏导数（Partial Derivative）**：多变量函数中沿某一坐标轴的导数，其他变量当常数。**多变量山坡比喻**：你站在一个三维山坡上（高度由 x、y 共同决定），偏导数 ∂f/∂x 就是"只往东走"的坡度，∂f/∂y 就是"只往北走"的坡度。

**链式法则（Chain Rule）**：复合函数的导数 = 各层导数相乘。**剥洋葱比喻**：函数套函数像洋葱套皮，求导时一层层剥开，每层算导数，最后全乘起来。

**梯度（Gradient）**：所有偏导数组成的向量。**关键性质**：梯度指向函数**上升最快**的方向，所以**负梯度**是**下降最快**的方向——这就是梯度下降的数学基础。

## 怎么算（How）

### 1. 导数

公式：`f'(x) = lim(h→0) [f(x+h) - f(x)] / h`

直觉：当 h 趋近 0 时，"平均变化率"变成"瞬时变化率"。

**数值小例子**：

设 `f(x) = x²`，求 `f'(3)`。

解析解：`f'(x) = 2x`，所以 `f'(3) = 2 × 3 = 6`。

逐步验证（用数值导数，h=0.001）：
- `f(3 + 0.001) = f(3.001) = 3.001² = 9.006001`
- `f(3 - 0.001) = f(2.999) = 2.999² = 8.994001`
- 中心差分：`[9.006001 - 8.994001] / (2 × 0.001) = 0.012 / 0.002 = 6.0`

数值导数 ≈ 6.0，与解析解一致 ✅。

**山坡解释**：在 x=3 这个点，山坡的坡度是 6——往前走一小步，高度上升 6 倍步长。

### 2. 偏导数

公式：`∂f/∂x = lim(h→0) [f(x+h, y) - f(x, y)] / h`（y 当常数）

**数值小例子**：

设 `f(x, y) = x² · y`，在 `(x=2, y=3)` 处求偏导数。

**对 x 求偏导**（y 当常数）：
- `∂f/∂x = 2x · y`（把 y 当常数，对 x² 求导得 2x）
- 在 `(2, 3)` 处：`∂f/∂x = 2 × 2 × 3 = 12`

**对 y 求偏导**（x 当常数）：
- `∂f/∂y = x²`（把 x² 当常数，对 y 求导得 x² × 1）
- 在 `(2, 3)` 处：`∂f/∂y = 2² = 4`

### 3. 链式法则

公式：若 `y = f(g(x))`，则 `dy/dx = f'(g(x)) × g'(x)`

**剥洋葱解释**：从最外层剥起，每剥一层算一层的导数，最后全乘起来。

**数值小例子**：

设 `y = (2x + 1)²`，求 `dy/dx|_{x=1}`。

**令中间变量** `u = 2x + 1`，则 `y = u²`。

**逐层求导**：
- 外层：`dy/du = 2u`（对 u² 求导得 2u）
- 内层：`du/dx = 2`（对 2x+1 求导得 2）
- 链式法则：`dy/dx = dy/du × du/dx = 2u × 2 = 4u`

**代入 x=1**：
- `u = 2 × 1 + 1 = 3`
- `dy/dx = 4 × 3 = 12`

所以 `dy/dx|_{x=1} = 12`。

数值验证（h=0.001）：
- `y(1.001) = (2 × 1.001 + 1)² = 3.002² = 9.012004`
- `y(0.999) = (2 × 0.999 + 1)² = 2.998² = 8.988004`
- 中心差分：`[9.012004 - 8.988004] / 0.002 = 0.024 / 0.002 = 12.0` ✅

### 4. 梯度与"负梯度是下降最快方向"

**梯度定义**：`∇f = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]`，是所有偏导数组成的向量。

**为什么负梯度是下降最快方向？** 这是深度学习最核心的数学事实之一，必须想清楚。

设你站在点 `P`，要选一个方向走一小步，让函数值下降最多。设方向为单位向量 `d`（`|d|=1`），步长 `ε`。函数值变化量近似为：

`f(P + ε·d) - f(P) ≈ ε · (∇f · d)`

要让下降最多，就要让 `∇f · d` 最小（最负）。根据点积的性质，`∇f · d = |∇f| · |d| · cos(θ) = |∇f| · cos(θ)`，当 `cos(θ) = -1`（即 `θ = 180°`，`d` 与 `∇f` 反向）时最小。所以 **`d = -∇f / |∇f|`** 是下降最快的方向。

**直觉**：梯度指向"上坡最陡"的方向，反方向就是"下坡最陡"的方向。蒙眼下山，每一步都往最陡的下坡方向走，就是梯度下降。

**数值小例子**：

设 `f(x, y) = x² + y²`（一个碗，最低点在 (0,0)），起点 `(3, 4)`。

- `∂f/∂x = 2x`，在 (3, 4) 处 `∂f/∂x = 6`
- `∂f/∂y = 2y`，在 (3, 4) 处 `∂f/∂y = 8`
- 梯度 `∇f = (6, 8)`，指向远离原点的方向（上升最快）
- 负梯度 `-∇f = (-6, -8)`，指向原点方向（下降最快）

走 0.1 步：新位置 `(3 - 0.1×6, 4 - 0.1×8) = (2.4, 3.2)`，`f = 2.4² + 3.2² = 5.76 + 10.24 = 16`，从原来的 25 降到了 16。✅

```python
import numpy as np

# 数值导数（中心差分）
def f(x):
    return x ** 2

def numerical_deriv(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

print(numerical_deriv(f, 3.0))   # 输出约 6.0，与解析解 f'(3)=6 一致
```

## 想多一点

> 为什么深度学习用"梯度下降"而不是直接求"解析解"？
>
> 提示：线性回归有解析解（最小二乘法），但神经网络不行——损失函数非凸（有无数局部最优），且参数极多（GPT-3 有 1750 亿参数），解析解的计算量是参数量的立方，根本算不动。梯度下降虽然慢，但每步只要 O(参数量) 的计算，是唯一可行的方法。

## 易错点预警

- ❌ 求偏导时忘记把其他变量当常数 → ✅ 正确：`∂(x²y)/∂x = 2xy`（y 当常数），不是 `2xy + x²`。检验方法：对 x 求偏导时，把 y 想象成一个具体的数（比如 5），`∂(5x²)/∂x = 10x`，对应 `2xy` 当 y=5 时的值。
- ❌ 链式法则顺序搞反 → ✅ 正确：`dy/dx = dy/du × du/dx`，从外到内。先算外层 `dy/du`，再算内层 `du/dx`，最后相乘。顺序反了虽然乘法结果一样，但理解上会乱。
- ❌ 以为梯度方向是下降最快方向 → ✅ 正确：**负梯度**才是下降最快方向，梯度本身是**上升最快**方向。深度学习里写 `w = w - lr * grad`，那个减号就是取负梯度。

## 章末小结

| 概念 | 一句话解释 | 易错点 |
|------|-----------|--------|
| 导数（Derivative） | 单变量函数的瞬时变化率 | 导数 ≠ 变化量，是变化率（坡度） |
| 偏导数（Partial Derivative） | 多变量中沿一个坐标轴的导数 | 求偏导时其他变量当常数 |
| 链式法则（Chain Rule） | 复合函数导数 = 各层导数相乘 | 顺序从外到内，不能乱 |
| 梯度（Gradient） | 所有偏导数组成的向量 | 梯度是上升最快方向，负梯度才是下降最快 |
| 数值导数 | 用 `[f(x+h)-f(x-h)]/(2h)` 近似 | h 太小会浮点误差，太大截断误差，1e-5 是经验值 |
