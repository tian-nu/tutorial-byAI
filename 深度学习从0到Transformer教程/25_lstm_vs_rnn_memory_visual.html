LSTM vs RNN 长期记忆对比

任务：t=1 时输入一个「标记信号」x₁=1，之后 t=2…20 输入全 0，要求模型在 t=20 输出原始信号。 RNN 的隐藏状态 hₜ 在 tanh 反复作用下指数衰减趋近 0（记不住）；LSTM 的细胞状态 Cₜ 靠遗忘门≈1 + 加法更新，能把信号几乎无损带到 t=20。

步骤 0 / 4
实验设置：T=20。RNN：hₜ = tanh(0.99·hₜ₋₁ + xₜ)（W_hh 已贴近 1 的极限）。LSTM：Cₜ = 0.99·Cₜ₋₁ + 0.01·xₜ（遗忘门 f≈0.99，输入门 i≈0.01，无新候选时近似恒等）。x₁=1，其余为 0。
