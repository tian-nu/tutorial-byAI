📝 步骤1：用户提问

你问AI："Python的requests库怎么用get_json()方法读取API返回的JSON？"

⚠️ 问题本身包含了一个陷阱——get_json() 这个方法根本不存在！但AI不会质疑你，它只会尝试回答。

🔍 步骤2：AI检索训练数据

AI在训练数据中搜索相关知识。它读过很多代码，见过很多 get_xxx() 模式的函数名。

但它没有找到 requests.get_json() 的准确定义——因为这个方法不存在。

⚠️ 关键问题：训练数据不完整，缺少关于这个问题的准确信息。

🎲 步骤3：概率推断填补空白

AI不会说"我不知道"——它必须输出点什么。既然没有准确数据，它就从相似的模式中拼凑。

AI的推理逻辑（它自己也不知道）：

  • 很多库都有 get_json() 方法 → 高概率
  • requests 是HTTP库，肯定有JSON相关方法 → 高概率
  • 所以 requests.get_json() 应该存在 → 猜错了！

⚠️ 这就是概率推断的边界：AI"猜"了一个不存在的API，因为它见过太多类似的模式。

❌ 步骤4：幻觉输出 — 一本正经地胡说八道

AI输出了一段看起来非常专业的代码，但核心方法是错的：

# ⚠️ 幻觉！requests 没有 get_json() 方法 import requests response = requests.get("https://api.example.com/data") data = response.get_json() # ← 这行会报错！ print(data) # ✅ 正确做法：用 .json() 方法 data = response.json() # ← 这才是对的

AI不是故意骗你，它只是不知道自己在胡说。它把概率最高的答案输出给你，但这个答案是错的。
