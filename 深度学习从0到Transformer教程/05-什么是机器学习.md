# Ch05 · 什么是机器学习

> 所属篇：第一篇 · 预计耗时：15 分钟

20年前你写垃圾邮件过滤器，要写几百条规则："包含'VIP'就删"、"包含'免费'就删"、"标题全大写就删"。规则写了又改，改了又补，永远有漏网之鱼。现在你给机器看1万封垃圾邮件和1万封正常邮件，它自己学会区分。这就是机器学习——**从数据学规则，而不是人写规则**。

---

## 为了什么（Why）

**核心痛点**：传统编程是"人写规则，计算机执行"。但现实世界太复杂了，很多问题根本写不出规则。

举个反例：你要写一个程序识别图片里的猫。怎么用"if-else"来描述一只猫？

```
如果（耳朵是三角形 且 眼睛是圆的 且 有胡须 且 ...）
    那么这是猫
```

猫有各种姿势、各种颜色、各种背景、各种角度……规则写不完，写了也覆盖不全。人脸识别、语音翻译、推荐系统——这些问题的共同点是：**人类能做，但说不清怎么做**。

机器学习换了一个思路：**不让你写规则，而是让机器从数据里自己找规律**。

## 要做到（Goal）

- **输入**：历史数据（特征 X + 标签 Y）。比如：一堆房子的面积和对应的真实房价。
- **输出**：一组参数 W，使得模型 `f(X; W)` 的预测值尽可能接近真实值 Y。
- **成功标准**：给定一个从未见过的新房子面积 X_new，模型能预测出合理的房价 Y_new。

## 做了什么（What）

机器学习的核心流程可以画成这样一个循环：

```
┌──────────────────────────────────────────────┐
│                                              │
│   数据(X,Y) → 模型 f(X;W) → 预测 Ŷ           │
│                    ↓                          │
│              损失 L(Ŷ, Y)                     │
│                    ↓                          │
│              优化器调整 W                       │
│                    │                          │
│ ───────────────────┘ （循环）                  │
│                                              │
└──────────────────────────────────────────────┘
```

### 逐组件拆解

**模型（Model）**：一个带参数的函数 `f(X; W)`。分号表示"W 是参数，X 是输入"。比如 `f(x) = w × x`，w 就是参数。模型就像一台机器——你往里投原料（X），它出产品（Ŷ），而参数 W 决定了这台机器怎么加工原料。

**损失函数（Loss Function）**：衡量"预测值 Ŷ 和真实值 Y 差多远"。差得越多，损失越大。就像考试分数——答对得多分高（损失小），答错得多扣分（损失大）。

**优化器（Optimizer）**：根据损失的大小和方向，自动调整参数 W，让下次预测更准。就像你考完试后看错题，然后针对性地复习——这就是"学习"的本质。

## 怎么算（How）

### 核心公式

训练目标就是找到一组参数 W*，让损失最小：

`W* = argmin_W  L(f(X; W), Y)`

翻译成人话：在所有可能的参数 W 中，找那个让损失 L 最小的 W。

### 数值小例子：房价预测

假设你有这样的历史数据：

| 房子 | 面积(㎡) | 真实房价(万) |
|------|---------|-------------|
| A    | 80      | 100         |

我们用一个最简单的模型：`f(X; W) = W × X`（先不管偏置 b），初始参数设为 `W = 1.0`。

**第1步：预测**

预测值 = W × X = 1.0 × 80 = **80万**

**第2步：算误差**

误差 = 真实值 - 预测值 = 100 - 80 = **20万**

**第3步：算损失**

用平方误差作为损失函数：`L = (真实值 - 预测值)² = 20² = **400**`

**第4步：优化（调整 W）**

损失是 400，说明 W=1.0 不够好。直觉上，80㎡的房子应该卖100万，那每平米大约值 100/80 = 1.25 万。所以我们应该把 W 从 1.0 往上调到接近 1.25。

具体怎么调？这就是下一章"梯度下降"要讲的事。现在你只需要理解一件事：**机器学习就是在不断重复"预测→算损失→调参数"这个循环，直到损失足够小**。

### 传统编程 vs 机器学习

这是最重要的对比：

```
传统编程：    规则(人写) + 数据 → 计算机 → 输出

机器学习：    数据 + 输出(答案) → 计算机 → 规则(学到)
```

传统编程：你告诉计算机"面积乘以1.25等于房价"，计算机照做。
机器学习：你给计算机看一堆"(面积, 房价)"的数据对，计算机自己发现"哦，原来面积乘以约1.25等于房价"。

## 怎么用（Use）

代码文件：`深度学习从0到Transformer教程/code/ch05_what_is_ml.py`

关键片段：

```python
from sklearn.linear_model import LinearRegression
import numpy as np

# 特征 X：房子的面积（单位：㎡）
X = np.array([[50], [80], [120]])

# 标签 y：对应的房价（单位：万）
y = np.array([60, 100, 150])

# 训练：fit 就是"让模型从数据中学习"
model = LinearRegression().fit(X, y)

# 预测：90㎡ 的房子多少钱？
prediction = model.predict([[90]])
print(f"90㎡ 预测房价: {prediction[0][0]:.1f} 万")
print(f"学到的系数 w: {model.coef_[0]:.4f}")
print(f"学到的截距 b: {model.intercept_:.4f}")
```

运行验证：

```bash
cd 深度学习从0到Transformer教程/code
python ch05_what_is_ml.py
```

预期输出：

```

【数据】
X (面积/㎡): [[50] [80] [120]]
y (房价/万): [ 60 100 150]

【训练结果】
90㎡ 预测房价: 110.0 万
学到的系数 w: 1.1250
学到的截距 b: 3.7500

【解读】
模型学到了: 房价 ≈ 1.125 × 面积 + 3.75

```

注意看：模型自己找到了 `w≈1.125` 和 `b≈3.75`，我们没有告诉它任何公式！

## 想多一点

> 机器学习和传统编程的本质区别是什么？
>
> 一句话总结：**传统编程是"人教计算机怎么做"，机器学习是"人给计算机看例子，让它自己学会怎么做"**。
>
> 这不是魔法——机器学习能学会的东西，本质上都存在于数据中的统计规律里。如果数据里没有规律（比如随机数），机器学习也学不出任何东西。所以有一句名言："Garbage In, Garbage Out"（垃圾进，垃圾出）。数据质量决定了模型的上限。

## 易错点预警

- ❌ 混淆"训练集"和"测试集"，用同一批数据既训练又评估 → ✅ 正确做法：把数据分成两部分——训练集用来学参数，测试集只用来最后评估一次，绝不能混用。否则就像考前泄露了真题，分数虚高。
- ❌ 认为"损失为0就是好模型" → ✅ 正确：损失为0说明模型把训练数据背下来了（过拟合），但遇到新数据可能表现很差。要看测试集上的表现才靠谱。

## 章末小结

| 概念 | 一句话解释 | 易错点 |
|------|-----------|--------|
| 模型（Model） | 带参数的函数 f(X; W)，输入特征输出预测 | 模型≠算法，算法是训练模型的方法 |
| 损失函数（Loss Function） | 衡量预测值与真实值的差距 | 损失越小不一定越好（可能过拟合） |
| 优化器（Optimizer） | 根据损失调整参数的策略 | 学习率太大导致不收敛 |
| 特征（Feature） | 输入数据的属性（如面积、年龄） | 特征选得好比模型选得好更重要 |
| 标签（Label） | 要预测的目标值（如房价、是否生还） | 分类问题是离散标签，回归问题是连续标签 |
| 训练集 / 测试集 | 训练集学参数，测试集评估泛化能力 | 绝不能用测试集参与训练 |
