# Ch18 · RNN 的结构与展开

> 所属篇：第三篇 · 预计耗时：25 分钟

你读一本书时，不是每读一个词就忘掉前面的。你的大脑保持着"到目前为止读到的内容"的记忆，每读一个新词就更新这份记忆——新记忆 = 旧记忆 + 新词。RNN 就是模仿这个过程：用一个"隐藏状态"当记忆，每步更新。这一章我们拆开 RNN 的结构，看它怎么把"记忆"变成数学公式。

---

## 为了什么（Why）

**核心痛点**：Ch17 说 MLP 处理不了序列，那我们需要一个能处理任意长度序列、且参数量不随序列长度增长的模型。

举个反例：假如为每个时间步建一个独立的 MLP——3 个词的句子用 3 个 MLP，10 个词的句子用 10 个 MLP。问题立刻冒出来：

- 参数量爆炸：10 个 MLP 有 10 套参数，100 个词就有 100 套。
- 无法共享规律：第 3 个位置学到的"主语后面跟谓语"规律，到第 5 个位置还得重新学一遍。
- 无法变长：建了 10 个 MLP 就只能处理 10 个词的句子。

**这一章的目标**：搞清楚 RNN 怎么用"一个网络 + 一个记忆变量"解决这两个问题——任意长度、参数共享。

## 要做到（Goal）

- **输入**：序列 `[x₁, x₂, ..., xₜ]` 和初始记忆 `h₀`。
- **输出**：每步的隐藏状态 `hₜ`（即"截至 t 时刻的记忆"）。
- **成功标准**：理解 RNN 的**参数共享**机制——所有时间步用同一组 `W_xh, W_hh, b`，参数量与序列长度无关。

## 做了什么（What）

RNN 的核心结构可以浓缩成一句话：**用一个隐藏状态 h 当记忆，每步用同一个公式更新它**。

```
RNN 的"记忆更新"流程

      x₁        x₂        x₃        ...   xₜ
       │         │         │                │
       ▼         ▼         ▼                ▼
     ┌───┐     ┌───┐     ┌───┐            ┌───┐
h₀→│RNN│→h₁→│RNN│→h₂→│RNN│→h₃ → ... →│RNN│→hₜ
     └───┘     └───┘     └───┘            └───┘
       │         │         │                │
       ▼         ▼         ▼                ▼
       y₁        y₂        y₃        ...   yₜ

注意：所有"RNN"框其实是同一个网络（同一组参数 W）
      这就是"参数共享"
```

### 逐组件拆解

**隐藏状态 hₜ（Hidden State）**：截至 t 时刻的"记忆"。它汇总了从开始到 t 时刻的所有输入信息。`h₀` 通常初始化为全 0 向量——相当于"开始读之前，记忆是空的"。

**输入权重 W_xh**：处理当前输入 `xₜ`，把"新词"变成记忆能消化的形式。

**隐藏权重 W_hh**：处理上一步记忆 `hₜ₋₁`，决定"旧记忆保留多少、遗忘多少"。

**参数共享（Parameter Sharing）**：所有时间步用**同一组** `W_xh, W_hh, b`。这就是 RNN 的精髓——不管序列多长，参数就那么几个。在第 1 步学到的规律，第 100 步自动适用。

**时间展开（Unfolding）**：把 RNN 按时间步展开成一条链。注意，展开只是画法，不是真的有 100 个网络——还是同一个网络，只是画了 100 次它自己的副本。

## 怎么算（How）

### 核心公式

```
hₜ = tanh(W_xh · xₜ + W_hh · hₜ₋₁ + b)
```

逐项解释：
- `W_xh · xₜ`：当前输入的贡献（"新词告诉了我什么"）
- `W_hh · hₜ₋₁`：旧记忆的贡献（"我记得什么"）
- `b`：偏置（"基础倾向"）
- `tanh`：激活函数，把记忆压缩到 `(-1, 1)` 范围内，防止数值爆炸

为什么用 tanh 而不是 ReLU？ReLU 输出无上界，会让记忆值无限增大；tanh 把记忆限制在 `(-1, 1)`，更稳定。

### 数值小例子（2 维输入，2 维隐藏）

设参数：
- `W_xh = [[0.5, -0.5], [0.3, 0.7]]`（2×2，输入维度 2，隐藏维度 2）
- `W_hh = [[0.1, 0.2], [-0.1, 0.4]]`（2×2，隐藏维度 2，隐藏维度 2）
- `b = [0.0, 0.0]`
- `h₀ = [0.0, 0.0]`（初始记忆为空）

#### t=1：x₁ = [1.0, 0.5]

**第 1 步：算 W_xh · x₁**

`W_xh` 是 2×2，`x₁` 是 2 维向量，结果是 2 维向量：

- 第 1 行：`0.5×1.0 + (-0.5)×0.5 = 0.5 - 0.25 = 0.25`
- 第 2 行：`0.3×1.0 + 0.7×0.5 = 0.3 + 0.35 = 0.65`

所以 `W_xh · x₁ = [0.25, 0.65]`

**第 2 步：算 W_hh · h₀**

`h₀ = [0, 0]`，所以 `W_hh · h₀ = [0, 0]`

**第 3 步：加偏置**

`z₁ = W_xh · x₁ + W_hh · h₀ + b = [0.25+0, 0.65+0] = [0.25, 0.65]`

**第 4 步：tanh 激活**

- `h₁[0] = tanh(0.25) ≈ 0.245`
- `h₁[1] = tanh(0.65) ≈ 0.572`

所以 **`h₁ = [0.245, 0.572]`** ✅

> 注：`tanh(0.25) = 0.2449...`，保留 3 位小数为 0.245。手算时取近似值即可。

#### t=2：x₂ = [0.0, 1.0]

**第 1 步：算 W_xh · x₂**

- 第 1 行：`0.5×0.0 + (-0.5)×1.0 = -0.5`
- 第 2 行：`0.3×0.0 + 0.7×1.0 = 0.7`

所以 `W_xh · x₂ = [-0.5, 0.7]`

**第 2 步：算 W_hh · h₁**（这里就是"记忆"开始起作用的地方）

`h₁ = [0.245, 0.572]`，所以：

- 第 1 行：`0.1×0.245 + 0.2×0.572 = 0.0245 + 0.1144 = 0.139`
- 第 2 行：`(-0.1)×0.245 + 0.4×0.572 = -0.0245 + 0.2288 = 0.204`

所以 `W_hh · h₁ = [0.139, 0.204]`

**第 3 步：加偏置**

`z₂ = W_xh · x₂ + W_hh · h₁ + b = [-0.5+0.139, 0.7+0.204] = [-0.361, 0.904]`

**第 4 步：tanh 激活**

- `h₂[0] = tanh(-0.361) ≈ -0.346`
- `h₂[1] = tanh(0.904) ≈ 0.718`

所以 **`h₂ = [-0.346, 0.718]`** ✅

### 关键观察：参数量与序列长度无关

不管序列是 2 步还是 200 步，RNN 用的都是同一组 `W_xh (2×2) + W_hh (2×2) + b (2,)`，总共 `4+4+2 = 10` 个参数。这就是参数共享的威力——MLP 处理 200 步要 200 套参数，RNN 只要 1 套。

## 怎么用（Use）

代码文件：`深度学习从0到Transformer教程/code/ch18_rnn_structure.py`

关键片段：

```python
import numpy as np

# 参数（与上面手算一致）
W_xh = np.array([[0.5, -0.5], [0.3, 0.7]])
W_hh = np.array([[0.1, 0.2], [-0.1, 0.4]])
b = np.zeros(2)

# 初始隐藏状态
h = np.zeros(2)

# 输入序列
sequence = [np.array([1.0, 0.5]), np.array([0.0, 1.0])]

# 逐时间步更新
for t, x in enumerate(sequence):
    h = np.tanh(W_xh @ x + W_hh @ h + b)
    print(f"t={t+1}: h={h.round(3)}")
```

## 想多一点

> RNN 的参数量与序列长度有关吗？
>
> 答案是：**完全无关**。所有时间步共享同一组 `W_xh, W_hh, b`。序列从 2 步变到 2000 步，参数量纹丝不动。
>
> 这正是 RNN 优于"每步一个 MLP"的核心——参数共享让模型能处理任意长度序列，而且在不同位置学到的规律自动通用。
>
> 代价是什么？所有位置都用同一组参数，意味着 RNN 假设"序列在不同位置遵循相同的规律"。对大多数序列任务（比如语言建模），这个假设是合理的；但如果你处理"前半段是中文、后半段是英文"的混合序列，RNN 就会有点吃力。

## 易错点预警

- ❌ 以为展开后每个时间步有独立参数（觉得 t=1 用 W¹、t=2 用 W²）→ ✅ 正确：**所有时间步共享同一组 `W_xh, W_hh`**。展开只是画法，不是真的有多个网络。
- ❌ 忘记初始化 `h₀`（直接从 t=1 开始算，但 `h₀` 未定义）→ ✅ 正确：`h₀` 通常初始化为**全 0 向量**，相当于"开始读之前记忆是空的"。
- ❌ 用 ReLU 当 RNN 的激活函数（觉得 ReLU 计算快）→ ✅ 正确：RNN 用 **tanh** 而非 ReLU。ReLU 无上界会让记忆值爆炸，tanh 把记忆限制在 `(-1, 1)` 才稳定。

## 章末小结

| 概念 | 一句话解释 | 易错点 |
|------|-----------|--------|
| 隐藏状态 hₜ（Hidden State） | 截至当前的"记忆" | 初始 `h₀` 通常为全 0 向量 |
| 参数共享（Parameter Sharing） | 所有时间步用同一组 W | 参数量与序列长度无关 |
| 时间展开（Unfolding） | 把 RNN 按时间步展开成链 | 展开只是画法，不是真的有多个网络 |
| W_xh（输入权重） | 处理当前输入 xₜ | 与 W_hh 区分，前者管新输入、后者管旧记忆 |
| W_hh（隐藏权重） | 处理上一步记忆 hₜ₋₁ | 这是 RNN"有记忆"的来源 |
| tanh 激活 | 把记忆限制在 (-1, 1) | RNN 用 tanh 不用 ReLU，防止数值爆炸 |
