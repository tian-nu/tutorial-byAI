# Node.js速成后端

<span class="t-tag t-tag-beginner">零基础</span> · 31 章

用 Express 从零搭建博客系统后端，涵盖 API 设计、数据库、JWT 认证、测试与 Docker 部署。短平快，适合快速上手。

---

## 一句话介绍

这是一套**"30小时从零到部署"**的 Node.js 后端教程。你不需要提前学过 Node.js——只要你会 JavaScript 基础（变量、函数、if/else、数组、对象、回调函数），就能跟着走完。每一步都有比喻、有图解、有排错指南。最终你会拥有一个**可以上线的博客系统后端**，以及一套可以迁移到任何后端项目的基本功。

## 你需要的最少 JavaScript 知识

在开始之前，确认你至少能看懂下面每一行（不需要能凭空写出来，看懂就行）：

```javascript
// 变量
const name = "Alice";
let age = 25;

// 函数
function greet(name) {
    return `你好，${name}`;
}

// if/else
if (age >= 18) {
    console.log("成年");
} else {
    console.log("未成年");
}

// 数组
const fruits = ["苹果", "香蕉", "橘子"];
fruits.push("西瓜");

// 对象
const user = { name: "Alice", age: 25 };
console.log(user.name);

// 回调函数
function doSomething(callback) {
    callback("做完了！");
}
doSomething((msg) => console.log(msg));
```

> **如果上面这些你大部分看不懂，建议先学 JavaScript 基础再回来。** 如果大部分能看懂但个别不熟——没关系，教程中遇到时会解释，你也可以现学现查。

## 术语速查（导读篇）

本章出现的术语，完整解释见各章附录和全局 `glossary.md`（待创建）：

| 术语 | 一句话解释 |
|------|-----------|
| **Node.js** | 一个让 JavaScript 在服务器上运行的程序，本质是 Chrome V8 引擎 + 系统 API |
| **Express** | Node.js 最流行的 Web 框架，帮你处理路由、请求、响应 |
| **npm** | Node.js 的包管理器，相当于"应用商店"——帮你下载和管理第三方库 |
| **后端** | 运行在服务器上的程序，负责处理数据、业务逻辑、与数据库交互 |
| **API** | 前后端之间的"服务员"——前端告诉他要点什么菜，他去后厨准备，再把菜端回来 |
| **RESTful** | 一种 API 设计风格：用 URL 表示资源，用 HTTP 方法表示操作 |
