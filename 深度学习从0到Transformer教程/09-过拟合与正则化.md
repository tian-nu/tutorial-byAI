# Ch09 · 过拟合与正则化

> 所属篇：第一篇 · 预计耗时：20 分钟

一个学生把历年考试真题背得滚瓜烂熟，模拟考100分。但高考遇到新题，他考了60分。这就是**过拟合（Overfitting）**——模型把训练数据"背"下来了，但没学到真正的"规律"，遇到新数据就傻眼。这一章我们搞清楚过拟合是什么、怎么发现它、怎么用正则化来治它。

---

## 为了什么（Why）

**核心痛点**：模型太复杂时，它会死记硬背训练数据中的噪声和细节，而不是学习通用规律。

举个反例：你有5个数据点，用一个4次多项式去拟合——曲线会穿过每一个点，训练误差为0。但这条线在数据点之间疯狂扭曲，对新数据的预测一塌糊涂。这就是典型的过拟合：**训练集99%准确率，测试集60%准确率**。

## 要做到（Goal）

- **输入**：训练数据、待评估的模型。
- **输出**：既能在训练集上表现好、又能在新数据上泛化的模型。
- **成功标准**：训练集和测试集的准确率差距 < 5%（没有明显的过拟合信号）。

## 做了什么（What）

模型拟合数据有三种状态，可以这样对比：

```
        欠拟合              刚好              过拟合
    (Underfitting)      (Just Right)     (Overfitting)

损失值  高                 低               极低(接近0)
训练集  差                 好               完美
测试集  差                 好               差

图形示意:
  数据点: ● ● ●

欠拟合: ──────────────   直线太平, 远离所有点
          ●   ●
             ●
                ●

刚好:   ╲╱╲╱╲            平滑曲线, 贴近趋势
       ● ╱  ╲ ●
         ●  ●

过拟合: ～～～～～～～～    扭曲曲线, 穿过每个点
      ●╲╱●╲╱●╲╱●
```

### 逐组件拆解

**训练集 / 验证集 / 测试集**：
- 训练集（Training Set）：用来学参数的（占 70%~80%）
- 验证集（Validation Set）：用来调超参数的（占 10%~15%）
- 测试集（Test Set）：最终只评估一次（占 10%~15%）

**L1 正则化（Lasso）**：在损失函数中加 `λ × Σ|w|` 项。效果是让不重要的权重变成精确的0（稀疏性），相当于自动做特征选择。

**L2 正则化（Ridge）**：在损失函数中加 `λ × Σw²` 项。效果是让所有权重整体变小，但不变成0。最常用。

**早停（Early Stopping）**：训练过程中监控验证集 loss，一旦验证集 loss 开始上升就停止训练（说明开始过拟合了）。

## 怎么算（How）

### 核心公式

```
原始损失：L_data = MSE 或交叉熵等

L2 正则化总损失：L_total = L_data + λ × Σ w²
L1 正则化总损失：L_total = L_data + λ × Σ |w|

L2 梯度修正：∂L_total/∂w = ∂L_data/∂w + 2λw
L1 梯度修正：∂L_total/∂w = ∂L_data/∂w + λ×sign(w)
```

### 数值小例子：L1 和 L2 的具体计算

**设定**：
- 原始损失 L_data = 10.0
- 权重 w = [3.0, -2.0, 1.0]（3个参数）
- 正则化系数 λ = 0.1

**L2 正则化计算**：

L2 正则项 = λ × (w₁² + w₂² + w₃²)
         = 0.1 × (3.0² + (-2.0)² + 1.0²)
         = 0.1 × (9 + 4 + 1)
         = 0.1 × 14
         = **1.4**

总损失 = L_data + L2 正则项 = 10.0 + 1.4 = **11.4**

梯度修正（以 w₁=3.0 为例）：

∂L_total/∂w₁ = ∂L_data/∂w₁ + 2 × λ × w₁
             = 原梯度 + 2 × 0.1 × 3.0
             = 原梯度 + **0.6**

这个额外的 +0.6 会把大权重往小的方向拉！权重越大，被拉的力度越大。这就是 L2 的核心思想——**惩罚大的权重**。

**L1 正则化计算**：

L1 正则项 = λ × (|w₁| + |w₂| + |w₃|)
         = 0.1 × (|3.0| + |-2.0| + |1.0|)
         = 0.1 × (3 + 2 + 1)
         = 0.1 × 6
         = **0.6**

总损失 = L_data + L1 正则项 = 10.0 + 0.6 = **10.6**

注意 L1 的正则项（0.6）比 L2（1.4）小——因为 L1 对大权重的惩罚不如 L2 激烈（平方放大了差异）。但 L1 有个独特性质：它会把不重要的权重推到**精确的0**，而 L2 只会让它们变小但不为0。

## 怎么用（Use）

代码文件：`深度学习从0到Transformer教程/code/ch09_overfitting_regularization.py`

关键片段：

```python
from sklearn.linear_model import Ridge, Lasso
from sklearn.model_selection import train_test_split
import numpy as np

# 生成带噪声的数据
np.random.seed(42)
X = np.random.randn(50, 1) * 2
y = 3 * X.flatten() + np.random.randn(50) * 1.5  # y ≈ 3x + 噪声

# 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3)

# L2 正则化（Ridge 回归）
model_ridge = Ridge(alpha=0.1).fit(X_train, y_train)
print(f"Ridge 训练集 R²: {model_ridge.score(X_train, y_train):.3f}")
print(f"Ridge 测试集 R²:  {model_ridge.score(X_test, y_test):.3f}")

# L1 正则化（Lasso 回归）
model_lasso = Lasso(alpha=0.1).fit(X_train, y_train)
print(f"Lasso 权重: {model_lasso.coef_}")  # 可能有精确的0
```

## 想多一点

> L1 为什么能产生稀疏权重（把某些权重压成精确的0）？
>
> 关键在于**梯度的不同行为**。
>
> **L2 的梯度是 `2λw`**：当 w 接近0时，梯度也趋近于0。就像你越接近目的地，推你的力越小，你只能无限逼近0但永远到不了精确的0。
>
> **L1 的梯度是 `±λ`（常数）**：不管 w 多小，只要不为0，梯度始终是固定的 ±λ。就像有一个恒定的力一直在把你推向0——所以 w 最终会被推到**精确的0**并停在那里（因为0点的次梯度包含0，更新停止）。
>
> 这就是为什么 L1 被用于**特征选择**：它能自动把不重要的特征对应的权重变为0，等于告诉你"这些特征没用"。

## 易错点预警

- ❌ 用测试集来调参（比如反复跑模型选最好的 α），导致数据泄露 → ✅ 正确做法：用验证集调参，测试集只在最后评估一次。如果你没有单独的验证集，可以用交叉验证（Cross Validation）来代替。
- ❌ 正则化系数 λ 设太大（如 λ=100），导致模型欠拟合 → ✅ 正确做法：从 λ=0.01 开始，用验证集或交叉验证选最佳值。sklearn 里可以用 `RidgeCV` 或 `LassoCV` 自动搜索最优 α。

## 章末小结

| 概念 | 一句话解释 | 易错点 |
|------|-----------|--------|
| 过拟合（Overfitting） | 模型把训练数据背下来，泛化能力差 | 不是模型越复杂越好 |
| 欠拟合（Underfitting） | 模型太简单，连训练数据都学不好 | 加特征、换更复杂的模型 |
| L1 正则化（Lasso） | 损失加 λΣ\|w\|，产生稀疏权重（部分为0） | 适合特征选择场景 |
| L2 正则化（Ridge） | 损失加 λΣw²，权重整体变小但不为0 | 最常用的正则化方式 |
| 早停（Early Stopping） | 验证集 loss 上升时停止训练 | 要保存验证集 loss 最低时的模型 |
| 训练/验证/测试集 | 分别用于学参数、调参、最终评估 | 测试集绝不能参与任何训练决策 |
