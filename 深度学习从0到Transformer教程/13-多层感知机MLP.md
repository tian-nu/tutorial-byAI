# Ch13 · 多层感知机 MLP

> 所属篇：第二篇 · 预计耗时：25 分钟

单层感知机解不了异或，被 AI 寒冬冻了 20 年。1986 年 Hinton 说："加一层隐藏层，再配上反向传播，就能拟合任意函数"。多层感知机（MLP, Multi-Layer Perceptron）让神经网络起死回生。从这一章开始，我们正式进入"真正能用的神经网络"时代。

---

## 为了什么（Why）

**核心痛点**：单层感知机只能解线性可分问题；真实世界的数据（图像、文本、语音）高度非线性。

举个反例：XOR 问题用单层感知机永远学不会——上一章我们证明了它是线性不可分的。但只要加一个隐藏层，MLP 秒学 XOR。这不是巧合：**多层 + 非线性激活 = 能拟合任意复杂函数**。

**这一章的目标**：理解 MLP 的结构、前向计算过程和参数量，用 PyTorch 实现一个能解 XOR 的网络。

## 要做到（Goal）

- **输入**：特征向量 X ∈ ℝⁿ（比如 XOR 的两个输入 [0,1]）。
- **输出**：预测向量 Ŷ ∈ ℝᵐ（比如 XOR 的预测结果）。
- **成功标准**：用 MLP 解决 XOR 问题，准确率 100%。

## 做了什么（What）

MLP 的结构就像三明治——输入层夹着隐藏层，最后是输出层：

```
  输入层          隐藏层            输出层
 (2 个神经元)    (3 个神经元)      (1 个神经元)

   x₁ ──→●──┐
             ├──> ●(ReLU) ──→●──┐
   x₂ ──→●──┘                 ├──> ●(sigmoid) ──→ ŷ
                               │
              (偏置 b₁)        │   (偏置 b₂)
```

### 逐组件拆解

**输入层**：接收原始特征。不参与计算，只是数据的入口。维度 = 特征数量 n。

**隐藏层（Hidden Layer）**：MLP 的核心。每层做两件事：
1. **全连接（Linear / Dense）**：`z = Wx + b`——每个神经元与上一层的所有神经元相连。
2. **激活函数**：`a = σ(z)`——注入非线性。没有激活函数，多层就退化成单层！

可以有多层隐藏层，层数越多，网络的表达能力越强（但也不是无限好，后面会讲）。

**输出层**：最后一层全连接。激活函数取决于任务：
- 二分类 → sigmoid（输出概率）
- 多分类 → softmax（输出概率分布）
- 回归 → 不加激活（直接输出数值）

### 万能近似定理（Universal Approximation Theorem）

你可能听过这个定理的名字，但它的直觉是什么？

**一句话**：只要有足够宽的隐藏层（哪怕只有一层），配合非线性激活函数，MLP 可以以任意精度逼近任意连续函数。

**直觉解释**：想象你在画一条复杂的曲线。你手头只有"直线段"（线性变换）和"弯折点"（ReLU 激活）。如果你有足够多的直线段，每段可以在不同的位置弯折，那你就能拼出任何形状的曲线——不管是波浪线、锯齿线还是圆弧。

类比：乐高积木。每一块积木形状简单（矩形），但如果你有足够多的积木，可以拼出城堡、飞船、任何你能想象的东西。隐藏层的每个神经元就是一块"乐高"，激活函数给了它"拼接的能力"。

**但要注意**："足够宽"在实践中可能需要非常多的神经元，参数量爆炸。所以现代做法是用"适中的宽度 + 适当的深度"来平衡表达力和效率。

## 怎么算（How）

### 核心公式

```
隐藏层: h = σ(W₁·x + b₁)
输出层: ŷ = f(W₂·h + b₂)    （f 是输出激活函数，如 sigmoid）
```

### 数值小例子：2-3-1 MLP 解 XOR

网络结构：**2 输入 → 3 隐藏 → 1 输出**

输入 x = [1, 0]（XOR 应该输出 1）

**第 1 步：隐藏层计算**

权重矩阵 W₁（3×2），每个隐藏神经元连两个输入：
```
W₁ = [[1, 1],    ← 隐藏神经元 1 的权重
      [1, 1],    ← 隐藏神经元 2 的权重
      [0, 1]]    ← 隐藏神经元 3 的权重
```
偏置 b₁ = [0, -1, 0]

逐个算 z 值：

- z₁ = W₁[0]·x + b₁[0] = 1×1 + 1×0 + 0 = **1**
- z₂ = W₁[1]·x + b₁[1] = 1×1 + 1×0 + (-1) = **0**
- z₃ = W₁[2]·x + b₁[2] = 0×1 + 1×0 + 0 = **0**

过 ReLU 激活（负数变 0，正数保留）：

- h₁ = ReLU(z₁) = ReLU(1) = **1**
- h₂ = ReLU(z₂) = ReLU(0) = **0**
- h₃ = ReLU(z₃) = ReLU(0) = **0**

隐藏层输出 h = [1, 0, 0]

**第 2 步：输出层计算**

权重 W₂（1×3）：W₂ = [1, -1, 1]，偏置 b₂ = 0

- z₂ = W₂·h + b₂ = 1×1 + (-1)×0 + 1×0 = **1**

过 sigmoid 激活：

- ŷ = sigmoid(1) = 1/(1+e⁻¹) = 1/(1+0.368) = 1/1.368 = **0.731**

**判决**：0.731 > 0.5 → 预测 **1** ✅（XOR([1,0]) 确实应该输出 1！）

### 参数量计算

这个 2-3-1 MLP 一共有多少个可学习参数？

| 层 | 参数 | 维度 | 数量 |
|----|------|------|------|
| 隐藏层权重 | W₁ | 3×2 | 6 |
| 隐藏层偏置 | b₁ | 3 | 3 |
| 输出层权重 | W₂ | 1×3 | 3 |
| 输出层偏置 | b₂ | 1 | 1 |
| **总计** | | | **13** |

才 13 个参数！这就是为什么说 MLP 是最简单的"真正的神经网络"——参数少到你可以手写出来每一个值。

## 怎么用（Use）

本章首次使用 **PyTorch**。别担心，我们会给每一行关键代码加上中文注释。

代码文件：`深度学习从0到Transformer教程/code/ch13_mlp_xor.py`

关键片段：

```python
import torch
import torch.nn as nn

# 定义模型：2输入 -> 4隐藏 -> 1输出
model = nn.Sequential(
    nn.Linear(2, 4),   # 全连接层：输入2维 -> 隐藏4维（仿射变换 y=Wx+b）
    nn.ReLU(),         # ReLU 激活函数：负数归零，正数保留
    nn.Linear(4, 1),   # 全连接层：隐藏4维 -> 输出1维
    nn.Sigmoid()       # Sigmoid 激活：压缩到 (0,1)，作为概率输出
)

# XOR 数据
X = torch.tensor([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
y = torch.tensor([[0.], [1.], [1.], [0.]])

# 损失函数：二分类交叉熵
loss_fn = nn.BCELoss()

# 优化器：Adam，自动调整学习率
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

# 训练循环
for epoch in range(1000):
    pred = model(X)           # 前向传播
    loss = loss_fn(pred, y)   # 计算损失
    optimizer.zero_grad()     # 清空上一步的梯度
    loss.backward()           # 反向传播（自动计算梯度）
    optimizer.step()          # 更新参数

# 预测
print(model(X))
# 预期输出接近 [[0.02], [0.98], [0.98], [0.02]]
```

## 想多一点

> 网络越深越好吗？
>
> 不是。虽然理论上更深 = 更强表达能力，但实践中会遇到几个问题：
>
> 1. **梯度消失/爆炸**：反向传播时梯度逐层相乘，太深了要么趋近于 0（消失），要么指数级爆炸。
> 2. **退化问题（Degradation）**：56 层网络的误差反而比 20 层更高！不是过拟合，而是优化困难。ResNet 用"跳跃连接"解决了这个问题。
> 3. **计算成本**：每多一层就多一次矩阵乘法，训练和推理都更慢。
>
> 所以经典的 trade-off 是：在保证效果的前提下，尽量用浅而宽的网络（宽 = 每层神经元多）。当然，Transformer 打破了这条规则——它很深（几十上百层）但依然工作良好，这得益于其特殊的架构设计。

## 易错点预警

- ❌ 忘记在隐藏层加激活函数，导致多层网络等价于单层（线性组合的线性组合还是线性）→ ✅ 正确：**每层全连接之后必须跟一个非线性激活函数**（输出层是否加激活取决于任务）。
- ❌ 隐藏层维度设太大（比如输入 2 维却用了 1000 维隐藏层），参数爆炸导致严重过拟合 → ✅ 正确：从小规模开始尝试（如 4~32 维），用验证集选择最佳宽度。
- ❌ 在 PyTorch 中 `nn.Linear(in, out)` 的参数顺序搞反 → ✅ 正确：第一个参数是**输入维度**，第二个是**输出维度**。`nn.Linear(2, 4)` 表示接收 2 维输入、输出 4 维。

## 章末小结

| 概念 | 一句话解释 | 易错点 |
|------|-----------|--------|
| MLP（多层感知机） | 多个全连接层 + 非线性激活函数堆叠而成 | 隐藏层太少则欠拟合，太多则过拟合 |
| 隐藏层（Hidden Layer） | 输入层和输出层之间的层，负责特征变换 | 必须配激活函数，否则无意义 |
| 全连接层（Dense/Linear） | 每个神经元与上一层所有神经元相连 | 参数量大，不如卷积高效 |
| 万能近似定理 | 足够宽的单隐藏层 MLP 可逼近任意连续函数 | "足够宽"可能不现实，实际用深度来补偿 |
| 参数量 | 各层权重矩阵元素数 + 偏置向量长度之和 | 参数越多越容易过拟合 |
