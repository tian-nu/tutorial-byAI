初始概览

生产环境中，用户通过 HTTPS 访问博客。Nginx 作为反向代理接收所有请求——API 请求转发给 Node.js（PM2 守护），Node.js 再查询 PostgreSQL；静态文件（如图片）由 Nginx 直接返回，不经过 Node.js。Node.js 和 PostgreSQL 运行在 Docker 容器中。
