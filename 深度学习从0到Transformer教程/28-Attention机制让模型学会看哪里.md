# Ch28 · Attention 机制让模型学会看哪里

> 所属篇：第五篇 · 预计耗时：30 分钟

你读"我爱深度学习"这句话时，看到"爱"字会自然回看"我"——爱的是谁？是"我"。看到"学习"会回看"深度"——学的是什么？是"深度学习"。人脑不是把整句话压成一个抽象的"句子向量"再去用，而是**每读到一个词，就动态决定该回看前面哪些词**。Ch27 的 Seq2Seq 把整句话压成一个固定向量 `c`，长句子必然丢信息。Attention 就是让 Decoder 每生成一个输出词，都**动态决定该关注 Encoder 哪些隐藏状态**——这就是"学会看哪里"。本章把 Attention 的三步——打分、归一化、加权求和——彻底拆开，并手算一个完整小例子。

---

## 为了什么（Why）

**核心痛点**：Ch27 的 Seq2Seq 用一个固定向量 `c` 装下整句话的信息。短句子够用，长句子必然丢信息——后段翻译质量会断崖式下跌，因为 Decoder 看到的 `c` 已经被信息塞爆了。

**举个反例**：翻译 30 字长句"我昨天去北京出差，见到了三年没见的老同学张三，他请我吃了北京烤鸭。" Seq2Seq 的 Encoder 把这 30 字全部压进一个 512 维的 `c`，Decoder 在生成"He"的时候已经记不清"张三"是男是女，在生成"treated me"的时候已经忘了"北京烤鸭"。固定 `c` 装不下这么多信息。

**Attention 的解法**：Decoder 每生成一个词，都**回看 Encoder 的所有 T 个隐藏状态** `h_1^enc, ..., h_T^enc`，根据当前需要挑出最相关的几个加权求和，得到一个**动态的、随每步变化**的上下文向量 `c_t`。这就好比查字典——你想知道"他"指代谁，就去原文里翻一遍，挑最相关的词。

**这一章的目标**：理解 Attention 的打分、归一化、加权求和三步，能手算一个简单例子。

## 要做到（Goal）

- **输入**：Ch27 的 Seq2Seq 架构、知道 Encoder 隐藏状态 `h_i^enc` 是什么。
- **输出**：理解 Attention 的三步公式，给定 Decoder 当前状态和 Encoder 3 个隐藏状态，能算出 attention 权重 `α` 和上下文向量 `c_t`。
- **成功标准**：手算得到 `α = [0.331, 0.351, 0.318]`，`c = [0.542, 0.458]`（与代码验证一致）。

## 做了什么（What）

Attention 的核心是三步走：

```
Encoder 隐藏状态                Decoder 当前状态
h_1^enc, h_2^enc, ..., h_T^enc    h_t^dec
   │     │       │                  │
   └─────┴───────┴──────────────────┴───┐
                                        ▼
                            ┌─────────────────────┐
                            │  1. 打分 (score)     │  ← 每个 Encoder 状态打一个相关性分数
                            └──────────┬──────────┘
                                       ▼
                            ┌─────────────────────┐
                            │  2. 归一化 (softmax)  │  ← 分数变概率，和为 1
                            └──────────┬──────────┘
                                       ▼
                            ┌─────────────────────┐
                            │  3. 加权求和 (c_t)    │  ← 用概率对 Encoder 状态加权求和
                            └──────────┬──────────┘
                                       ▼
                                  上下文向量 c_t
```

打个比方：Attention 就像你在地图上找重点——`h_t^dec` 是你"想找什么"的搜索关键词，每个 `h_i^enc` 是地图上一个地点，**打分函数**计算"搜索词和这个地点的相关性"，**softmax** 把分数变成"0 到 1 的概率"，**加权求和**就是"按概率把所有地点的内容混在一起"。

### 逐组件拆解

**打分函数（Score Function）**：给定 Decoder 当前状态 `h_t^dec` 和 Encoder 第 i 个状态 `h_i^enc`，输出一个标量分数 `e_{t,i}`。分数越高表示越相关。常见三种：

1. **Dot（点积）**：`e_{t,i} = h_t^dec · h_i^enc`（最简单，Transformer 用它的变体）
2. **General（一般）**：`e_{t,i} = h_t^dec · W · h_i^enc`（W 是可学习矩阵，Luong 提出）
3. **Concat（拼接）**：`e_{t,i} = v^T · tanh(W · [h_t^dec ; h_i^enc])`（v 和 W 是可学习参数，Bahdanau 提出）

> **为什么有三种？** 历史原因。Bahdanau 2014 年提出 Attention 时用 concat，因为它对 RNN 隐藏状态的"非线性匹配"更友好；Luong 2015 年简化成 general 和 dot——它们更省参数、计算更快，但对维度有要求（dot 要求 `h_dec` 和 `h_enc` 同维）。Transformer 后来在 Self-Attention 里用 dot 的缩放版本，因为矩阵运算可以高度并行。三种是同一思想的不同实现，**没有优劣之分，看场景选**。

**归一化（softmax）**：把分数 `e_{t,1}, ..., e_{t,T}` 变成概率分布 `α_{t,1}, ..., α_{t,T}`，要求：

```
α_{t,i} = exp(e_{t,i}) / Σ_j exp(e_{t,j})
```

且 `Σ α_{t,i} = 1`，每个 `α_{t,i} ∈ [0, 1]`。

**上下文向量（Context Vector）**：用 attention 权重对 Encoder 所有隐藏状态加权求和：

```
c_t = Σ_i α_{t,i} × h_i^enc
```

Decoder 第 t 步不再用固定的 `c`，而是用动态的 `c_t`。最后把 `[h_t^dec ; c_t]` 拼起来过线性层 + softmax 输出词。

## 怎么算（How）

### 三种打分函数的公式

**Dot（点积）**：

```
e_{t,i} = h_t^dec · h_i^enc = Σ_k h_t^dec[k] × h_i^enc[k]
```

**General（带可学习矩阵 W）**：

```
e_{t,i} = h_t^dec^T · W · h_i^enc
```

其中 `W` 是 `d × d` 的可学习矩阵，相当于先对 `h_dec` 做一次线性变换再点积。

**Concat（拼接后过 MLP）**：

```
e_{t,i} = v^T · tanh(W · [h_t^dec ; h_i^enc])
```

其中 `W` 是 `d × 2d` 的矩阵（拼接后的向量长度翻倍），`v` 是 `d` 维向量，`tanh` 是激活函数。这个形式可以学到 `h_dec` 和 `h_enc` 之间的非线性关系。

### 数值小例子（用 dot 打分）

设：
- Encoder 3 个隐藏状态：`h_1^enc = [0.5, 0.5]`，`h_2^enc = [0.8, 0.2]`，`h_3^enc = [0.3, 0.7]`
- Decoder 当前状态：`h_t^dec = [0.6, 0.4]`

**第 1 步：打分**

逐项算点积：

- `e_1 = 0.6 × 0.5 + 0.4 × 0.5 = 0.30 + 0.20 = 0.50`
- `e_2 = 0.6 × 0.8 + 0.4 × 0.2 = 0.48 + 0.08 = 0.56`
- `e_3 = 0.6 × 0.3 + 0.4 × 0.7 = 0.18 + 0.28 = 0.46`

`h_2^enc`（"深度"对应的隐藏状态）和当前 Decoder 状态最相关，分数最高。

**第 2 步：softmax 归一化**

> ⚠️ **数值稳定的 softmax**：直接算 `exp(e)` 在分数很大时会溢出。标准做法是先减去最大值再 exp，公式为 `softmax(x) = exp(x - max(x)) / Σ exp(x - max(x))`。这在 Ch03 已经讲过。本章例子分数都很小（< 1），减不减最大值结果一样，但代码里必须养成习惯。

- `exp(0.50) = 1.6487`
- `exp(0.56) = 1.7507`
- `exp(0.46) = 1.5841`
- 总和 `= 1.6487 + 1.7507 + 1.5841 = 4.9835`

归一化：

- `α_1 = 1.6487 / 4.9835 = 0.331`
- `α_2 = 1.7507 / 4.9835 = 0.351`
- `α_3 = 1.5841 / 4.9835 = 0.318`

所以 `α = [0.331, 0.351, 0.318]`，三者之和为 1.000。

**第 3 步：加权求和得上下文向量**

```
c_t = 0.331 × [0.5, 0.5] + 0.351 × [0.8, 0.2] + 0.318 × [0.3, 0.7]
```

逐维算：

- `c_t[0] = 0.331 × 0.5 + 0.351 × 0.8 + 0.318 × 0.3`
         `= 0.1655 + 0.2808 + 0.0954 = 0.5417 ≈ 0.542`
- `c_t[1] = 0.331 × 0.5 + 0.351 × 0.2 + 0.318 × 0.7`
         `= 0.1655 + 0.0702 + 0.2226 = 0.4583 ≈ 0.458`

所以 `c_t = [0.542, 0.458]`（细纲里 `[0.542, 0.459]` 是用更粗的四舍五入 α 算的近似，全精度为 0.458）。

**直觉解读**：Decoder 当前在生成某个词，它"分配"了 35.1% 的注意力给 Encoder 第 2 个状态（分数最高），32% 给第 3 个状态，33.1% 给第 1 个状态。最后的上下文向量偏向 `h_2`（0.8 那一项贡献最大），但仍融合了三个状态的信息。这就是 Attention"动态看哪里"的本质。

## 怎么用（Use）

代码文件：`深度学习从0到Transformer教程/code/ch28_attention.py`

关键片段：

```python
import numpy as np

def softmax_stable(x):
    """数值稳定的 softmax：先减最大值再 exp。"""
    x = x - np.max(x)
    e = np.exp(x)
    return e / e.sum()

def attention_dot(h_dec, h_enc_list):
    """dot 打分函数的 Attention。"""
    scores = np.array([np.dot(h_dec, h) for h in h_enc_list])
    alpha = softmax_stable(scores)
    c = np.sum(alpha[:, None] * h_enc_list, axis=0)
    return c, alpha

# 验证小例子
h_enc = np.array([[0.5, 0.5], [0.8, 0.2], [0.3, 0.7]])
h_dec = np.array([0.6, 0.4])
c, alpha = attention_dot(h_dec, h_enc)
print(alpha)  # [0.331, 0.351, 0.318]
print(c)      # [0.542, 0.458]
```

## 想多一点

> Attention 权重 `α` 真的代表"模型在看哪里"吗？
>
> 答案是：**不完全等于，要谨慎解读**。`α` 是"Decoder 当前状态和 Encoder 各状态的相关性度量"，但它不等于因果解释。同一组 `α` 可能在不同任务里意义不同，可视化时容易产生误导——比如某个 `α_i` 高，可能是真的"重要"，也可能只是"维度对齐得好"。BERT 出来后有不少论文专门研究 attention weight 的可解释性问题，结论是：attention weight 可以作为"模型在关注什么"的参考，但不能当作严谨的因果证据。

## 易错点预警

- ❌ 忘记 softmax 归一化，直接用原始分数 `e_i` 作为权重 → ✅ 正确：必须 softmax 让权重和为 1，否则加权求和的尺度会乱。原始点积分数可能是负数或大于 1，没法当概率用。
- ❌ softmax 时不减最大值，分数大时溢出 → ✅ 正确：用 `softmax(x) = exp(x - max(x)) / Σ exp(x - max(x))`，与 Ch03 教的一致。这是个习惯问题，分数小看不出来，分数一大就崩。
- ❌ 把 attention 权重高当成"模型觉得这个词重要"的因果证据 → ✅ 正确：权重是相关性度量，不是因果重要性。可视化时只能作为参考，不能当严谨解释。
- ❌ general 和 concat 打分函数忘写公式 → ✅ 正确：dot 是 `h_dec · h_enc`，general 是 `h_dec · W · h_enc`，concat 是 `v^T · tanh(W · [h_dec ; h_enc])`，三种各有适用场景。

## 章末小结

| 步骤 | 公式（dot 版） | 作用 | 易错点 |
|------|--------------|------|--------|
| 打分 | `e_i = h_dec · h_enc_i` | 衡量 Decoder 当前状态与 Encoder 各状态的相关性 | 还有 general、concat 两种，按场景选 |
| 归一化 | `α = softmax(e)` | 把分数变成概率分布，和为 1 | 必须减最大值，防止溢出 |
| 加权求和 | `c_t = Σ α_i × h_enc_i` | 聚合所有 Encoder 状态得到动态上下文 | 权重和必须为 1 才能正确加权 |
| 解码 | `y_t = softmax(W_o · [h_dec ; c_t])` | 拼接后过线性层生成词 | c_t 每步都变，不是固定向量 |
