# 28 — Wireshark 入门：网络也有"监控摄像头"

## 学习目标

- 安装 Wireshark 并完成首次成功抓包
- 理解捕获过滤器和显示过滤器的区别
- 能用基本过滤器筛选感兴趣的流量
- 认识 Wireshark 界面四大区域

---

你在小区门口装了个监控摄像头，能回放谁进了小区、几点进的、待了多久。Wireshark 就是网络的"监控摄像头"——它把经过你网卡的每一个数据包都录下来，让你回放、搜索、分析。

学网络不抓包，就像学医不解剖——你背了一堆协议名词，但从来没见过它们长什么样。从这一章开始，我们用三章实战，把前面学的 TCP（第 15-17 章）、HTTP、DNS 全部"亲眼看见"。

---

## 28.1 安装 Wireshark

### Windows

1. 打开 https://www.wireshark.org/download.html
2. 下载 Windows Installer（64-bit）
3. 安装过程中，**关键步骤**：
   - 勾选 **Install Npcap**（抓包驱动，必须装）
   - Npcap 安装选项中，勾选 **"Support raw 802.11 traffic"**（如果需要抓 WiFi 帧的话）
   - 其余默认即可
4. 安装完成后，从开始菜单启动 Wireshark

### macOS

```bash
brew install --cask wireshark
```

安装后需要给权限：

```bash
sudo chown $USER:admin /dev/bpf*
```

然后注销重新登录。

💡 **想多一点：Windows 没有 Wireshark 怎么办？**

如果你用的是公司电脑没有管理员权限装不了 Wireshark，有两种替代方案：

1. **用 tcpdump（Linux/macOS 自带）**：命令行抓包，虽然没有图形界面，但同样能抓到包并保存为 `.pcap` 文件，然后传到有 Wireshark 的机器上分析。
   ```bash
   sudo tcpdump -i any -w capture.pcap host baidu.com
   ```
2. **跟着本章截图走**：每一节都配有详细的截图描述，即使你手里没跑 Wireshark，跟着文字描述读完也能理解每个步骤发生了什么。但强烈建议想办法装上——亲手抓一次包比看十遍截图管用。

### 验证安装

启动 Wireshark，看到欢迎界面（列出了你的网卡列表），就说明安装成功了。

## 28.2 界面速览——四块区域，各管各的

打开 Wireshark 后，你会看到四大区域（从上到下）：

| 区域 | 名称 | 干什么的 |
|------|------|----------|
| ① | **过滤器栏** | 输入过滤条件，只显示你关心的包 |
| ② | **包列表（Packet List）** | 每个包一行，显示序号、时间、来源、目的、协议、长度、信息 |
| ③ | **包细节（Packet Details）** | 选中某个包后，这里按协议分层展开包里的所有字段 |
| ④ | **原始数据（Packet Bytes）** | 这个包的十六进制原始数据 + ASCII 对照 |

把这四块想象成：
- ① = 搜索框（"我只看北京的车辆"）
- ② = 车辆进出记录表（所有经过的车）
- ③ = 某辆车的详细信息（车牌、颜色、品牌、驾乘人员）
- ④ = 这辆车的原始照片（未经解析的原始数据）

## 28.3 选择网卡——别抓了个寂寞

Wireshark 启动后会列出你电脑上所有网卡。你需要选择一个**真正在收发数据的网卡**。

❌ **常见错误**：
- 选了"Loopback"（回环网卡）→ 只能抓到本机发给本机的包
- 选了虚拟网卡（VMware/VirtualBox 创建的）→ 只能抓到虚拟机的流量
- 选了没插网线的以太网卡 → 什么都抓不到

✅ **正确做法**：
1. 看网卡名称旁边的**波形图**——有小波动的那张卡就是正在收发数据的卡
2. 一般笔记本电脑：选 **WiFi 网卡**（名称里带 "Wireless" 或 "Wi-Fi"）
3. 台式机插网线：选 **以太网卡**（名称里带 "Ethernet"）
4. 如果不确定，打开一个网页，看哪个网卡的波形在跳动

💡 **想多一点：选错网卡抓到空包怎么办？**

打开 Wireshark，选了某张网卡，点了开始，等了 30 秒——包列表空空如也。三步排查：

1. **看波形**：网卡旁边有波形图吗？没有 = 这张卡没有流量经过
2. **换一张卡**：切到有波动的卡，一般就是 WiFi 或以太网
3. **还在空？** 打开浏览器随便访问一个网站，制造流量后再看

## 28.4 捕获过滤器——抓之前就筛

捕获过滤器是**抓包前**设置的规则。不符合条件的包根本不会被记录下来，省内存、省 CPU。

语法：

| 过滤器 | 含义 |
|--------|------|
| `host 192.168.1.1` | 只抓与该 IP 相关的包（无论收发） |
| `port 80` | 只抓端口 80 的包 |
| `tcp` | 只抓 TCP 包 |
| `host baidu.com and port 443` | 只抓 baidu.com 的 HTTPS 流量 |
| `not arp` | 排除 ARP 包（ARP 噪声很大） |

设置方法：在开始抓包前，在捕获选项里找到"Capture Filter"输入框，填入上面的表达式。

❌ **错误写法**：`host = 192.168.1.1`（多了等号）

✅ **正确写法**：`host 192.168.1.1`

---

## 28.5 显示过滤器——抓完再筛

显示过滤器是**抓包后**用的。它不丢数据，只是把不符合条件的包暂时隐藏。

这是你日常用得最多的功能。先从常用的开始：

| 过滤器 | 含义 |
|--------|------|
| `http` | 只显示 HTTP 包 |
| `dns` | 只显示 DNS 包 |
| `tcp.port == 443` | 只显示 HTTPS（端口 443）的 TCP 包 |
| `ip.addr == 8.8.8.8` | 只显示与 8.8.8.8 相关的包 |
| `tcp.flags.syn == 1` | 只显示 TCP SYN 包（三次握手的第一个包） |
| `icmp` | 只显示 ICMP（ping）包 |
| `tls` | 只显示 TLS 握手包 |

输入过滤器后，如果语法正确，输入框背景是**绿色**；语法错误则变**红色**。

❌ **常见错误**：`tcp.port=443`（少一个等号，Wireshark 的显示过滤器要求 `==`）

✅ **正确写法**：`tcp.port == 443`

💡 **想多一点：为什么要区分捕获过滤器和显示过滤器？**

打个比方：
- **捕获过滤器** = 你只拍北京车牌的车的照片（拍完就没了，没拍到的永远丢失）
- **显示过滤器** = 你拍了所有车的照片，但在手机相册里搜索"北京车牌"（只是暂时隐藏其他照片）

所以：**不确定要什么的时候，先全抓再用显示过滤器筛选**。磁盘空间够的话，全抓永远比漏抓强。

## 28.6 着色规则 + 色盲友好提示

Wireshark 默认给不同协议上不同颜色，帮你快速辨认。常见默认配色：

| 颜色 | 协议 |
|------|------|
| 浅绿 | HTTP |
| 浅蓝 | DNS |
| 浅紫 | TCP |
| 深灰底 | TCP 有问题的包（重传、丢包） |
| 黑底红字 | 被 RST 重置的包 |

💡 **色盲友好提示**：如果你对颜色分辨有困难，可以通过以下方式自定义：

1. 菜单栏：**View → Coloring Rules**
2. 在弹出的对话框中，可以双击任意规则修改背景色和前景色
3. 建议方案：把"坏包"类规则改为**加粗字体**而非仅靠颜色区分（点击规则 → Edit → 勾选 Bold）
4. 也可以完全禁用着色：**View → Colorize Packet List**（取消勾选），纯靠协议名称辨认

## 28.7 第一个抓包——ping 一下百度

好了，理论够了。来抓你的第一个包。

### 步骤

**Step 1**：打开 Wireshark，双击你正在用的网卡（有波形跳动的那张），开始抓包。

你会看到包列表疯狂滚动——别慌，这是电脑在正常"呼吸"（后台同步、心跳包等）。

**Step 2**：在过滤器栏输入 `icmp`，列表暂时还是空的（因为还没 ping）。

**Step 3**：打开终端（PowerShell / Terminal），执行：

```powershell
# Windows PowerShell
ping baidu.com -n 4
```

```bash
# macOS / Linux
ping -c 4 baidu.com
```

**Step 4**：回到 Wireshark，你应该看到 8 个包（4 个 Request + 4 个 Reply）。

**Step 5**：点击红色的"停止"按钮（红色正方形），停止抓包。

### 看懂结果

点第一个包（ICMP Echo Request），看包细节区域：

```
Internet Control Message Protocol
    Type: 8 (Echo (ping) request)
    Code: 0
    Checksum: 0xXXXX
    Identifier (BE): 1
    Sequence Number (BE): 1
```

这就是你的电脑对百度说："喂，你在吗？"

再点第二个包（ICMP Echo Reply）：

```
Internet Control Message Protocol
    Type: 0 (Echo (ping) reply)
    Code: 0
```

这是百度回你："在呢！"

💡 **想多一点：我的包列表里全是乱七八糟的东西，找不到 ICMP 包！**

过滤器栏你输入的是 `icmp` 吗？注意：
- ❌ 不要输入 `ICMP`（大小写无所谓，Wireshark 不区分，但有些人会打成 `ICPM`）
- ❌ 不要在 `icmp` 前后加空格
- ✅ 输入小写 `icmp` 后按回车

如果过滤后还是空的，说明你 ping 的包没被抓到——检查你是不是选错网卡了（回 28.3 节）。

## 28.8 实战演练：抓到https://baidu.com的TCP连接

现在换成 TCP 练手。

**Step 1**：清空过滤器栏，你会看到所有包。

**Step 2**：打开浏览器，访问 `https://baidu.com`。

**Step 3**：在过滤器栏输入 `tcp and ip.addr == baidu.com的IP`。不知道 IP？先输入 `dns`，找到 `baidu.com` 的 DNS 响应，里面就有 IP。然后把 IP 代进去。

或者更简单的写法——直接用 DNS 名做过滤（Wireshark 会自动解析）：

```
http.host contains "baidu.com"
```

如果没有 HTTP 明文包（因为 HTTPS 加密了），就这样写：

```
tls.handshake.extensions_server_name contains "baidu.com"
```

这会显示 TLS 握手中包含 `baidu.com` 的 Client Hello 包。

## 术语表（存入附录）

| 术语 | 解释 |
|------|------|
| **Wireshark** | 开源的网络封包分析工具，业内标准抓包软件 |
| **捕获过滤器** | 抓包前设置的过滤规则，不符合条件的包不记录，语法用 BPF（Berkeley Packet Filter）格式 |
| **显示过滤器** | 抓包后设置的过滤规则，只是隐藏不符合条件的包而不删除，语法用 Wireshark 自有格式 |
| **Npcap** | Windows 上的数据包捕获驱动，Wireshark 通过它从网卡获取数据 |
| **ICMP** | Internet Control Message Protocol，用于网络诊断（ping 用的就是这个协议） |
