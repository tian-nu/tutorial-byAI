# Ch00 · 开篇：为什么写这份教程

> 所属篇：第零篇 · 预计耗时：10 分钟

2023 年 ChatGPT 横空出世，所有人都在谈 AI。但你有没有发现一个尴尬的事实：90% 的人只会调用 API。`from transformers import pipeline` 跑两行代码出结果，就觉得"我会 AI 了"。可如果 API 被封了，你能从零造一个吗？模型输出乱码时，你能定位到是 Tokenizer 编码没对齐，还是 Self-Attention 的 mask 写反了吗？这份教程就是来回答这些问题的——我们不调包，我们从零开始，一行一行把 Transformer 写出来。

---

## 为了什么（Why）

AI 热潮里有两类人，中间隔着一道鸿沟：

- **调包侠**：会 `import`，能跑通 demo，遇到 bug 只会重启、改 batch size、换 seed。
- **懂原理的人**：能看懂论文每一行公式，遇到 bug 能定位到梯度爆炸、梯度消失、注意力掩码错位。

这不是鄙视调包侠。工业界 80% 的活儿调包就够了。但剩下 20% 的关键问题——模型为什么训不动、为什么 loss 不降、为什么生成重复——只有懂原理的人能解决。

举个反例：只会 `from transformers import pipeline` 的人，遇到"模型输出乱码"时束手无策，只能 Google 碰运气；懂 Self-Attention 的人会先查 Tokenizer 编码是否对齐、padding 是否被 mask 掉、position embedding 是否越界。

> **本教程的定位**：带你从"调包侠"走到"懂原理的人"。不教你调 API，教你**为什么 API 这么设计**。

## 要做到（Goal）

- **输入**：你会任意一门编程语言（Python 最好，不会也行，Ch04 会带装），数学只记得高中水平。
- **输出**：读完本教程后，你能看懂 "Attention Is All You Need" 论文的每一句话，能向别人讲清楚"Transformer 为什么取代了 RNN"。
- **成功标准**：能从零用 NumPy 手写一个 Self-Attention，并解释每个矩阵的维度含义。

## 做了什么（What）

> **本节精简**：Ch00 是开篇，没有技术结构可拆，只讲方法论和路线图。

本教程的方法论是**五维度框架**——每一个技术点都按下面五个角度展开，缺一不可：

1. **为了什么（Why）**：这个技术解决什么痛点？不学会怎样？
2. **要做到（Goal）**：学完后的可观测效果是什么？
3. **做了什么（What）**：这个技术的结构是什么？由哪些组件构成？
4. **怎么算（How）**：核心公式 + 具体数字的逐步计算。
5. **怎么用（Use）**：代码怎么写？怎么验证跑对了？

为什么强制五维度？因为只看公式会"假懂"，只敲代码会"瞎用"。五维度逼你既知其然又知其所以然。

## 怎么用（Use）

> **本节精简**：Ch00 没有代码，只给阅读建议。

### 阅读建议

1. **准备纸笔**：每个公式都手推一遍。看懂 ≠ 会推，会推 ≠ 讲清楚。
2. **准备 Python 环境**：每章代码都手敲一遍，不要复制粘贴。Ch04 会带你搭环境。
3. **每章末尾做小结**：合上教程，用自己的话复述这一章讲了什么。复述不出来就是没懂。
